## 播放建议

- 声音默认关闭；从游戏岛一次点击进入后只自动启动画面和摄像头，孩子主动打开声音后才播放。
- 三套主题使用各自循环音乐；赛程跨过 25% / 50% / 75% 时轮换短提示，进入最后 15% 时播放一次冲刺提示。达到目标使用 `finish-best`，正常冲线使用同样正向的 `finish-gentle`。
- 正常音乐建议音量约 `0.14—0.18`，冲刺版交叉淡入时保持相同总响度。
- 发动机建议音量约 `0.08—0.20`，播放速率在约 `0.85—1.45` 内随内部车速平滑变化，不能每帧突变。
- 换道使用 `lane-whoosh-short.cc0.ogg`，只在车道状态确认后播放；头部边界抖动不能反复触发。
- 碰撞建议音量不高于 `0.30`，同一障碍的碰撞冷却期间不重复播放。
- 倒计时、终点和碰撞是一次性音效；暂停、结算、离页和关闭声音时立即停止或淡出所有循环轨。
- 音频失败只降级声音，不阻止摄像头、赛车控制、赛程或结算。
