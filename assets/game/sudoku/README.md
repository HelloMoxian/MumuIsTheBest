# 星页数独美术

内置 image_gen.imagegen 生成的五套主题图标和场景，沿用试玩确认的精细美术。正式运行时使用 apps/web/public/images/sudoku/ 下的 45 个透明 PNG 图标及 5 张背景。

source/ 保存 6 张原始生成图集和完整 prompts.json，提示词内的 source 为相对文件名。原始透明通道及每个图案的身份保持一致，图标编号仅用于稳定资源映射，不出现在候选摘要中。

图标顺序为每张图集按行从左至右。主题包括 gems、elements、numbers、letters、crew，均为 9 个图案。背景图集为 2 列 × 3 行：水晶花园、原子星港、数字航海、字母邮局、伙伴营地、备用探索舱（最后一张不用于正式数独）。最终素材已按主体轮廓对齐为 512px 方形画布。

运行时不依赖临时原型、源图集或在线图片服务。无新增声音资产；背景音乐沿用全站设置。
