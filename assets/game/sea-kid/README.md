# 跳海小孩图集

生成方式：内置 imagegen（不是 CLI / API fallback）。三张原图永久保留；图集原始 alpha 已存在，因此提取时不再抠除角色颜色。

| 源文件 | 网格 | 内容 |
| --- | --- | --- |
| characters.png | 6 × 4 | 三级外形 × 六姿态，六种普通敌人 |
| objects.png | 6 × 4 | 八个 BOSS、独立道具/子弹/机关 |
| environment.png | 4 × 4 | 四种纹理、平台、水、四种植物与四种装饰 |

产品文件：`apps/web/public/images/sea-kid/{characters,objects,environment}/`。每组 manifest 记录源格位、完整画布、alpha 与稳定 ID；`apps/web/src/features/sea-kid/assets.json` 记录渲染范围与角色头部/脚底锚点。

切分使用 `.agents/skills/chroma-atlas-extractor/scripts/extract_chroma_atlas.py`，`--keep-background`，角色/道具 inset=1，环境 inset=3，保持完整格位。稳定 ID 与次序见各组 manifest，不通过文件系统顺序推断。之后运行 `python3 scripts/prepare-sea-kid-assets.py`，清理邻格小残片并更新目录；此步骤不改源图。
