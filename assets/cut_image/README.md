# 切水果逐帧美术资产

本目录由用户提供并作为正式产品资产随 Git 发布。源文件保留原目录、文件名、透明通道和逐帧尺寸，不覆盖、不重采样，也不二次裁切。

## 正式使用

- `food/`：胡萝卜、黄瓜、茄子、鸡腿和鱼的完整体与两半碎片。
- `blood/`：四种颜色的命中果渍。
- `other/`：炸弹、三连切龙虾和龙虾碎片。

前端通过 `import.meta.glob` 打包 PNG 并按文件名数字顺序播放；运行时不依赖本目录以外的图片管理服务。

## 当前保留但不接入

- `bar/`、`score/`、`start/`：橙色街机语言与星际探索舱不一致，且图片文字不利于无障碍和高 DPI，因此 HUD、分数、倒计时和进度改用 HTML/CSS。
- `effect/double/`、`effect/words/`：素材写有“双倍得分”，与正式三倍超级模式冲突。
- `effect/freeze/`、`effect/bossdead/`：本版未定义冰冻或 Boss 规则，保留给后续明确玩法使用。

所有 `sprite.json` 是用户提供的帧率与序列说明。部分记录的 `count` 与实际 PNG 数量不完全一致时，以已存在、按数字自然排序的 PNG 文件为运行时事实，构建不猜测缺失帧。
