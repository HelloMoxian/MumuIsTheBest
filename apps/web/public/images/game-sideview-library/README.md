# 横版 2D 游戏资产库

这是一套独立的横版侧视美术资产，供后续小游戏选用。它与“万物构成塔”的节点、图谱、合成数据和运行逻辑没有关系，也不应从该功能中直接引用或反向耦合。

## 资产规模

- 《命令与征服：红色警戒 2／尤里的复仇》：8 张图集，160 个格位。
- 《魔兽争霸 Ⅲ》：7 张图集，140 个格位。
- 合计：15 张 5×4 图集，300 个格位。
- 每张源图均为 1536×1024 PNG；同名 WebP 是面向网页加载的压缩版本。

## 格位映射

所有图集固定为 5 列、4 行，每格一个完整元素，不在图片中烘焙名称。`catalog.v1.json` 中的 `items` 使用从左到右、从上到下的零基顺序：

```ts
const column = index % 5;
const row = Math.floor(index / 5);
```

1536 不能被 5 整除，裁切时不要写死整数格宽。应按原图尺寸的比例边界取整，避免越往右误差越大：

```ts
const x0 = Math.round((column * imageWidth) / 5);
const x1 = Math.round(((column + 1) * imageWidth) / 5);
const y0 = Math.round((row * imageHeight) / 4);
const y1 = Math.round(((row + 1) * imageHeight) / 4);
```

网页中也可以直接用百分比背景定位；需要独立透明精灵时，建议从 PNG 源图按上述边界裁切，再执行背景分离与边缘清理。

## 使用约定

- 默认优先加载 `atlases/` 下的 WebP；精细放大、再加工和重导出使用 `source-atlases/` 下的 PNG。
- 业务数据只保存 `catalog.v1.json` 中的稳定 `id`，不要保存数组下标。
- 后续扩展继续保持“一张图 20 个元素”，新增图集和条目，不改变旧 ID 与旧格位。
- 横版玩法中，人物和载具默认朝右；需要朝左时由渲染层水平翻转。
- 图集含深色工作底与青色分隔线，当前版本是可稳定批量生成的母版资产，不等同于已经抠成透明背景的最终动画精灵。
