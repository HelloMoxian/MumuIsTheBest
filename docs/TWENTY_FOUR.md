# 24点

数学入口 `/math/twenty-four`，正式规则版本 2（外壳数据版本仍为 1）。

## 数字与计算

- 每题 8 张数字牌：先随机生成 4 张有解原始牌，再加入 4 张独立随机牌，并打乱全部位置。数值为 0—13，允许同值牌；每张牌有独立位置身份。大号显示实际数字，1/11/12/13 同时注明 A/J/Q/K。
- 从 8 张中任选恰好 4 张，每张只使用一次。其余牌可不用；加减乘除不限次数，只允许单层括号（可并列，不可嵌套）、负数与精确分数。不能拼接数字、阶乘、乘方或除以零。少于 4 张即使得到 24 也不完成。
- 两两合并枚举覆盖左右非交换次序和所有括号结构。生成器只查找必要括号深度不超过 1、且中间结果均为非负整数的参考解，最多尝试 80 次，再使用已验证的保底四张并继续随机加牌。用户答案不受“整数中间结果”限制。服务端使用约分 BigInt 有理数，判定不依赖浮点容差或 eval。
- 额外牌与原始牌完全平等；服务端接受任意合法四牌解，不要求复现预先保存的解。

## 儿童交互

- 主体为四个大数字格，新题与清空后四个数字和三个运算符全部为 null。八张候选及加减乘除常驻显示；点格后选数字，或直接点候选依次填入首个空格。已用牌标注格号并禁用，同值不同牌仍可分别选。点连接位可指定要替换的运算，未指定时依次填入首个空运算位。
- 每格下方左、右各有括号按钮。点左括号进入配对状态，只允许选择合法的右侧结束位置或取消；配对中不可提交。最多两对，只可并列，不可嵌套，不允许交叉范围、单个数字空套或重复范围；点击已有右括号移除一对。括号直接显示在数字两侧。
- 算式遵循先括号、再乘除、后加减，同优先级从左到右。点“算好了”后核验；未到24给出实际结果和调整提示，正确才提交服务端结算。支持精确分数、负数，除以零不能提交。
- 保留撤销、重置算式、参考解、换题确认、历史及下一题。撤销和重置保留用时、参考解状态。候选始终可见，Escape 取消指定位置并恢复触发格焦点；窄屏算式工作台自身横向滚动，候选面板保持四列，不让全页横向溢出。
- 正计时可隐藏；暂停遮住数字与解法，后台自动申请暂停，回前台主动继续。暂停以服务端收到并保存为准，离线或退出前未送达的暂停不虚报成功；计时不会依赖浏览器自报时长。
- 继承单行顶栏、知识币余额与飞币反馈；不接数字输入键盘。按钮可 Tab/Enter/空格操作，选中有数字和对号；桌面全宽紧凑布局，候选与提交按钮一屏可见，参考解以模态展示；窄屏四列候选，算式局部横向滚动；尊重减弱动效。原有全站音乐继续遵从用户偏好。

## 计时与奖励

仅知识币，不发能量币。固定时间奖励不参与现有十分钟随机三倍活动；旧活动池与进入锁定协议不变。

| 服务端累计活动用时 | 独立完成奖励 |
|---|---:|
| ≤ 60 秒 | 40 |
| > 60 秒且 ≤ 180 秒 | 30 |
| > 180 秒且 ≤ 300 秒 | 20 |
| > 300 秒 | 10 |

看过参考解的本题，完成后固定 5 币；不看解法的撤销或重置不扣奖。按毫秒判断边界，界面显示分钟与整秒。不倒计时、不结束慢题、不扣币。题目生成后启动计时，每次修改由服务端累计；暂停到继续之间不累计。刷新恢复原题而不重新计时；未成功暂停的离页时间会累计。

## API、保存与恢复

- GET/POST `/api/math/twenty-four`。四格页面使用 new/edit/edit-undo/edit-reset/submit/pause/resume/hint；必须携带 operationId、revision 和当前 gameId。edit 保存经过校验的四格编辑状态，submit 由服务端按优先级生成表达式并核验，不能提交金额或耗时。旧 merge/undo/reset 命令继续兼容旧页面。
- `learning/math/twenty-four-state.json`，外壳 schemaVersion 1、稳定 ID、createdAt/updatedAt，包含当前题、参考解、旧合并过程、四格编辑状态、半配对括号、最多 100 步独立编辑撤销、活动计时、辅助标记、通关历史与最近 200 操作回执。默认位于仓库外 `../data/`，亦支持原有 APP_DATA_DIR。
- 四格编辑状态 version 2，运算符可为 null，仅接收单层配对。存储层仍严格接受旧 version 1；读取时去除冗余括号，无法以相同顺序和单层括号表达的旧编辑器提供空白界面，源状态不在读取时改写。首次编辑或清空时将旧编辑器保留到 legacyEditor，再写入 version 2；旧撤销栈逐步按同样规则恢复。原 board、历史、计时及奖励保留，旧参考解按同一组八张牌重新求单层解。没有新增导入导出格式或更改数据目录。文件不存在是空状态；损坏、非法及未来版本拒绝读取/覆盖。

- 写入串行、临时文件原子替换，目录 0700、文件 0600。完成先落盘待发资格，再调用知识币钱包，最后保存已到账状态；钱包使用永久的局 ID 回执幂等，回执不受交易日志截断影响。
- 知识币文件兼容添加 `twentyFourRewards`（局 UUID → 实际奖励），旧文件缺省为空表；不改变原有余额和其他玩法回执。GET、POST 和启动均尝试恢复待发资格，任一步失败可重试；客户端只在确认入账后更新余额和播放飞币。
- 同一操作重放返回最新状态，操作内容冲突或旧 revision 返回 409；客户端保留待发原操作，阻止新修改，允许重试或恢复最新题目。
- 无独立导入/导出格式。未来备份需同时包含题目存档和知识币钱包，不单独回滚余额或移除回执。
