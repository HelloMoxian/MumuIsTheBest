# 华容道（图片数字滑块）

入口：数学 → 华容道，路由 `/math/sliding-puzzle`。这是图片数字滑块，不是传统曹操华容道。

## 规则与操作

- 行数、列数独立可选 2—6，默认 3×3，共 25 种尺寸。数字从左到右、从上到下为 1 到 行×列−1，右下角为空。
- 点击空格同一行或列的任意格子，将它与空位之间的整段方块向空位移动一格，不跨越交换；其他格子不动。Tab/Enter/Space 同样可操作，方向键选择空位相应方向的邻格，Z 撤销。
- 一次整段滑动记为一步。撤销反向重放整段移动，可一直退回本局打乱后的起点；打乱记录单独保留，不算玩家步数。完成后也可以撤销再思考。
- 开场：整张原图约 1.2 秒 → 等比裁剪并显现分割线约 0.75 秒 → 右下角图块淡出约 0.5 秒 → 50 次、每次约 32ms 的合法移动。打乱不直接逆转上一步，末盘必须未完成，因来自已解盘所以一定可解。50 次不意味着数学上的均匀随机或最短解距离。
- 后台与设置弹窗暂停开场；可跳过演示。减弱动效偏好直接进入已经完成全部 50 步打乱的棋盘。玩家移动使用 180ms 平滑位移，避免快速点击覆盖正在进行的位移。
- 完成补回右下角图块，显示“拼好啦”与 行×列×3 分。分数仅为本局分数，未新增知识币或能量币账本；不在局中展示奖励规则，音效默认关闭，顶栏可主动开启；打乱和有效移动使用轻滑动声，撤销用回退声，完成用清亮提示声。复用 GemAudio 本机采样、55ms 节流与有界声源；音量为 35%，只控制本页音效，不修改背景音乐设置。隐藏、配置弹窗、进度冲突、麦克风占用和离页停止音效；异常不阻塞棋盘。

## 图片与界面

- 通关演出：最后一步先落定 240ms → 格子轻亮两次（共 1.2 秒）→ 格子与外沿光晕呼吸三次（共 2.4 秒）→ 900ms 淡入右下角、淡出数字与分割线。全程保留原方块及原图片裁剪，不另换一张整图，不缩放或平移棋盘；最后得到的完整图片就是玩家拼好的原方块。
- 工作区使用固定的可收缩网格行，庆祝得分放在始终占位的 80px 状态栏；参考图不再插入会改变高度的结算卡片。胜利时视口边缘出现青紫光晕与短暂星屑，覆盖层不占布局、不拦截操作，窗口与全屏均可看到完整作品。
- 撤销、新局与重新读取取消旧庆祝；后台或弹窗暂停阶段计时及呼吸动效。恢复已完成的缓存直接显示完整作品；减弱动效时直接显示静态整图、光晕与祝贺。保存结果不依赖动画结束，演出不更改分数或重复奖励。

- 图片专用目录：`apps/web/public/images/sliding-puzzle/`；目录清单：`apps/web/src/features/sliding-puzzle/pictures.ts`，共 23 张本机副本，原图不移动、不修改。
- 来源：空间站、加减数字星球；红色要塞的主视觉及城堡/熔岩/冰雪/森林；物质塔背景；宝石迷阵圣殿；连连看水晶花园；猫鼠图库的四个室内与四个室外场景；数独的五个主题背景。添加图片时同时更新专用目录与清单。
- 普通新局随机选图，选图弹窗可指定或随机；设置尺寸后新开一局。替换未完成局在原生弹窗中明确告知，取消保留原局。
- 以 列/行 为裁剪比例，随机选择多余宽度或高度上的裁剪位置；以 object-fit: cover 保持源图比例，整盘小图与参考图复用同一裁剪参数。开头先用 contain 展示未经裁剪的源图。
- 右侧完整参考图没有常驻数字遮挡。鼠标停留或键盘可见聚焦时，原图对应区域持续微亮；离开后恢复，不循环闪烁。鼠标与键盘的不同目标可同时高亮。移动端参考图位于棋盘下方。
- 复用 GameTopBar 与 useGameFullscreen；隐藏本玩法不需要的全局数字键盘。全屏保留全部核心操作，浏览器拒绝原生全屏时降级到窗口内沉浸。

## 缓存合同

按本次需求使用浏览器 localStorage 键 `mumu:sliding-puzzle:v1`，不写服务端个人数据目录，不访问真实学习记录。

载荷 schemaVersion=1：本局 UUID、createdAt、updatedAt、rows、cols、imageId、cropX、cropY、cells、shuffle、history、completedAt。新局 shuffle 恰好 50 条；读取同时兼容旧版 200 条轨迹，不截断、不重新打乱旧盘，history 是尚未撤销的玩家操作；每条包含点击格 from 与原空位 empty。保存当前撤销分支的所有步骤，不截断历史。撤销后的废弃分支不用于恢复。

新局先保存完整打乱后的棋盘，再播放演示；因此开场刷新也能直接续玩。每次有效移动和撤销同步保存整个载荷，写入错误保留内存状态与旧缓存，并提供重试及离页提示。多页面更新检测到冲突时停止编辑，重新读取后继续。

读取时校验尺寸、图片 ID、时间、裁剪值，并从有序棋盘完整重放打乱与玩家历史，核对当前棋盘。空缓存新建；损坏与未知版本拒绝自动覆盖，仅用户明确开始新局时替换。首版无历史版本迁移；未来版本必须显式升级解析与迁移。清除浏览器站点数据会清除本玩法缓存，不属于服务端数据备份范围。

## 必要校验

引擎测试覆盖行列整段滑动、非法移动、25 种尺寸合法打乱与反向复原、多步撤销、完成再撤销、持久化重放、空/损坏/未来版本、写入失败与冲突。UI 遵守设计系统；没有计时压力、在线图片依赖或麦克风需求。
