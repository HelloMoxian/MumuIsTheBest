# 物质守恒玩法规范

## 1. 学习目标

“物质守恒”通过化学方程式配平帮助木木理解：

- 化学反应中原子会重新组合，但每种元素的原子总数不变；
- 化学式前的系数表示物质之间的相对数量；
- 配平只能修改化学式前的系数，不能修改化学式右下角的数字；
- 标准配平结果使用最简正整数比。

平衡方程式中，箭头左右同一元素的原子数必须相等。这一语义参照 [OpenStax Chemistry 2e：Writing and Balancing Chemical Equations](https://openstax.org/books/chemistry-2e/pages/4-1-writing-and-balancing-chemical-equations) 与 [IUPAC Gold Book：chemical reaction equation](https://goldbook.iupac.org/terms/view/C01034/pdf)。

## 2. 资料库

资料库位于 `apps/web/src/features/conservation/reaction-library.ts`，当前包含 165 条不重复常见反应，覆盖：

- 化合与分解；
- 金属、卤素置换；
- 沉淀、放气和复分解；
- 酸碱中和与氧化物和酸的反应；
- 烃、醇、硫化物等燃烧；
- 工业冶金、电解、烟气净化和电池总反应；
- 光合作用、呼吸、发酵等生命与环境过程；
- 少量适合观察较大系数或括号化学式的进阶反应。

每条记录必须提供：

- 稳定唯一 ID；
- 最简正整数系数和未改变的化学式；
- 中文反应名、现实用途或科学情景；
- 条件标签、可观察现象和反应类别；
- 启航、探索或挑战难度。

危险、剧烈或有毒物质相关记录只能用于虚拟认识。文案不得提供可操作的用量、温度、浓度、装置或家庭实验步骤。

## 3. 自动守恒校验

核心逻辑位于 `apps/web/src/features/conservation/logic.ts`：

1. 解析箭头两边的每个化学式及前置整数系数；
2. 复用反应熔炉分子式解析器，支持上下标、括号、方括号和结晶水；
3. 将每个化学式中的原子数乘以前置系数；
4. 分别累计反应物和生成物中的每一种元素；
5. 拒绝左右不守恒、系数非正整数或系数仍有公因数的数据。

页面检查孩子输入时区分四种状态：

- `incomplete`：仍有系数槽未填写；
- `unbalanced`：指出一个左右差异最明显的元素；
- `proportional`：左右已经守恒，但整组系数仍可约分；
- `balanced`：守恒且为最简正整数比。

## 4. 随机与难度

- 每局可选 5、10 或 20 道题。
- 每局从资料库随机无重复抽取；中途“换一道”也不会选择本局已经出现的反应。
- 启航：系统给出大部分数字，只留 1—2 个系数槽。
- 探索：只保留少量已知系数，大部分由孩子填写。
- 挑战：所有系数槽都由孩子完成，并优先从非启航反应中抽取。
- 每道题开始时选中第一个可编辑槽；数字控制台提供 `1—15`，键盘 `1—9` 可作为常用系数的快捷输入。

## 5. 反馈与结果

- 当前系数会实时驱动“元素天平”，逐项显示 `左 n / 右 n`。
- 未配平时不清空、不扣分，只提示先观察一个元素。
- “给我一个提示”每次只填写一个不正确或未填写的系数。
- 配平成功后才进入反应动画；动画完成后可进入下一题。
- 结果页显示每道标准方程式、用时以及“独立完成 / 提示后完成”，不显示失败、扣分或排名。
- 中途刷新不会保存成绩；当前模块不写入个人数据或历史文件。

## 6. 实时动画

成功动画使用 Canvas 逐帧绘制：

1. 反应物结构从左侧漂入中央能量核心；
2. 中央轨道旋转并产生短暂的局部光芒；
3. 反应物淡出、生成物结构展开到右侧；
4. 底部显示“每一种原子都守恒”并锁定天平。

动画只表达“原子重新组合”，不声称还原真实反应机理、空间结构、能量曲线或反应速率。启用 `prefers-reduced-motion` 时，过程缩短为静态淡入和守恒确认。

## 7. 维护与测试

新增反应必须通过 `logic.test.ts` 的资料库自检：

- 至少 150 条、ID 和标准方程式不重复；
- 每条方程式元素守恒；
- 所有系数为最简正整数比；
- 所有元素符号属于正式周期表；
- 中文描述、条件和现象不为空；
- 随机抽题、三个难度、比例可约分和单步提示保持可测试。
