# 找数字玩法规范

状态：**已实现**

入口：`/math/find-number`

## 1. 学习目标

“找数字”通过连续比较训练数感、范围意识和二分查找直觉。孩子不需要打字，可以直接问：

- “是 500 吗？”
- “小于 800 吗？”
- “大于 300 吗？”

系统明确回答目标数字与提问数字的关系，并在持续存在的数轴上冻结不可能的区段。玩法不使用倒计时、步数排名、扣分或失败文案。

## 2. 数字范围与随机

可选范围：

- `0—100`
- `0—1,000`
- `0—10,000`
- `0—100,000`

起点和终点都属于候选范围，例如 `0—100` 一共有 101 个整数。目标使用均匀随机整数生成，必须允许随机到 0 和范围终点。

当前版本不保存个人数据或跨局历史。

## 3. 比较语义

支持五类问句：

| 问句 | 目标成立时保留 | 目标不成立时保留 |
|---|---|---|
| 是 `n` 吗 | 命中即通关；否则根据目标大小保留一侧 | 同左 |
| 小于 `n` 吗 | `… n-1` | `n …` |
| 大于 `n` 吗 | `n+1 …` | `… n` |
| 不超过 `n` 吗 | `… n` | `n+1 …` |
| 至少是 `n` 吗 | `n …` | `… n-1` |

所有区间均为闭区间。每次计算必须保证目标仍位于新的候选区，不允许出现差一位错误。

重复提问或候选区外提问仍进入记录，但本次新排除数量为 0，并显示“这次没有新排除”的温和提示。

只有“是 `n` 吗”且 `n` 等于目标时算作找到数字。范围收缩到一个候选数时仍鼓励孩子再说一次精确答案完成锁定。

## 4. 大数语音解析

- 支持阿拉伯数字、全角数字和中文数字。
- 中文数字覆盖零至十万，包括 `十二`、`一十二`、`两千零五`、`一万零五百`、`三万四千五百六十七` 和 `十万`。
- 纯中文数字序列可以按位识别，例如 `一二三` 识别为 123。
- 语音命令支持“开始一局 / 开始游戏”“结束一局 / 结束游戏”“下一局 / 再来一局 / 重新开始”，并兼容 `start / end / next / restart`。
- 只消费 ASR 最终句，避免增量识别把“八”过早消费成问题，而完整句实际是“八百”。

## 5. ASR 生命周期

- 页面进入后若本机已经配置 Key，在开始页监听“开始一局”。
- 游戏进行中持续监听比较问句、“结束一局”和“下一局”。
- 通关或主动结束后重新监听“下一局”。
- 每一段识别仍由服务端强制限制为 2 分钟。到时保留目标、候选区、计时和全部记录，并显示“继续识别”按钮。
- 语音不可用时，页面保留关系选择、数字输入和“问一问”按钮，核心玩法不会被阻断。

## 6. 数轴与动画

- 开局及候选跨度大于完整范围约 `18%` 时显示全范围数轴；候选跨度达到该阈值后自动切换到局部数轴。
- 局部视窗在候选区两侧保留上下文，最小跨度为 12，并在约 `620ms` 内平滑聚焦；画面必须显示“局部放大”，刻度按当前视窗重新选择清晰的整数间隔。
- 候选区使用青—紫—粉发光带并显示左右端点、剩余数量。
- 已排除区使用灰色星尘冻结带、斜纹和裂纹，不只靠颜色表达。
- 本次新排除区在约 850ms 内播放扫描暗化和少量星屑消散；旧淘汰区保持稳定。
- 进行中不显示候选中点、预计剩余提问次数或一键推荐问题，数字输入框也不自动填入中点。
- 通关后先在原猜题页面保留约 `1.25s` 的连接动画：目标位置显示黄色光点与少量星屑，大号目标数字从数轴原位弹起，再通过共享数字过渡进入结果页。
- `prefers-reduced-motion` 下直接切换最终状态，不播放扫描、星屑、漂浮和脉冲。

## 7. 过程记录与结果

每条记录包含：

- 提问顺序和可见问句；
- 系统关系回答；
- 提问时刻；
- 本次新排除数量；
- 累计排除数量；
- 当前剩余数量。

精确命中后结果页显示目标数字、提问次数、总耗时、完整提问过程和每次排除数量。结果页数字使用落地回弹和分阶段内容淡入承接数轴动画，不能整页瞬间跳出。主动结束时温和揭晓目标，但不得写成通关。

两种结果均提供“下一局”“换一个范围”和“回到学习大厅”。

## 8. 测试要求

- 中文数字零至十万必须覆盖代表性样例和非法输入。
- 五类比较必须覆盖等号边界，严格区分 `< / > / ≤ / ≥`。
- 0 和范围终点必须可随机生成。
- 长比较序列中目标必须始终位于候选区。
- 重复及范围外问题不得错误缩小候选区。
- `801—819 / 0—1,000` 等小候选区必须进入局部视窗且两端保留可读间距；靠近 0 和范围终点时视窗不得越界。
- 合并前运行全量测试、前后端 TypeScript 检查和生产构建。
