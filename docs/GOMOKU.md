# 五子棋

入口：游戏大厅 → 五子棋，路径 `/games/gomoku`。

- 双人共用一台设备，15×15 交叉点，黑方先手，每次一子，不可覆盖。
- 使用休闲无禁手规则：横、竖、两种斜线连续五颗或更多即获胜；不采用职业连珠的禁手、交换开局规则。满盘无胜者为平局。
- 鼠标/触摸直接选择交叉点；棋盘聚焦后方向键或 WASD 移动，空格/Enter 落子。确认键长按不重复落子。
- 手柄复用全站导航：选中棋盘按 A 进入操控，十字键/左摇杆移动，A 落子，B 退出操控后可选择顶栏与下一局；按下左摇杆切换全屏。遵从全站自定义绑定，任意已连接手柄可轮流操作。
- 大号黑白待落子随光标吸附并慢闪，顶部同步显示轮次；占用点的待落子偏移且给出文字说明。最后一子有青色中心点。
- 开局网格逐线展开，黑白棋子入场并显示“黑方先手”；约 2.1 秒结束，首次落子立即收起，不锁输入。获胜时连线绘制、五子逐一弹亮和扩散环、两侧星屑及桂冠文字庆祝，随后保留慢闪。下一局直接黑先；进行中重新开局通过原生模态确认。
- 落子声为本机合成的棋子撞击木质棋盘：短噪声接触与固定频率快速衰减共鸣，去掉电子滑音与获胜高音旋律。
- 顶栏“月下琴声 / 竹影轻弦 / 云海长音 / 关闭”提供三种原创低音量、无鼓点的舒缓配乐，首次操作后播放。进入时遵从全站已保存的音乐关闭偏好；本页切换只在当前页面生效，不改全站设置。五子棋屏蔽全站音乐与其浮钮，关闭配乐不会恢复喧闹音乐。
- 落子音效默认开启，顶栏独立开关。后台、失焦、麦克风或朗读占用时暂停本页声音，离页清理；音频不可用不影响棋局。
- 全屏沿用通用 hook，原生失败降级窗口专注。横向全屏将轮次/下一局与工具分放两侧，棋盘上下只留 8px，取消最大尺寸限制；竖屏尽量用满宽度。窄屏保留大号移动/落子按钮。减弱动态效果关闭开场装饰、星屑、闪烁与位移，保留静态胜利标记。
- 当前局只在页面内存中保留，刷新/离页后重新开始；没有个人数据、服务器 API、奖励、迁移或外部资源请求。大厅插图为本机 SVG。

实现：`apps/web/src/features/gomoku/`。轻量规则测试覆盖交替、非法落子、四向胜利、白方胜利、长连、边界、平局及结束锁定。
