# 数学玩法：乘法小能手

状态：已实现

入口：`/math/multiplication`

## 玩法目标

乘法小能手复用算数大战的并行语音挑战方式：1—5 道题纵向同时出现，木木可以自由决定计算顺序；说出“等于 + 答案”后，唯一匹配的题目被点亮。

同一局必须保证算式不重复、答案互不相同。只有全部题目完成才结算为 100 分并保存历史；未完成不生成成绩，也不使用“答错”“失败”或扣分表述。

## 难度规则

### 0—10 乘法

- 两个乘数均为 0—10 的整数。
- 同一乘法事实允许以不同顺序出现，例如 `7 × 8` 和 `8 × 7` 都是合法题目。
- 同一局不会同时出现答案相同的两个算式，因此上述两个顺序不会在同一局同时出现。
- 结果范围为 0—100。

### 逆向除法

- 题目由 0—10 乘法事实逆向生成，例如 `56 ÷ 7 = 8`。
- 被除数为两个 0—10 整数的乘积，范围为 0—100。
- 除数为 1—10，绝不出现除以 0；商为 0—10。
- 所有题目都能整除，不出现余数或小数。

### 进阶乘除

- 每题随机为乘法或除法，同一局尽量混合两种运算。
- 乘法的两个乘数均为 0—20，结果为 0—400。
- 除法的被除数为 0—100，除数为 1—20，商为 0—20。
- 除法必须整除，绝不出现除以 0、余数或小数。

## 并行挑战与语音

- 题目数量可选 1、2、3、4、5；每题独占一行，不使用多列题目卡。
- 正确答案每 200ms 检测一次并立即点亮。
- 未匹配任何未完成题目的结果等待 2 秒确认，再显示“这个结果不是任何一个题的答案，请再算算”，语音识别持续运行。
- 每段 ASR 严格限制为最多 2 分钟；一局最多顺序开启 5 段，共最多 10 分钟语音识别时间。
- 段与段之间保留题目和完成进度；第 5 段结束仍未完成时结束本局且不保存成绩。

## 计时和历史

- 第一题耗时为开局到第一个正确答案的间隔。
- 后续题目耗时为上一个正确答案到本题正确答案的间隔。
- 计算时间为开局到最后一题完成的总间隔；单题平均耗时为计算时间除以题目数。
- 历史面板按“题目数量 + 难度”聚合局数、平均总耗时、单题平均耗时、平均计算时间、木木年龄和正确率。

完整成绩保存到：

```text
var/learning/math/multiplication-history.json
```

若设置了 `APP_DATA_DIR`，则写入该目录下同样的相对路径。文件必须经过 schema 与业务规则校验，并使用临时文件 + 原子替换写入；它被 Git 忽略，不记录音频、识别原文或未匹配的语音结果。
