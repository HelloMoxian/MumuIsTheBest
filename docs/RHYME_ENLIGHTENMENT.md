# 声律启蒙精读舱

状态：**全书原文与前五章精注已实现**

## 目标

“声律启蒙”不是只供背诵的全文播放器。孩子点击每一个小句后，应当同时知道：

1. 这句话在说什么；
2. 不熟悉的词是什么意思、怎样读；
3. 两边为什么能放在一起；
4. 里面是否藏有历史故事、神话或古代生活知识。

当前页面路由为 `/classics/rhyme-enlightenment`。首页新增“国学”一级学科入口。

## 句子内容结构

内容定义位于 `apps/web/src/features/rhyme-enlightenment/content.ts`。每个点击句必须包含：

- `text`：校对后的简体原文；
- `pinyin`：带声调的整句普通话拼音；
- `meaning`：一段儿童可理解的画面或意思；
- `terms`：至少一组真正需要解释的对面词，包含词、拼音和含义；数组必须为偶数，按“左词、右词”连续存放，页面以“左词 对 右词”成组展示；
- `pairing`：只用具体事物解释“为什么这样对”；
- `storyTitle`、`story`：典故、古代生活背景，或明确说明没有专门典故。

不得在儿童讲解中加入平仄、词性、格律名词、古音争论或术语表格。这些内容若未来需要提供，只能进入独立的家长/教师扩展层，不能混入当前四层讲解。

## 儿童解释规则

### 先解释画面，再解释知识

优先让孩子看见、听见或想象句中画面。例如“半溪流水绿，千树落花红”先解释溪水、落花和颜色，再说两边怎样照应。

### 对子原因只讲具体关系

允许的表达包括：

- 都是天气、花木、鸟兽、建筑或人物；
- 一个来、一个去；
- 一个在天上、一个在人间；
- 一个写颜色、一个写声音；
- 两边来自不同季节、时间或地点。

不要写“偏正结构”“名词性中心词”“仄仄对平平”等分析。

### 不强行制造典故

- 有可靠典故：用不超过两段的儿童口语讲清人物、行动和这句为何借用它。
- 只有古代生活知识：讲器物、称呼、地理或习俗。
- 没有专门典故：明确写“这句没有专门故事”，转而引导观察画面。
- 存在多种说法：写“常见注本多解释为……”，不得把争议说成唯一事实。

### 处理古代语境

- 性别刻板印象：说明这是古人的表达习惯，不限制今天的女孩和男孩。
- 战争与兵器：用于理解历史词语，不鼓励攻击或模仿。
- 饮酒：只说明古代人物和文学语境，明确儿童不能尝试。
- 危险环境：如“玩水”，补充现实中需要大人陪伴，但不要打断主解释。
- 生僻审美和妆饰：说明其时代背景，不把它包装成今天必须遵守的标准。

## 朗读协议

- 必须复用 `apps/web/src/shared/speech/`，业务页面不自行创建 `SpeechSynthesisUtterance`。
- 声音不会在进入页面时自动播放。点击句子或“从头朗读本章”才开始。
- 模式一“只读原文”：每个点击单位只朗读 `text`。
- 模式二“原文和讲解”：依次朗读原文、意思、词语小卡、对子原因和故事。
- 全文朗读严格按页面句序逐句调用通用服务，并同步高亮当前句。
- 暂停、继续、停止必须可见；切换句子、章节、朗读模式或离页时立即取消旧朗读令牌，旧队列不得继续。
- 页面文字永远保留。声音不可用或出错时，只显示温和提示，不影响阅读和切章。

- 桌面端左侧原文、右侧讲解，两栏独立滚动；移动端改为上下排列。
- 原文句子是大尺寸按钮，正文至少 22px、拼音至少 16px、触控高度至少 64px。
