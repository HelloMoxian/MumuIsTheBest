# 英语回声岛

状态：**正式实现**

## 1. 目标与内容

英语回声岛是面向约五岁儿童的逐句听力玩法。核心体验固定为“先只听英文 → 再揭晓并听中文 → 完成并进入下一句”，让孩子把英文声音与中文意思建立稳定映射。

- 正式目录：[`content/english/echo-island.v1.json`](../content/english/echo-island.v1.json)
- 离线音频包：`content/english/echo-island-audio.v1.tar`
- 来源与使用边界：[`content/english/README.md`](../content/english/README.md)
- 句库固定包含 1000 条完整表达；每句都有美式英文和简体中文真人 MP3。
- 原始 MP3 不转码，以未压缩 USTAR 目录项 `en/NNNN.mp3`、`zh/NNNN.mp3` 保存。服务端按目录项返回音频并支持 HTTP Range。
- 这批来源内容只用于用户的个人非商业学习，不得默认上传、公开发布或用于商业分发。

## 2. 单句三步协议

每个句子的正常流程只有一个大号主按钮：

1. `播放英文`：播放当前英文 MP3。播放期间主按钮、返回与句子清单入口锁定，不能跳过或重复开始。
2. `显示中文并播放`：英文自然结束后才可点击；点击后立即揭示中文并播放中文 MP3。播放期间同样锁定。
3. `下一句 · 收下知识币`：中文自然结束后才可点击；服务端成功记录次数并确认知识币入账后，才选择和显示下一句。

音频加载失败不推进阶段、不增加次数、不发知识币；保留原文和重试按钮。离页时必须停止当前音频。固定课程录音不使用浏览器 TTS 降级，避免重新引入机械感；页面首次操作也通过 `data-skip-startup-greeting` 排除全局问候，防止两个声音重叠。

### 2.1 返回上一句

- 页面会在本次打开期间保留最近 100 条已经完成并进入下一句的句子历史；首次进入、刷新后没有上一句时，“返回上一句”保持可见但禁用。
- 点击“返回上一句”只切换当前句子，并统一回到“播放英文”步骤；不会自动发声，也不会撤销此前已经保存的练习次数或知识币。当前句尚未完成的英文或中文步骤不会被记录或奖励。
- 返回后重新完成“英文 → 中文 → 下一句”属于一次新的完整练习，继续使用新的幂等事件 ID，并按普通手动奖励规则结算。
- 真人录音播放、完成保存或连续自动播放期间按钮禁用。需要先停止连续播放，等待当前录音自然结束后再返回，不能以回退操作截断录音、跳过保存或制造叠播。

### 2.2 连续自动播放

- 孩子主动点击“连续自动播放”后，页面从当前可执行步骤开始，自动串联英文录音、中文揭示与录音、完成保存和下一句英文；不自动播放背景音乐，也不允许两个录音重叠。
- “停止连续播放”不会粗暴截断正在说话的真人录音；当前录音自然结束后停在下一可执行步骤。离页仍立即停止声音。
- 自动播放遇到音频或保存错误时停在可重试步骤，不能跳过错误句。知识币额度用完不是错误，不得停止或等待播放。
- 页面在连续播放期间锁定返回、句库和手动三步按钮，保留始终可见的停止按钮以及额度到顶后的“继续获取知识币”按钮。

## 3. 练习次数与句子状态

- “练习次数”指完成一整次“英文 + 中文 + 下一句”循环，不是播放按钮点击数。
- 全部句子清单中的独立英文试听不增加练习次数，也不发知识币。
- `completionCount >= 50` 表示“已学会”，但后续温习仍会继续增加次数。
- 完成记录带 UUID 事件 ID；同一事件重试不会重复增加次数。
- 清空操作只清空全部句子的练习次数、复习计数和完成事件记录，保留当前标记池。清空必须二次点击确认。

## 4. 二十句学习池与复习

- 首次打开时，服务端从 1000 句中随机选择 20 句作为标记池。
- 普通学习只从标记池中随机选句；池内有多个候选时避免与上一句立即重复。
- 标记池中的句子完成第 50 次后立即毕业并移出；服务端从未标记句子中选取当前练习次数最低的一句补入。最低次数并列时随机选择。
- 每完成 5 个普通学习句，下一句优先从已学会且当前未标记的句子中随机选择一条温习。若尚无已学会候选，则继续学习当前标记池，并在候选出现后安排温习。
- 完成温习后，普通学习计数重新从 0 开始。
- 家长可以在全部句子清单中手动取消或添加标记。添加时若已有 20 句，服务端自动替换当前池中练习次数最高的一句；取消最后一条时自动补入一条最低次数句，保证玩法始终可继续。

## 5. 知识币与五倍暴击

- 每次完整循环的基础奖励是 1 个知识币。
- 15% 概率触发固定五倍暴击，奖励总数是 5 个，不是 1 + 5。
- 暴击由服务端在知识币写入事务中抽取，浏览器不能传入或决定结果；奖励事件使用同一 UUID 保证幂等。
- 连续播放按服务端识别的批次累计真实入账，每批最多 20 个知识币。若五倍奖励会越过上限，本次只入账剩余额度；达到 20 后，每句仍正常播放并记录练习次数，但奖励事务按同一完成事件幂等记录为 0。
- 达到上限后页面显示 `本轮已获得 20 / 20` 和“继续获取知识币”。点击只创建下一批 20 枚额度，不暂停、重播或跳过当时正在播放的录音；未点击时连续播放无限继续且不再发币。停止再开启不会绕过当前批次额度。
- 英语回声岛不参加全局每十分钟数学玩法三倍轮换，避免三倍与五倍规则叠加。
- 服务端确认入账后，通用知识币层飞出与实际奖励相同数量的币；五倍时页面额外显示不超过约 2.4 秒的“知识币暴击”星形框。文字使用真实 HTML，美术只作为透明装饰。
- `prefers-reduced-motion` 下关闭位移、旋转和弹跳，只保留短暂显隐与准确的 `+5 知识币` 文字。

## 6. 全部句子清单

右上角“全部句子”打开覆盖式家长清单，包含：

- 英文、中文、练习次数；
- 当前学习池与已学会文字状态；
- 英文真人录音试听；
- 全部 / 学习池 / 已学会筛选与中英文搜索；
- 加入或移出学习池；
- 二次确认的全部次数清空。

清单试听时同一时间只允许一个音频实例。关闭清单立即停止试听。选中不能只靠颜色，必须同时提供对号、文字和边框。

## 7. 数据与安全

个人进度默认写入：

```text
../data/learning/english/echo-island-progress.json
```

使用 `APP_DATA_DIR` 时写到对应绝对目录。文件包含 `schemaVersion`、稳定 UUID、创建/更新时间、标记句子 ID、普通练习计数、总完成数、幂等事件 ID 和稀疏句子次数记录。服务端使用单写入队列、临时文件 + 原子替换、0700 目录和 0600 文件权限。

目录与音频属于可版本控制的产品资产；个人次数与标记只属于运行时个人数据，不得写回 `content/`、`src/` 或 `public/`。
