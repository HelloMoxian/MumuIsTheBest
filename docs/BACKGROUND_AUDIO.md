# 全站背景音乐与宝石音效

全站由 GlobalMusicLayer 挂载唯一音乐播放器，右下角“背景音乐”打开原生对话框，提供晶光漫步、星云漫游、阳光航线三首曲目及独立音乐/宝石音效开关和音量。选择随本机服务保存，所有功能页恢复同一偏好。

按用户明确要求，首次默认开启音乐（18%）和宝石音效（55%）。每页恢复设置后尝试自动播放；浏览器拒绝时显示“点击后播放”，真实指针或键盘操作后重试。关闭音乐或设为 0 后不再自动重开。切曲自动开启所选音乐，歌曲循环播放；跨页面重载从所选曲目开头播放，不保存播放秒数。无外部运行时音频请求。

## 存储

复用 /api/persistent-data/audio-preferences，服务端文件为仓库外 ../data/preferences/audio.json（APP_DATA_DIR 可覆盖数据根路径）。外层沿用 schemaVersion 1、UUID、stableId、创建及更新时间；payload schemaVersion 1 包含 musicEnabled、track、musicVolume、effectsEnabled、effectsVolume。仅接受三种曲目 ID、布尔开关和 0—1 有限音量，拒绝未知字段或未来版本。

文件缺失使用默认值，首次改变设置时创建文件；旧版本没有此文件，无需迁移其他玩法或语言偏好。沿用持久化层单写队列、临时文件和原子替换。恢复失败不覆盖原记录；写入失败保留本页选择并显示重试，直到确认前不宣称已保存。未来备份应包含 preferences/audio.json；音乐文件和目录不包含运行时个人数据。当前多标签按最后成功写入为准，已打开页面在重新进入时恢复最新设置。

## 声音协调

- 页面隐藏/pagehide 暂停音乐；重新可见后遵从音乐选择恢复，离页释放播放器。快速切歌、暂停或离页时，迟到的播放回执不能恢复旧音乐。
- 通用 browserTts 和双语学习朗读期间音乐降至原音量 18%；共享 ASR 会话及首页麦克风调试期间暂停背景音乐，结束后恢复。不修改 ASR 服务协议或 10 分钟上限。
- audioFocus 通过明确的引用持有协调麦克风，以及通知已有俄罗斯方块/星际极速赛/赤色要塞的配乐让出声音；原游戏操作音效仍受其原有开关控制。全站背景音乐播放时不叠播旧配乐。
- 音频异常不抛到玩法，也不影响保存、分数、奖励或视觉动画。默认设置按这次用户要求覆盖旧版“音频默认关闭”，孩子或家长可以随时关闭。

## 宝石迷阵

九个本地 PCM WAV 样本对应选中、交换、回退、普通消除、连锁、火焰、星形/新星、超能、下落落地。指针按下和键盘操作先解锁音频设备，交换与消除在对应动画帧开始播放，落地在下落动画完成时播放；不同特殊类型按本轮实际 blast 数据判断。相同音效 55ms 节流、最多 8 个同时发声源；连锁音调逐轮增加，上限 1.5 倍。

暂停、隐藏、说明/换局弹窗、麦克风或静音会停止当前音效；资源晚到不补播过期动作。无有效交换时只播放交换与回退，服务端失败/重复结算不伪造成功音。减弱动效下仍给一次消除声，音量独立控制。前台音乐在游戏手动暂停时可继续作为环境音乐，音效停止。

## 素材与验证

音乐与音效来源、处理参数和 SHA-256 见 assets/audio/global/manifest.json 与 CREDITS.md。scripts/prepare-background-audio.mjs 从保留的原始文件生成运行时音频，需要 ffmpeg，仅用于开发阶段。

自动测试覆盖自动播放拦截、换曲、音量、静音、后台与麦克风避让、异步竞态、资源失败、音效节流及清理、文件恢复和非法版本/输入/存储错误；所有存储测试使用临时目录。音频摘要、WAV 样本和幅值均做校验。

### 宝石消除英中鼓励

16 段完整英中 MP3 已预生成并随工程提供，目录为 `public/audio/bejeweled/praise/`，文案源为 `content/bejeweled/praise.v1.json`。消除时按普通匹配、连锁与特殊宝石选择；复用共享学习语音播放器及单个等待位的队列，完整播完当前段再播最新等待段。独立“鼓励语音”开关控制本页；暂停保留位置，关闭或离页清空队列。预生成语音无需运行时联网；失败仍由统一浏览器文字朗读降级。音乐沿用语音避让机制。详见 `BEJEWELED.md`。
