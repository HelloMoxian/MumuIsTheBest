# 自然地图正式功能

## 气候多选与专题呈现（2026-09-30）

- 气候提供「常见类型 / 冷暖 / 干湿季节」三种交叉观察视角。同一份 Köppen 分类代码共享选择集合，切换视角不清空；分组与始终展开的子项联动，部分选中用原生 indeterminate 表达。例如「沙漠」包括 BWh 与 BWk，「半干旱草原」包括 BSh 与 BSk。组内取消只影响该组；没有勾选时显示全部，有勾选时所选类型鲜明显示，其余作为暗色参照。地图点选同样切换对应类型。分类是气候观察，不等同于实测植被边界。
- 新接口 `/api/nature/maps/world/climatev2` 使用独立公开缓存 `cache/nature-maps/climate.json.gz`，不改旧世界包或个人存档。来源仍为 Beck 等（2018）的 1980–2016 present，不混入未来预测；从 0.5° 升级至 1/12°（约 0.0833°，赤道约 9 千米），每轴 6 倍细化，包含 30 类。相邻同类格网合并为矢量多边形并保留孔洞，极区裁至 ±85°，只去除共线冗点，不平滑生成虚构细节。不能称为 1 千米成品。
- 安装：`uv run --with shapely==2.1.2 --with numpy==2.2.6 --with pillow==11.3.0 python scripts/install-nature-climate.py`。只有安装时联网，来源固定为 Figshare 12407516，源 TIFF 为 `Beck_KG_V1_present_0p083.tif`；包中保存下载内容 SHA-256、来源文件、时间及署名。构建依赖不进入产品运行时。包采用 schemaVersion=1、id=climate-v1，完整转换和校验后临时文件+原子替换；旧版/损坏包不覆盖，临时文件冲突时停止。缺失、损坏、未来版本和空集合返回可重试错误，不悄悄退回粗数据。
- 世界专题颜色提高饱和度和不透明度，图例复用同一颜色表。选中/勾选区域用明亮青色边线与透明覆盖层缓慢呼吸（3.6 秒），不改原分类色；后台停播，减少动态效果时使用静态高亮，卸载/切换清理计时器。动画不重复创建地名标签。
- 海洋颜色使用统一中文海域名决定；同名太平洋、大西洋的南北块同时选中，保留原始几何。海域拼接边线及抗锯齿缝关闭，海岸轮廓继续保留；选中海域用统一覆盖层呼吸，不画穿过赤道的选中边线。
- 移除地图操作说明、装饰标题图、山脉和关口按钮前的重复提示；保留操作名称、图例、所选资料、加载/错误/重试。精度、统计含义及来源集中到默认折叠资料区。矿点显示开关只保留加载或数量反馈，不重复说明按钮作用。
- 资料依据：[Beck 分类定义表](https://www.nature.com/articles/sdata2018214/tables/1)、[数据集](https://doi.org/10.6084/m9.figshare.6396959)，CC BY 4.0。分组为本工程教学整理，源分类不变。

- 数据是研究用的山地范围而非精确山脊线或行政边界；保留跨境山脉自然延伸，不用矩形裁成“中国国界”。仅为减小本机包体，将原始矢量以 0.001° 容差保拓扑简化；这一数值不是测量精度。中国地图的行政层级、政治标注和个人记录不变。

## 精细海拔地形（2026-09-30）

- 地形视图在地形和阴影上方叠加陆地轮廓：深色外衬、浅青色细线，使用已有 land 几何的海岸线，不添加国家行政分界；海拔、山脉和海洋地形视图可见，其他专题隐藏。

- 海拔图新增山峰与关口标记开关；关闭后清空地图点数据并隐藏聚合圆、单点、名称、海拔和地点浮层，缩放仍保持关闭，侧栏搜索/定位继续可用。状态保留在本次页面内，切换世界图层不重置；不写个人存档。
- 名称下显示带单位的海拔，18px 浅底衬字。地形设色与高度文字统一采用 0/1000/2000/3000/5000/7000/8900 米对应绿/蓝/黄/橙/棕红/紫/黑七节点，按每段实际米数线性 RGB 插值（不是七色等距排列）；文字低于 0 / 高于 8900 只钳制颜色、不修改数值。DEM 海面以下保留独立蓝色，0 米陆地从绿色开始；图例渐变按米数比例设置停点，并以可换行的七项色标呈现数值。未知数据不填零，历史包的零值只有明确“海拔 0 米”时才显示。自然地名库高度与 DEM 网格是不同来源，不能混同。
- 原底图为 Natural Earth HYP_50M_SR 的 4096×4096 Web Mercator 图片。新增 Mapzen / Tilezen Terrarium 数字高程瓦片，浏览器用 MapLibre `color-relief` 分层设色与 `hillshade` 绘制，不是照片放大、生成式地形或新增测量。未安装/损坏时保留旧图，增强饱和度与对比度；海洋主题仍用原来的陆地遮罩与清晰海域色块，不受新 DEM 影响。
- 安装包包含全球 z0—4 概览，73—136°E / 18—54°N 范围的 z5—9 地形（默认地面像素约 180—300 米；矩形只是下载范围，不是国界），及十个精选关口周边 z10—12 精细区域。z12 为每个关口 5×5 瓦片，宽约 35—45 千米，约 30 米级 SRTM；并非全国均达到 30 米。过度放大只显示已有数据，不能恢复道路/关楼细节。现有国界、港澳台联动与行政区划不变。
- 关口：唐古拉山口、平型关、居庸关、山海关、雁门关、剑门关、潼关、昆仑山口、聂拉木通拉山口、嘉峪关。安装器保留 WGS84 坐标逐项来源；位置用于浏览地貌，不是每条公路最高点。高度为 z12 坐标处 Terrarium 像素取值、四舍五入至 10 米，明确展示“附近地面约…米”。关口快捷按钮放大至 z12。世界地图最多放大至 z14。

安装：`python3 scripts/install-china-terrain.py`。需 Python 3 / Pillow，仅安装时联网；默认写入仓库同级 `data/cache/nature-maps/china-terrain.v1.pack`，遵循 APP_DATA_DIR、禁止仓库内目录。可选 `--national-zoom 8/9/10`；现有瓦片经 SHA-256 校验后复用，无效或未来版本保留并终止。失败下载不发布；全部下载完成后独占创建 `.pack.tmp`、fsync、原子替换，旧文件在发布前始终可用。遗留临时文件不会自动覆盖，确认没有安装进程后再处理；不并发运行安装器。

包格式：8 字节 `MUMUDEM1` + 4 字节小端 JSON 长度 + UTF-8 manifest + 按 key 排序的原始 PNG。schemaVersion=1，固定 ID、createdAt/updatedAt、WGS84、Terrarium、精度/范围/关口来源；每瓦片索引为相对数据区 offset、长度、SHA-256。PNG 编码高度 `R×256 + G + B/256 − 32768` 米。服务端限定索引大小、瓦片长度/坐标/字节范围，校验读取哈希；仅按需读文件，不把整包加载进内存。128 个瓦片结果缓存；缺少高层时截取父瓦片并用最近邻放大，避免 RGB 插值破坏高程编码。损坏不重写，未知版本拒绝，无家庭数据迁移。

- `GET /api/nature/terrain/china`：就绪状态及公开元信息，缺失返回 available=false，不影响世界图；可重试，无运行时下载。
- `GET /api/nature/terrain/china/:z/:x/:y.png`：仅服务已安装本机 DEM，整数范围校验；`X-Terrain-Source-Zoom` 标明实际数据层级，父级回退不声称更高精度。没有数据返回 404、损坏返回 503，错误不回传路径。成功图片私有缓存一小时。替换已加载的地图包后重启服务。

来源：[AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/)、[Tilezen 数据署名与许可](https://github.com/tilezen/joerd/blob/master/docs/attribution.md)。SRTM / GMTED2010 courtesy of USGS；ETOPO1 courtesy of NOAA；Wikidata 坐标 CC0。中国细节优先采用这套可直接离线安装的约 30 米级数据；另调研了 [Copernicus GLO-30](https://registry.opendata.aws/copernicus-dem/)，但其整片 DSM 文件较大、需要进一步裁切处理，本次没有声称接入它。地形用于地理观察，不作工程高程测量。

本机已安装 8,805 片、647,430,108 字节；公开快照摘要与 SHA-256 见 `content/nature/maps/terrain-runtime.v1.json`，大包不进 Git。验证：前端地图 20 项、后端地图/地形 13 项、安装器合成数据 3 项；包括缺失/损坏/未来版本、父级回退不改变编码、下载与发布失败保留旧包、离线复用、未知高度处理与渐变端点。浏览器验证剑门关精细地貌、关口定位与近似高度、关闭标记后缩放、全球设色及跨图层清理。

## 功能

- 世界：八个可切换图层、拖动/滚轮/双指与键盘缩放、文字搜索、地区列表、点击查看与放大。地理边界用 MapLibre GL JS 6.11.2 在本机 Web Worker 内切片绘制；无远程瓦片、字体、地图 Key 或运行时联网要求。
- 中国：全国 → 省 → 市 → 区县，列表与地图双入口。放大地图中心会进入有下级数据的地区，缩小返回上级；面包屑可返回。勾选点亮只记录指定 adcode，不自动点亮下属地区。
- 足迹：地图选点或选中心，填写名称、日期、文字与最多四张照片；每张不超过 8 MiB，仅 JPG/PNG/WebP。远景聚合位置点，缩放级别 8 起显示照片，点击打开原生模态相册；列表可直接定位、查看。支持编辑文字和日期，删除必须再次确认。完全重合的多个足迹仍可分别从记录列表打开。
- 控件至少 48px、文字至少 18px；键盘列表与焦点可用。无新增声音/奖励；减弱动效关闭镜头过渡。缺少 WebGL2 时显示重试提示并保留文字列表。
- 三张卡片由 ImageGen 在同一图集中生成：彩色平面世界地图、中国轮廓、底图上的定位标签与照片。保留原图集，按实际分隔线切分后等比例适配为 2:1 卡片与 WebP；插画仅作入口装饰，不作为地理数据。提示词、切分坐标与工具记录见 [artwork.v3.json](../content/nature/maps/artwork.v3.json)。

## 主要语言概览

- 「语种分布」改为十八种精选语言的国家/地区设色图；用户进入时只读取现有 `countries` 面数据，不请求旧 Glottolog 点云。保留中文、日语、韩语/朝鲜语、英语、法语、俄语、葡萄牙语、西班牙语、阿拉伯语，以及德语、意大利语、印地语、孟加拉语、乌尔都语、印度尼西亚语、土耳其语、波斯语、斯瓦希里语。
- `core-languages.v1.json` 固定使用 Unicode CLDR 47 和 Natural Earth 5.1.2。每个地区最多两种：底色表示第一种，斜纹表示第二种；它们覆盖同一几何，不虚构境内语言边界，也不代表人口比例。灰色表示精选集合外的主要语言，不能解释为无语言。
- 规则：优先该版本的全国官方/事实通用语言且使用比例至少 5%，地区官方语言至少 20%；没有全国语言记录时才考虑至少 50% 的候选。筛到十八个组后按数据中的使用比例最多取两种。中文相关汉语变体合并；书写系统变体去重，比例取最大值而不相加。该规则是教学取舍，不是官方排名或精细民族语言地图，CLDR 数值年份各异且含第二语言使用者。
- 258 个边界条目中 191 个有精选语言。用稳定 ID 加中文名称双重匹配，版本不匹配退为灰色；点击与搜索显示所选语言。原国家几何、选择联动和个人记录不变。
- 数据与许可：[Unicode CLDR 47](https://github.com/unicode-org/cldr-json/blob/47.0.0/cldr-json/cldr-core/supplemental/territoryInfo.json)，[Unicode-3.0 许可](../content/nature/maps/unicode-license.txt)；重建脚本 `scripts/generate-core-language-map.py` 记录固定 URL 和源 SHA-256。例如加拿大英法两语，与[加拿大政府说明](https://www.canada.ca/en/immigration-refugees-citizenship/services/settle-canada/language-skills.html)一致；新加坡仅选英中两语是显示限制，不能解释为只有两种官方语言。

python3 scripts/install-nature-maps.py

## API 与数据合同

所有 API 在 /api/nature 下；输入与持久化文件通过 Zod 校验，所有文件路径只来自固定目录与验证过的 UUID/adcode。

- GET /maps/world 或 /maps/china：数据包说明；GET /maps/:scope/:layer：该层 GeoJSON。world/terrain 返回本机晕渲图片。
- GET /state：读取记录，缺失返回空值且不写文件。PUT /lights/:adcode 仅接受布尔 lit，验证行政区确实存在；重复设置不增加 revision。
- POST /footprints：UUID、title（1–60 字）、date（真实日历日期）、note（最多 2,000 字）、longitude/latitude、photos（最多四张 base64）。固定 GCJ-02 坐标，不自动读取 GPS/EXIF。
- PATCH /footprints/:id：只更新标题、日期、文字，保留照片和坐标。DELETE /footprints/:id：元数据提交成功后删除图片文件。
- GET /photos/:uuid/full 或 /thumb：只服务已登记照片，私有 no-store 缓存头；不公开静态文件夹。不存在的 ID 返回 404。

个人数据位置：
- learning/nature/geography.json：schemaVersion=1，稳定 ID=nature-geography，createdAt/updatedAt/revision、lights、footprints。每条足迹有 UUID、创建/更新时间、GCJ-02、所用地图快照时间和照片元数据。
- media/nature-footprints/&lt;UUID&gt;.webp 与 &lt;UUID&gt;.thumb.webp：Sharp 解码检查最多 4,000 万像素，拒绝动画，自动旋转后缩至最长 2,400px、转 WebP；缩略图 240×180。重新编码去除 EXIF/GPS，不保存原始上传。
- cache/nature-maps/china.json.gz 与 world.json.gz：公开数据缓存，不含个人内容。

同一服务进程使用单写入队列；元数据和图片采用临时文件 + rename、0600 文件权限、0700 新目录。照片全部准备好才发布记录，失败删除本次未发布图片；崩溃发生于图片写入与元数据提交之间时可能留下未引用图片，不会发布不完整足迹。UUID 重试不重复添加旅行。单台数据目录只运行一个服务写入实例。

第一阶段只有入口，无旧版个人存档，所以不存在 v0 迁移；v1 可原样重启读取，损坏或未知版本返回错误且禁止覆盖。未来格式变更必须增加显式迁移与恢复点。此功能没有更改默认数据根目录、通用备份格式或既有记录。备份时必须同时包含 geography.json 和整个 media/nature-footprints；建议暂停服务后复制，避免跨文件快照不一致。公开 cache 可重建，也可随本机备份保留，但不能替代个人数据备份。
