# 拼音星桥

状态：**正式实现**

本文定义“语文 → 拼音星桥”的总表范围、汉字关联、高亮语义、单屏布局和语音协议。后续修改必须保持兼容，或同步更新本文、设计系统、实现与测试。

## 1. 学习范围

首页固定展示小学拼音学习中的 63 个单元：

- 23 个声母：`b p m f d t n l g k h j q x zh ch sh r z c s y w`；
- 24 个韵母：`a o e i u ü ai ei ui ao ou iu ie üe er an en in un ün ang eng ing ong`；
- 16 个整体认读音节：`zhi chi shi ri zi ci si yi wu yu ye yue yuan yin yun ying`。

三个分区使用教材顺序，不按字母排序。这里的“全部拼音”指以上完整学习单元集合，不把 2500 个汉字产生的每一种带调音节重复铺成数百个小格。

## 2. 汉字与组词来源

- 汉字、完整带调拼音和组词统一复用 `content/chinese/common-characters.v1.json`，不维护第二份容易失配的汉字资料。
- 声母按完整拼音的开头匹配；`zh / ch / sh` 必须优先于单字母声母，避免错误归入 `z / c / s`。
- 韵母按去声调后的拼音字符片段匹配；`ü / üe / ün` 同时兼容 `j / q / x / y` 后省略两点的书写形式，但详情仍展示数据中的标准带调完整拼音。
- 整体认读音节按去声调后的完整音节精确匹配。
- 每次打开详情或“换一批汉字”时随机抽取最多 6 个互不重复汉字；随机只改变展示顺序和样本，不改变候选池。
- 每个汉字至少展示一个包含该字的常用组词；优先展示两个，极矮屏可只显示第一个。

## 3. 拼音高亮

- 每张汉字卡必须展示汉字、完整带调拼音和组词。
- 选中的声母、韵母或整体认读音节在完整拼音中切分成 `前缀 / 命中 / 后缀` 三段。
- 命中段保留原始声调符号。例如选择 `ao` 查看“好”时，展示 `h` + 高亮 `ǎo`；选择 `sh` 查看“是”时，高亮 `sh` + `ì`。
- `ü / üe / ün` 在 `j / q / x / y` 后匹配省点拼写时，高亮实际显示的 `u / ue / un`，并在弹窗说明中保留当前学习单元名称。
- 高亮同时使用加粗、下划线、浅色高亮底和无障碍文本说明，不能只依赖颜色。

## 4. 单屏布局

- 页面使用固定视口高度，顶部为返回、标题和语音入口，下方为拼音总表；不出现页面纵向滚动。
- 桌面端同时展示三个分区，每个拼音格至少 48 × 48px。
- 窄屏改为“声母 / 韵母 / 整体认读”三段切换，一次完整展示一个分区，仍不要求纵向滚动。
- 详情弹窗锁定在当前视口内，桌面为 3 列 × 2 行，窄屏为 2 列 × 3 行，不提供内部纵向滚动。
- 极矮屏优先压缩说明文字、间距和第二个组词；汉字、完整拼音、高亮片段、至少一个组词和关闭操作不能消失。

## 5. 手动与键盘操作

- 点击拼音格立即打开汉字详情。
- `← / → / ↑ / ↓` 在当前分区移动选中；`Enter / Space` 打开详情；`Escape` 关闭详情。
- 分区按钮可触控和键盘操作。切换分区后选中该分区第一个拼音。
- 关闭详情后焦点回到原拼音格。
- “换一批汉字”保持当前拼音，只重新抽取候选字。

## 6. 语音协议

页面使用统一 ASR 客户端和同源 Fastify 转接，每段最多 2 分钟。

- 导航：`上 / 下 / 左 / 右`；
- 分区：`声母区 / 韵母区 / 整体认读区 / 下一组 / 上一组`；
- 详情：`详细信息 / 打开卡片`；
- 换批：`换一批 / 换一批汉字`；
- 关闭：`关闭卡片 / 返回拼音表`；
- 离页：`返回首页`。

同一句中的连续方向词按出现顺序逐个执行；打开、换批、关闭和返回只在最终识别句执行，并按句子去重。语音状态不得覆盖拼音格，ASR 不可用时所有功能仍可手动完成。

## 7. 数据与隐私

- 当前玩法不保存浏览记录、随机结果、识别文本或成绩。
- 不新增服务端数据文件，不把孩子的语音内容写入浏览器存储。
- 内容为空或格式异常时显示可理解的空状态，不能用虚构汉字填补。

## 8. 测试要求

- 校验三类数量、教材顺序和 ID 唯一；
- 校验每个拼音单元至少存在一个可展示汉字；
- 校验声母、韵母、整体认读和 `ü` 省点规则；
- 校验带调拼音高亮保留原始字符；
- 校验随机抽样不重复且能随随机源变化；
- 校验语音方向、分区、打开、换批、关闭和返回命令；
- 通过前端 TypeScript 检查、单元测试和生产构建。
