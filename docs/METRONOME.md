# 节拍器

艺术入口：`/art/metronome`。面向儿童的循环音乐创作，使用常见拍号与预制鼓点；不要求识谱，不收集麦克风或外设输入，不发放知识币。

## 界面与操作

- 顶部只保留播放、录制、节奏、速度、循环长度、伴奏与节拍声；音轨在中间独立滚动，底部始终保留演奏键盘。按用户要求收紧工具区：桌面图标按钮 32px、文字控制 36px、音轨约 56px；图标有中文悬停说明与可访问名称，琴键至少 48px，粗指针图标目标 44px。
- 主键盘数字行 1—0 与屏幕十键等价；长按保留音符时值。钢琴、拨弦、敲击类松开后仍自然衰减，管乐/拉弦/风琴类长按持续、松开柔和收音。输入框、弹窗与组合快捷键不触发演奏；全局数字键盘不抢占本页。
- 初始为钢琴、流行 4/4、90 拍/分钟、2 小节。单音采用 C 大调，可切换 C 大调五声音阶；低/中/高音区。键盘与拨弦乐器提供一键常用三和弦，和弦使用自己的按键名称与映射，不受单音五声音阶筛选影响。
- 录制先数两个完整小节，再录所选长度；两小节灰色预备区直接接在时间线前，标尺显示「预备 1 / 预备 2」，各轨对齐，同一游标连续走进正式区；不使用遮挡音轨的浮层。录制期间保留前导区，结束后收回并继续循环播放。预备按钮为「取消准备」，只播放节拍声、不播放作品或伴奏；试弹不写入作品，预备时按住的键不会跨界自动录入。再次“录一段”叠加；音轨旁的“重新录这一段”替换本轨，预备期间取消或完全未输入不会抹掉原段落。
- 默认自动吸附：简单拍子半拍，6/8 每个大拍三等分；设置可改整拍、半拍、三等分、四等分或自由敲。自由敲保留到 1/96 大拍，不是无限精度音频录制。
- 1/2/4/8 小节；延长时复制原段落，生成独立音符 ID。缩短有确认，音轨与音符变更可撤销最近 40 次；撤销范围是当前作品，切换作品清空撤销栈。
- 轨道旁直接显示只听、静音、手动编辑图标；当前轨道下直接显示音量、换音色、重录、清空、移除，不再使用轨道「···」弹窗。清空/移除仍确认并可撤销；窄屏局部滚动，不隐藏静音。
- 手动编辑：点击片段时间位置，或点编辑图标/底部「手动编辑」，当前轨道内展开一个小节的格子。先选格，再按主键盘 1—0 或屏幕琴键，立即在该位置添加音符并试听，不依赖录制时钟、加载速度或按住时长；同格异音可以叠加，同格同音选中已有音符。首次时值为一格，录好的非网格音符保留原始时值。
- 编辑区可切换小节、每拍 1/2/3/4 格，选择已有音符、前后移、缩短、拉长、删除。左右方向键选格，Delete/Backspace 删除所选音符；小节格子仅展开当前一小节，底部琴键常驻。播放期间禁用编辑，键盘只试听；实时录制开始前退出手动编辑，退出后琴键恢复普通演奏。
- 手动输入与编辑复用原有 schema、容量校验、撤销、自动保存与导出，不新增个人数据格式。编辑游标与选中音符仅在内存中；切换作品/开始新作品清理，删除或撤销后失效选择不得误改别的音符。
- 静音始终优先于单独听；只听某轨时自动排除伴奏，其余作品轨静音。节拍声独立控制：按钮显示当前「无 / 低 / 中 / 高」，按此顺序循环，默认为低。低档保持原响度，高档接近默认钢琴起音；播放、预备、录制中切换不重启时钟，下一次调度生效（提前窗口最多 100ms）。无档也关闭预备声，灰色两小节与游标照常前进。档位随每首作品保存、复制、导入/导出。

## 拍号与音色

`content/metronome/rhythms.v1.json` 是六种预制鼓点来源：进行曲 2/4、圆舞曲 3/4、流行/摇滚/迪斯科 4/4、六八拍 6/8。这是启蒙示例，不宣称穷尽音乐节奏，也不把风格等同于拍号。

内部每个大拍 96 ticks。2/4、3/4、4/4 按四分音符数拍；6/8 明确是两个附点四分音符大拍，每个大拍分三个八分音符，不能错误地显示为六个等重的大拍。切换模板按小节位置缩放已有音符，并恢复该模板的推荐速度。

`content/metronome/instruments.v1.json` 提供 38 个音色/打击组合，分键盘、拨弦、拉弦、管乐、低音、打击乐、鼓七类。包括钢琴、电钢琴、风琴、手风琴、吉他、竖琴、班卓、提琴、长笛、竖笛、单/双簧管、大管、萨克斯、铜管、贝斯、木琴、马林巴、钟琴、钢鼓、太鼓、定音鼓和多种手鼓/镲/木块组合。

音色是 FluidR3 采样乐器的近似；不模拟真实乐器的全部音域、指法、演奏法或力度层。实际可弹音高按谱音生成；原音源个别缺键采用最近采样移调，不把不同按键压成同一个音。

## 音频与资源

- 直接使用 Web Audio。声音发生时间依据 AudioContext 时钟；25ms 调度、100ms 提前窗口，所有轨道、节拍与伴奏共用时基。渲染帧不决定声音时间。
- 节拍保留普通拍 1000Hz / 重拍 1500Hz 正弦和 25ms 包络；低档普通/重拍峰值 .11/.18，中档 .33/.45，高档 .72/.95，与钢琴共用总音量和限制器。以默认钢琴 C4、力度 .8、音轨 .8 的前 50ms 采样能量作为高档参考：限制器前 RMS 约 .12，节拍高档约 .09/.12；这是相对起音校准，不代表所有音高、设备的听感完全一致。
- 录制现场音不在第一圈重复回响；循环接缝使用半开时间区间，避免漏拍、重拍。音符时值到段落末尾截断，声音尾音允许跨越接缝。
- 松键与停止分开处理：钢琴、电钢琴、吉他、竖琴、低音和敲击音色不因松键截断；完整采样保留原尾音，仅有起音/循环的采样用循环区加有限衰减重建尾音（按音色/音高调整，最长 6 秒）。管乐松键约 0.4 秒、拉弦约 0.5 秒、风琴/手风琴约 0.3 秒渐弱。钢琴这是便于启蒙的延音式手感，不等同于真实钢琴不踩踏板的制音。
- 同一音轨内相同实际音高重按，旧音用 25ms 淡出；不同音高、不同音轨互不截断，和弦只对共有音高重触发。实时弹奏、循环回放和 WAV 导出复用同一逻辑；停止/取消能清掉已松开的尾音和已排期的声音，不依赖松键收尾。以上只是播放行为调整，作品 schema 与已有音符时值不变。
- 同时保留最多 192 个实时采样声部；离线导出不使用此裁剪，避免长作品开头被误删。主输出限制器减少叠加峰值。
- 进入创作页取得 `audioFocus.acquireCreative()` 并暂停背景音乐，退出释放，保留原音乐偏好。本页隐藏背景音乐悬浮按钮，停止旧朗读。页面进入本身不播放声音。
- 页面隐藏、离页、麦克风取得声音占用、音频时钟停顿超过 500ms 会停止播放，保留已录内容；迟到的加载结果不能继续旧演奏。
- 音色在 `apps/web/public/audio/metronome/`，约 11MB，运行时仅加载本机文件。无需联网或新增运行依赖。
- 开发提取器 `scripts/prepare-metronome-audio.py` 从 WebAudioFont 固定提交 `23ca907d4370a04fd89ca483a92915e4d6159ab9` 提取数字元数据与 MP3 字节，不执行远端 JS。每个输出附原 URL、原文件 SHA-256 与源版本。
- FluidR3 的无循环标记 `loopStart=-1, loopEnd=-2` 在解码前规范为零；其他负值拒绝。
- 许可和署名见 `apps/web/public/audio/metronome/CREDITS.md`，同时保留原音源与转换项目的 MIT 许可。

## 作品管理与数据

- 作品自动保存，作品弹窗另提供明确的“保存”。列表可直接打开、播放、复制、删除；名称失焦或回车保存。
- 复制重新分配作品、音轨、音符 ID，修改副本不影响原件。删除需要确认；删除最后一首后创建一份空白作品。删除不具备回收站，需要保留的作品应先导出。
- 保存于仓库外 `APP_DATA_DIR/creative/metronome-library.json`，默认 `../data/creative/metronome-library.json`；不写浏览器长期缓存、Git、public 或 content。
- 外壳 schemaVersion 1、固定 ID `metronome-library`、创建/更新时间和递增 revision；内层作品集 schemaVersion 2、activeId、作品数组，每首作品含 UUID、创建/更新时间、节奏、设置、轨道和音符。v2 的 `click` 为 `off | low | medium | high`；其他字段不变。
- 共享契约 `apps/server/src/metronome-contract.ts` 同时校验浏览器、API、磁盘、导入文件。上限 24 首、每首 32 轨、每轨 1024 音符、每首 4096 音符、总集 12000 音符，上传最多 4MB。
- `GET /api/metronome` 返回完整状态或 null；`PUT /api/metronome` 提交 expectedRevision 与 library。单进程写入队列 + 比较版本，陈旧窗口返回 409，不覆盖另一窗口。
- 0600 临时文件、同步、原子替换；缺目录创建 0700。读取损坏/未来版本时禁止编辑与覆盖；保存失败保留最新内存编辑、提供重试和下载。未确认落盘前不显示“已保存”，存在未保存内容时保护离页。
- v1 作品集严格校验后在内存迁移：`click: true` 映射低，false 映射无；不改音符、ID、创建时间或 revision。GET 不写盘。首次保存 v2 前，在同一写入队列内将原始字节以 0600 临时文件、同步和原子硬链接保留到 `metronome-library.json.v1.<SHA-256>.bak`，不覆盖恢复点；重试复用内容相同的恢复点，恢复了不同旧档也分别保留。备份失败拒绝改写原档。回退可在停服后保留当前 v2，再用恢复点还原 v1。未知版本仍拒绝；数据根目录与其他模块备份格式不变，整机备份应包含作品文件及迁移恢复点。

## 导入与导出

- “下载音乐”：选重复 1/2/4/8 遍，离线渲染立体声 44.1kHz、16-bit PCM WAV，保留混音/只听/静音设置，排除节拍器点击声，包含 6 秒尾音余量，总长上限 180 秒。
- “下载可编辑作品”：下载整个作品集 v2 JSON，新建含时间的文件名。该文件与 WAV 均属于个人作品，下载到用户选择的本机目录，不进入公共素材。
- “导入作品”：严格校验本软件导出的 v1/v2 作品集 JSON，v1 先迁移音量开关，重新分配 ID 后追加，不替换现有作品。容量不足、非法文件、未来版本均拒绝且保留原作。此格式是音乐模块的可编辑交换文件，不是全站备份包。

## 验证

38 种乐器图标使用内置 ImageGen 的三张 4×4 图集，原稿、逐格映射、生成提示词及裁切记录位于 `assets/art/metronome/instruments/v1/`。运行时透明图标位于 `public/images/metronome/instruments/v1/`，按乐器 ID 区分，用于选择卡片、音轨与底部当前音色；替换旧的家族简笔画，不改变录制、作品数据或页面布局。提取复用项目 chroma-atlas-extractor，保留生成器原生 alpha。

自动测试覆盖拍号/网格、接缝、循环复制、音色键位覆盖、采样校验、WAV 编码、录制边界/叠加/替换、作品复制/删除、音频调度、保存顺序/错误/冲突、空存档、未知版本、原子写入失败与权限。文件测试只用临时目录。

两小节预备回归覆盖六种节奏、无声预备时的游标、初始拍位、正式录制边界和中途取消。四档节拍回归覆盖循环顺序、低档原包络、高档增益、实时切档时钟连续、静音/导出排除点击声、v1 迁移、恢复点原文/权限/失败重试和重新打开后的高档保存。声部回归逐一覆盖 38 种音色的松键尾音、同音重触发、异音/异轨隔离、回放时值、短循环采样尾音、和弦共有音高、提前排期与停止清理。

手动编辑回归覆盖空轨插入、同格叠音/去重、录制音符保留、非法键位、循环边界、移位/时值夹取和存档 schema 兼容；组件渲染检查单小节范围、图标名称、播放禁用，以及六种节奏的灰色前导区与连续游标。

浏览器在独立测试服务和临时数据目录下验证主键盘录制、全部音色加载解码、音符编辑、循环扩展、只听、主动/自动保存、重开恢复、作品复制/播放/确认删除、音乐导出和全屏布局。1280×720、1366×768、375×667 的页面无整体横向/纵向溢出，多轨在轨道区滚动。内置浏览器不开放原生全屏时使用既有的沉浸布局降级；不夸称测试了全部浏览器/操作系统。
