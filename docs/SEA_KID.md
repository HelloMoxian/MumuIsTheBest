# 跳海小孩

正式入口：游戏大厅 → 跳海小孩，`/games/sea-kid`。本机 Canvas 2D 横向卷轴游戏，圆润卡通素材；不是临时路线页的运行时扩展。无数据库、联网素材、生命次数、倒计时或新增货币奖励。

## 控制与流程

- 左右方向键 / A、D 移动；空格 / K / Z 跳跃；J / X 攻击（可长按）；Shift 加速；P 暂停。键盘始终可用，屏幕按住按钮支持多点触控。
- 共用手柄注册：十字/左摇杆移动、A 跳跃、X 攻击、RB 加速、Start 暂停，B 通过全站导航暂停。操作窗口可查看与重设手柄键位。
- 丛林 → 大海 → 洞穴 BOSS → 下一大关，无限循环；小关完成显示约 1.8 秒结算并生成下一关。只落海/掉坑会死亡，约 .65 秒后回当前小关开头，角色恢复无武器、无药水、无滑板、无泳圈的最原始状态。
- 首次进入、刷新续玩、失焦、后台、手柄断开后均等待主动开始/继续。全屏始终提供退出和返回入口；不新增自动音源，使用已有全站背景音乐。

## 角色与道具

- 药水累计两级：第一级跳得更高，第二级保留跳高并增加速度；画面通过体型区分，不显示强壮等级名称。首次获得药水而无武器时同时给予锤子，保证退化下限为有武器状态。
- 受击按二级 → 一级 → 有武器退化，包含短暂击退和 1.15 秒保护，避免连续接触立即清空加成。保护结束后敌人、石头、子弹和机关仍可再次击退；有武器只是装备退化下限，不再永久免疫。没有新增血条或接触即死，死亡仍由落海/掉坑触发。
- 滑板独立提速；受击先损失滑板，本次不再降低药水等级。普通移动、Shift 加速、药水与滑板的速度总和受统一上限约束。
- 锤子为弧线投掷，风火轮为直线穿透普通敌人的替代武器；捡到新武器替换旧武器。
- 泳圈独立，只抵消一次落海：送回最近的安全静止平台，并消耗泳圈，保留其他装备。不能抵消洞穴/丛林落坑。被推、普通受击不消耗泳圈。
- 水果加 50 分、其他道具 100 分、敌人 150 分、BOSS 1000 + 大关数 × 100 分。掉落重来不会重复计入同一目标的分数，但道具仍可再次取得效果。
- 实际得分时在拾取/击败位置显示上飘数字，重复拾取不伪造加分。非水果道具拾取后角色以亮色叠图透明度做 1 秒强化提示，每 .2 秒一轮共五轮；不改变无敌时间。减弱动效使用静态描边和原地短暂分数。
- 行走使用「迈腿 A → 收腿站姿 → 迈腿 B → 收腿站姿」四拍，每实际移动 26px 换一拍，保留脚底锚点；原地顶墙不空转，滑板上保持站姿。复用已有三个体型的原始帧，不修改图集。
- 敌人/BOSS 击败时立即失去伤害能力，展示层另画约 1.3 秒的翻转、上抛后坠落残影；BOSS 结算遮罩等待主要抛落动作完成再出现。减弱动效只短暂淡出。效果、步态相位放在 WeakMap 中，暂停冻结，重开/切关清除，刷新不重播，不参与积分或存档。

## 地形与机关

- 固定每小关 15,600 世界像素。最高速度 520 px/s，因此不含停留、战斗与起步的净行进时间为 30 秒；无强化按住加速为 380 px/s，普通步行为 240 px/s。固定步长 1/120 秒，重力 1800、基础跳跃初速度 620、强化跳跃 720。
- 生成使用固定种子，坐标以 0.1 像素精度表达，间隙不取整数格。素材按 88px 等尺寸重复，并裁切平台边缘，物理不依赖贴图格。
- 新路线使用 generatorVersion=2：地面基准高度范围从 350—466 扩到 300—490，相邻静态平台最大高差从 46px 增到 84px；遇到升降平台扣除双方振幅，最不利上升仍至多 84px，低于基础跳跃约 107px 的最高点。横向间隙继续按真实高度差重新计算，不依赖强化通过。
- 相邻主路线根据基础角色的弹道、上升高度与完整身体宽度计算极限跳距，另留 32px 余量；移动平台取两端最不利高度。平台宽度下限留出落脚及加速距离，不依赖药水、滑板或泳圈通过。
- 前三个大关丛林/洞穴无坑，大海平台间距 -10 至 5px；第四关起逐渐扩大间隙、缩短平台、增加敌人密度，难度渐近上限而不越过基础角色跳跃极限。
- 第八大关起 BOSS 区有两个静态坑；按照“八关之后”的新增要求，第九大关起路线中加入坠落与周期升降平台。约每四个平台安排一个动态平台，之间有静态落脚点。
- 坠落平台踩下 .8 秒后下落，4.5 秒后恢复；落前描边与裂纹提示。升降平台振幅 20px，周期 3.4—5 秒，角色跟随平台位移；上升/下降是相反周期方向。
- 陷阱包括固定石头、周期喷火、周期推人和预告落石。喷火/推人每 3.6 秒约有 1 秒生效，其他时间可通过；落石位置有向下提示。早期仅少量石头/喷火，九关起加入推人/落石。
- 固定石头接触后不会失效，可被锤子或风火轮打碎；普通落石接触角色不再消失，落到平台后继续保留并造成接触伤害，武器可将其打碎，掉出地图则自然清除。同一落石机关有石头留在原位置时不反复堆叠。火焰与推人装置仍按原周期工作，普通水弹/墨汁命中后仍消耗。
- 云、树木和洞穴装饰按稳定世界槽位编号选择位置、样式与大小，视差位置使用世界坐标减摄像机偏移；循环边缘仅增删离屏对象，不再用屏幕编号重新分配可见树木。
- 六种普通敌人：青蛙、蜗牛、章鱼、蝙蝠、小蜥蜴、小刺猬，具有巡逻/跳跃/飞行差异和独立投掷物。
- 八种 BOSS 循环：鼓腮蛙王、岩壳蟹王、墨海章鱼、洞穴蝠王、火山小龙、滚石刺猬、冰晶巨人、熔岩巨人，分别以跳跃、快速往返、三向墨汁、空中摆动/散射、跳跃火球、冲撞、落冰石、落火山石为主。进入后锁定末尾 1280px 场地，入口固定提供锤子；BOSS 生命与频率随难度有上限地增加。

## 分数、路线和存档

- 最远距离 = 已完成小关长度总和 + 当前小关最大 x。后退、死亡、重复行走不重复累计；界面以 32px 为一个距离单位，无工程长度含义。
- 换路线：确认后以同难度新种子生成，回小关起点，保留装备、得分和最远距离。新路线道具/敌人作为新目标计分，旧路线不再可回访。
- 重新开始：确认后清空当前轮成绩及装备，回第一大关丛林；只影响此游戏。
- 按用户要求，浏览器 `localStorage` 的 `mumu:sea-kid:v1` 保存一个完整原子快照。含 schemaVersion、ID、创建/更新时间、revision、完整已生成路线、世界/小关、角色、最远距离、得分、领取/计分集合、BOSS、弹丸、机关/坠落时钟及结算阶段；刷新不重新生成路线。
- 每约 1.8 秒以及暂停、离开、小关状态变化保存；单次 `setItem` 原子替换，先解析验证。读写异常、坏 JSON、非法平台索引、未来版本和多窗口更新不能自动覆盖。多标签使用读前原文比较与 storage 事件检测冲突，冲突后暂停并要求重新载入；这不是跨进程数据库事务。
- 快照仍为 schemaVersion=1，兼容 generatorVersion=1/2 的完整路线；旧路线原样保留，不自动重抽或移动已有平台，换路线/下一小关/重新开始才生成 v2 高起伏地形。已打碎固定石头用现有 `collected` 集合中的 `rock:陷阱索引` 标记，刷新保持消失，死亡回小关开头时随原有场内领取状态一起重置；落石继续使用原有 shots 数据。未知快照或生成器版本仍拒绝读取。提供原存档下载用于人工备份，不上传、不导入其他游戏奖励。

## 素材与验证

- 由内置 imagegen 生成三张原始图集，保留于 `assets/game/sea-kid/`；最终 64 格 PNG 在 `apps/web/public/images/sea-kid/`。角色 24 格含两级强化的六姿态与六敌人，道具/BOSS/机关 24 格，场景 16 格。
- 工程 chroma-atlas-extractor 按 6×4、6×4、4×4 切分。原图已带 alpha，因此 `--keep-background` 保留透明通道，角色整格不裁边。`scripts/prepare-sea-kid-assets.py` 去掉小型孤立残片并生成锚点目录；不改变源图集。
- `assets.json` 的头部/脚底锚点供运行时稳定绘制角色；物品可按目录 bounds 显示。武器、子弹、墨汁、火球与人物完全独立，程序控制其位置、旋转、碰撞和生命周期。加载失败保留可玩的图形回退。
- 专项测试覆盖 1,800 条连续坐标路线、15 条高难海上路线的基础角色实际跳跃、状态退化、泳圈、死亡重开、计分去重、换路线、BOSS 锁屏、平台恢复、空数据、非法/未来存档、写入失败和跨窗口冲突。测试使用内存存储，不触碰真实个人数据。
- 全量命令：`pnpm --filter @mumu/web test`、`pnpm --filter @mumu/server test`、`pnpm typecheck`、`pnpm build`。工程没有单独格式化/lint 命令。
