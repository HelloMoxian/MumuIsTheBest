# 元素周期表功能规范

状态：**已实现**

本文定义“化学 → 元素周期表”的数据、布局、语音交互和元素详情语义。后续扩展必须保持兼容，或同步修改本文、数据生成器与测试。

## 1. 功能目标

- 用标准元素周期表布局完整展示原子序数 **1—118** 的元素。化学元素不存在“0 号元素”，因此用户口语中的“0 到 118”按现行正式元素范围 1—118 实现。
- 每个元素格同时显示原子序数、符号、中文名、带声调拼音和相对原子质量。
- 镧系 57—71、锕系 89—103 在主表下方各占一整行；主表第 6、7 周期保留对应系列入口位置。
- 通过分类颜色、类别文字和选中描边共同表达碱金属、碱土金属、过渡金属、其他金属、类金属、非金属、卤素、稀有气体、镧系和锕系，不能只依赖颜色。
- 默认选中 1 号元素氢；点击元素直接打开详情，键盘或语音移动后可再说“详细信息”或按 Enter 打开。
- 点击元素后的详情必须展示统一知识库中所有含该元素的物质；不能维护第二套手写“常见化合物”清单。

## 2. 权威数据与维护

基础数据由 `scripts/generate-periodic-table.mjs` 从以下资料生成：

- PubChem Periodic Table / PUG REST：原子序数、符号、英文名、相对原子质量、电子排布、电负性、半径、电离能、电子亲和能、氧化态、常温状态、熔点、沸点、密度和发现年代。
- 中国化学会发布的 IUPAC 中文元素周期表：1—118 号中文名称；拼音由项目维护并带声调。
- CIAAW Standard Atomic Weights：用于核对标准原子量的权威入口。需要注意，部分放射性元素没有标准原子量，资料通常显示代表性同位素质量。

数据入口：

- https://pubchem.ncbi.nlm.nih.gov/ptable/
- https://pubchem.ncbi.nlm.nih.gov/rest/pug/periodictable/JSON
- https://www.chemsoc.org.cn/international/news/a2613.html
- https://ciaaw.org/atomic-weights.htm

重新生成：

```bash
curl -fsSL https://pubchem.ncbi.nlm.nih.gov/rest/pug/periodictable/JSON \
  | node scripts/generate-periodic-table.mjs
```

生成器必须验证：

1. 恰好有 118 个连续原子序数；
2. 中文名和拼音都是 118 项；
3. 每个元素按电子排布计算出的各电子层电子数之和等于原子序数；
4. 标准周期表坐标唯一；
5. 不用推测值覆盖权威资料中的未知项。

## 3. 周期表布局与导航

- 桌面端使用 18 族、7 周期的全宽图谱，最小内部宽度保证元素格可读；窄屏允许周期表主体横向滚动。
- 镧系和锕系是底部独立的第 8、9 显示行，不改变其真实第 6、7 周期属性。
- 左、右移动只在当前显示行寻找下一个实际元素，并自动越过空位。
- 上、下移动在目标方向寻找空间距离最近的实际元素；优先较近显示行，再比较列距离。
- 若目标方向没有任何元素，选中项保持不变，不循环、不越界。
- 一段语音中的每一个方向字都要依次执行，例如“上上下下、左左右右”会执行八次移动。

## 4. 语音输入

- 使用现有同源 Fastify → 阿里云 Fun-ASR 安全转接，不在浏览器中保存或显示 API Key。
- 首次使用前仍需在首页“功能测试 → 语音识别测试”保存本机配置。
- 支持“上、下、左、右”“详细信息”“查看详情”“返回”“关闭详情”等自然表达。
- ASR 中间结果可能反复携带同一句的完整前缀。页面以 `sentenceId` 保存已消费文本，只处理新增后缀，避免同一个方向重复移动。
- 详情打开时暂停处理方向词，只响应“返回”；关闭详情后继续使用原语音会话。
- 每次 ASR 会话仍由服务端强制限制为最多 10 分钟。到时后页面显示“继续识别”入口，只有用户主动点击才开启下一段。
- 页面不自动开启麦克风，防止浏览器权限弹窗和意外录音；儿童点击明显的语音导航按钮后才开始。

## 5. 元素详情

详情使用近全屏弹窗：

- 左栏固定在滚动视野内，显示中文名、拼音、英文名、符号、原子序数、相对原子质量和动态原子模型。
- 原子模型按真实电子层数量和电子数动态创建，不为 118 种元素维护静态图片。
- 原子核固定在中心，质子和中子以互相挤压、轻微形变的球体组成紧密核团；只有核团和外围光晕可以极慢旋转，元素符号始终保持正向。
- 1—10 号元素按完整质子数和由相对原子质量估算的中子数逐个渲染；11 号以后的元素使用 42 个按质子/中子比例混排的粒子表达密集结构，旁边的文字仍标明完整质子数、估算中子数与电子数。
- 原子核附带“核电荷 `原子序数+`”标记，例如钠显示 `11+`。
- 每个电子层有独立的固定椭圆轨迹；轨迹本身不旋转，电子沿轨迹按不同速度和交替方向运行。电子使用带负号的圆形标记，中心必须稳定落在轨迹上。内层电子为低亮灰蓝色，最外层电子使用该元素类别的高亮色。
- 钠必须明确展示 `2、8、1`，并解释最外层 1 个电子与高活泼性的关系。
- 右栏展示物理与原子资料、化学性格、真实电子层序列、在人类世界中的用途，以及来自 `content/chemistry/compound-catalog.v1.json` 的完整相关物质清单。
- 化合物清单按教材优先级和中文名排序，显示总数，支持中文名、英文名、化学式和简介搜索，并按每页 12 条浏览；分页只控制渲染量，不得丢掉任何知识库命中记录。
- 点击清单条目后在同一详情中展示中文/英文名、化学式、有机/无机与物质类别、具体原子组成、结构语义、知识要点、安全说明和原始资料入口。
- 有 PubChem CID 的条目展示本地 `pubchem-compounds.v1.png` 图集中的二维结构图，并提供 PubChem 来源链接，同时展示已有球棍模型；无可靠 CID 的材料只展示知识库组成或晶格代表片段，不伪造图片。
- 可用的 PubChem 数值至少包括分子量、IUPAC 名称、形式电荷、重原子数、氢键供体/受体、可旋转键、拓扑极性表面积和结构复杂度。缺失字段写“暂无可靠数据”，不能推测。
- 超重元素的用途应明确为核物理/化学研究；预测性质标记为“预测”，不得把预测值写成已经实测的结论。
- 化合物资料不足时显示“尚无可稳定展示的常见化合物”，而不是编造日常化合物。
- 对目录中没有任何命中的元素显示明确空状态，并说明可能是寿命很短或当前资产尚无可靠结构；不得回退到旧手写资料。

## 6. 可访问性与动效

- 每个元素是可聚焦按钮，有完整中文 `aria-label`；只有当前选中元素进入 Tab 顺序。
- 方向键移动、Enter 打开、Escape 关闭详情；关闭详情按钮在弹窗打开后获得焦点。
- 选中态同时使用白色描边、类别色光环和 `aria-pressed`，不只依赖颜色。
- 主要按钮最小 48px；窄屏详情改为单栏，原子模型不再 sticky，避免遮挡文字。
- `prefers-reduced-motion` 下停止持续轨道和粒子动效，但保留静态结构与全部信息。

## 7. 测试基线

`apps/web/src/features/periodic-table/logic.test.ts` 至少覆盖：

- 1—118 数据完整、序号连续、首末中文名正确；
- 所有电子层之和等于原子序数；
- 周期表坐标唯一，镧系与锕系各 15 个；
- 连续方向词按顺序执行；
- 横向跳过空位、纵向选择最近实际元素；
- 上下左右边缘不越界；
- 详情与返回指令识别。
- 118 个元素的化合物索引与统一 518 条目录逐元素求交结果完全一致；所有档案字段完整，502 条运行时 PubChem 图片索引有效。
