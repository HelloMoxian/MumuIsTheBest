# 数学：加减练习

状态：首个正式数学玩法已实现。

## 练习目标

让木木快速、稳定地掌握 0—20 范围内的基础加减“原子算法”。重点是通过短局、多次练习提升熟练度，不增加无关的题目复杂度。

## 本局配置

- 题目数量：5 / 10 / 20。
- 题目类型：加法 / 减法 / 加减混合。
- 题目朗读：不朗读 / 中文 / English。
- 本局开始后配置锁定，完成后才可修改，保证成绩口径一致。

## 出题边界

- 左右两个操作数都必须在 0—20。
- 加法结果必须在 0—20，例如 `7 + 8` 合法，`10 + 11` 不合法。
- 减法结果必须在 0—20，不生成负数。
- 同一局不重复出完全相同的算式。
- 加减混合至少同时包含一道加法和一道减法。

## 语音协议

- 中文和英文题目朗读统一使用 [`WEB_SPEECH_SYNTHESIS.md`](./WEB_SPEECH_SYNTHESIS.md) 的浏览器原生 TTS 服务；业务层生成“七加三等于多少”一类自然口语，不直接朗读算式符号。
- 每题严格执行“停止上一会话 → 朗读当前题 → 朗读完成或安全降级 → 创建本题 ASR 会话”。切题、重开或离页造成朗读 `cancelled` 时，旧题不得继续创建 ASR 会话。
- 朗读不支持、语言包缺失或声音失败时保留可见题目，并继续允许语音或其他已提供方式作答；TTS 不使用阿里云 ASR Key。
- 准备页识别“开始”或 `start`；结果页识别“再来一局”或 `restart`。
- 每道题创建全新的 ASR 会话，上一题的文字和增量状态不会带入下一题。
- 只消费 ASR 标记为最终结果的句子；同一句最终结果使用“句子 ID + 文字”去重。
- 只有 `等于`、`=` 或全角 `＝` 后紧跟的数字才是候选答案，其他闲聊不判题。
- 全局数字键盘提交属于孩子明确按下的答案，不要求额外输入“等于”；进行中的当前题必须直接复用同一 `acceptAnswer` 判题、首次正确证据、奖励与切题流程。
- 支持阿拉伯数字、全角数字和中文数字；`十二`、`一十二`、`零十二` 均解析为 12。
- 阿里云可能返回增量或包含前文的完整句子。重复出现的错误答案只记录在本题的集合中一次，不会重复降低正确率。
- 答题页每 200ms 检查一次最新的增量/最终文字：只要任一候选命中正确答案就立即通过，不等待句子结束。
- 增量错误候选不会立即判错，需要稳定保持 2 秒才写入本题成绩并显示“再想一想”。
- ASR 已标记为最终句的错误答案属于明确作答：立即、永久写入本题的错误证据，但视觉上的“再想一想”仍延迟至 2 秒；期间即使又说出正确答案，也只能结束本题，不能把本题恢复成“第一次答对”。
- 每个会话继承 [`ASR_REALTIME.md`](./ASR_REALTIME.md) 的服务端 600 秒强制上限。到时保留当前题和计时，显示“当前未识别语音”，由孩子点击“继续识别语音”创建一个新的会话。

## 判题与反馈

- 首个合法候选答案正确：本题记为“第一次答对”。
- 首个或后续合法候选答案错误：立即显示“答案 ? / 再想一想”，但语音不中断。
- 本题只要曾命中过错误候选，即使后来答对，`firstAttemptCorrect` 仍为 `false`。
- 同一题反复说错只影响这一题一次，不按错误次数重复扣正确题数。
- 识别到正确答案后显示答案和对号，播放一次短促清亮的程序化成功音，并通过统一知识币接口为本题奖励 2 币；2 秒后进入下一题。
- 知识币奖励与是否首次答对无关，只要本题最终答对即奖励一次。同一题的正确处理只能触发一次奖励，奖励失败不能阻止继续练习或篡改历史正确率。
- 进入页面时建立统一奖励场次；进入时若加减练习是当前三倍玩法，本局所有随后答对的题都在 2 币基础分上乘三，按每题 6 币结算。顶部持续显示余额与本局三倍状态，十分钟轮换不改变已锁定倍率。
- 只在全部题目完成后保存成绩；刷新、关闭或中途离开不保存不完整记录。

## 历史记录

历史文件默认保存于：

```text
../data/learning/math/add-subtract-history.json
```

若设置绝对路径 `APP_DATA_DIR`，则写入该目录下相同的 `learning/math/` 相对路径。文件：

- 使用 `schemaVersion: 1`；
- 每局和文件都有稳定 ID / 创建、完成、更新时间；
- 使用临时文件 + 原子替换写入，权限仅当前用户可读写；
- 通过进程内单写入队列串行追加；
- 位于 Git 工作树之外，不进入 Git，也不受仓库内 `git reset` 或 `git clean` 影响。

服务端根据逐题的 `firstAttemptCorrect` 计算正确题数和正确率，不信任浏览器上传的汇总值。历史面板按“题目数量 + 题目类型”聚合，展示场次、平均总耗时、单题平均耗时、平均计算时间、木木年龄和正确率。

## 视觉与声音

- 页面遵循 [`DESIGN_SYSTEM.md`](./DESIGN_SYSTEM.md) 的“沉浸式逐题练习页”模式。
- 专属背景为原创生成的 3D 星际数学实验室插画，中央保留低细节演算安全区。
- 不使用循环背景音乐；成功音由 Web Audio 在本地生成，不依赖外部版权资源。
- 页面支持键盘焦点、移动端布局和 `prefers-reduced-motion`。
