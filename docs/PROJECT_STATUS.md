# 木木学习岛：项目状态总览

状态：**首页、语音底座、十个专项玩法与十一个多学科探索玩法已完成**
更新时间：2026-07-31

本文是当前已确定规则、已实现能力和后续边界的总览入口。详细的技术、安全和视觉规则以链接的专项文档为准。

## 产品方向

- 面向约 5 岁儿童的技术启蒙与算术学习网站。
- 核心价值是“木木最努力”：鼓励好奇、尝试、坚持和一点点进步，而非强调天生聪明或排名竞争。
- 体验定位是学习与娱乐结合的星际学习乐园；题目、反馈和下一步操作必须始终比装饰更醒目。

## ASR 安全与使用规则

- 实时识别使用阿里云百炼 Fun-ASR；浏览器仅连接同源 Fastify WebSocket，后端在上游握手时添加鉴权头。
- API Key 永不写入 Git、代码、日志、截图、测试或浏览器存储。
- 语音测试页是本机配置入口。Key 仅保存于 Git 忽略的 `var/config/asr-settings.json`（文件权限仅当前用户可读写）；页面只显示已配置状态，绝不回显明文。
- 单次实时 ASR 会话从上游 `task-started` 起**强制最多 2 分钟**。服务端负责到时发送 `finish-task`，前端倒计时仅作辅助。未来任何算术、游戏或知识模块接入 ASR 时默认继承此规则。
- 不保存孩子的音频或识别文本；所有错误提示不得泄露 Key、请求头或上游原始鉴权异常。

协议、安全架构和手动测试方式见 [`ASR_REALTIME.md`](./ASR_REALTIME.md)。

## 已实现能力

### 通用浏览器文字朗读

- 前端已提供统一的 TTS 服务和 React Hook，后续题目、阅读材料、知识卡片与提示语共享同一套调用、声音选择和播放状态。
- 服务直接使用浏览器 Web Speech API，不依赖 API Key、付费云服务或新增第三方包；默认使用 `zh-CN` 并优先设备本地声音。

- 新内容会取消旧内容；切题或离页后的旧朗读返回 `cancelled`，不会继续打开旧题的 ASR。
- 浏览器不支持、语言包缺失或网络声音失败时只降级声音，始终保留可见内容与核心学习流程。
- 加减练习已经迁移到该服务，并保持“先朗读、再打开 ASR”的半双工顺序。

完整架构、用法、隐私边界与测试要求见 [`WEB_SPEECH_SYNTHESIS.md`](./WEB_SPEECH_SYNTHESIS.md)。

### 数学：算数大战

- 首页“数学 → 算数大战”已成为正式可用入口，支持同时出现 1—5 题和简单/中等/超难三个档位。
- 同一局算式和答案均保持唯一，孩子说出一个“等于 + 答案”时最多点亮一题，并可自由决定解题顺序。
- 简单题聚焦带进退位的两位数加减；中等题混合乘法与整除除法；超难题使用 2—4 个数和 300 以内的综合运算，并避免低复杂度随机题。
- 正确结果每 200ms 检查并立即点亮；未命中任何题目的识别结果等待 2 秒确认后显示温和提示，识别过程不中断。
- 每段 ASR 仍由服务端限制为 2 分钟，本玩法最多顺序续接 5 段；第 5 段结束仍未完成则不生成成绩。
- 逐题耗时按相邻正确答案的识别间隔计算。只有全部完成才以 100 分、100% 正确率结算，并写入独立的 Git 忽略历史文件。
- 历史面板按题目数量和难度聚合平均总耗时、单题耗时、计算时间、年龄与正确率。

### 化学：反应熔炉

- 首页“化学 → 反应熔炉”已成为正式可用入口；运行时资料库包含 518 种物质，由 297 种安全的原始分子、68 种元素覆盖化合物和 153 种教材常见物质/碳材料结构组成。
- 资料库共有 268 种有机物和 250 种无机物，覆盖原子序数 1—80 的全部元素；当前 165 条物质守恒反应涉及的物质全部进入熔炉，原子序数 21—80 的金属均至少有两种记录且至少一种不是二元氧化物。
- 每批先随机确定 10 种优先元素，再选择能覆盖它们的 8 种无机物和 2 种有机物；最终至少出现 10 种元素，避免从全池直接抽样造成重复。
- 右侧原子仓严格按本批 10 种物质的总需求生成。少量原子逐个投放，大量同类原子按最多 10 个一组投放，支持 C₆₀ 等大结构。
- 炉体使用实时 Canvas 绘制能量云、星尘、投放波纹、原子布朗运动和边界碰撞；配方齐全后依次播放靠近、震动、键位发光、局部闪光和稳定漂移。
- 解析器支持上下标、括号、方括号配合物、结晶水与前置系数，并过滤变量聚合物、未知元素符号和异常大配方。
- 离散分子使用 PubChem 或同行评议来源的真实连接拓扑并用实线显示；离子晶体、盐和水合物用虚线连接组成示意，虚线明确不代表共价键。金刚石、碳纳米管和石墨烯显示有限的代表性晶格片段，C₆₀ 显示完整 60 原子球形笼。
- 页面明确标注“虚拟组成演示，不是实验步骤”，不提供危险物质的可操作制备条件；减弱动效模式会关闭持续运动并缩短聚合动画。

完整资料库、组成语义和实时渲染规则见 [`REACTION_FURNACE.md`](./REACTION_FURNACE.md)。

- 首页单屏展示 `23 个声母 / 24 个韵母 / 16 个整体认读音节` 共 63 个学习单元；桌面同时展示三类，窄屏使用不滚动的三段分区切换。
- 点击拼音格会从现有 2500 常用字资料中随机抽取最多 6 个相关汉字，展示大字、完整带调拼音和组词；当前声母、韵母或整体音节在完整拼音中保留声调并加亮。
- 详情舱桌面使用 3 列 × 2 行、窄屏使用 2 列 × 3 行，适配当前视口且不出现内部纵向滚动；支持“换一批汉字”继续探索。
- 鼠标/触控、键盘方向键和语音共享选中状态；语音覆盖方向导航、三个分区、详细信息、换批、关闭和返回首页，每段继续继承 2 分钟上限。
- 当前玩法不记录浏览历史或成绩，汉字和组词复用 `content/chinese/common-characters.v1.json`，不维护重复内容源。

完整范围、匹配、高亮、响应式和语音协议见 [`PINYIN_STAR_BRIDGE.md`](./PINYIN_STAR_BRIDGE.md)。

### 语文：常用汉字

- 首页“语文”已接入“常用 500 / 1000 / 1500 / 2000 / 2500 字”五个正式入口，全部复用同一套玩法，只改变频率前缀字池。
- `content/chinese/common-characters.v1.json` 包含 2500 个互不重复的一级规范汉字、9978 个组词和 4592 条成语记录；拼音、部首、笔画、简明释义和儿童朗读例句均随字提供。
- 内容生成同时参考规范字频率、HSK 分级词、SUBTLEX-CH 词频和新华字典候选，并通过独立脚本检查数量、前缀池、乱码、拼音、组词、例句和成语结构。
- 单局支持 5/10 字。汉字立即出现，约 1.7 秒后显示拼音，约 3.9 秒后显示释义、组词、例句和成语；桌面学习态固定在一个视口内。
- 语音覆盖“开始练习 / 我会了 / 下一个 / 详细信息 / 结束一局 / 再来一局 / 文字清单 / 返回”，增量和整句 ASR 按句子与语义去重，每段继续继承 2 分钟强制上限。
- 自适应抽题按“需要复习 / 新字 / 已掌握复习”混合选择；没说“我会了”的字只标记为继续复习，不使用答错或失败表述。
- 学习次数、我会了次数、继续复习次数和最近时间原子写入 Git 忽略的 `var/learning/chinese/common-characters-progress.json`；文字清单按频率分页展示并支持搜索、状态筛选。

完整内容来源、交互、语音、自适应和数据语义见 [`COMMON_CHARACTERS.md`](./COMMON_CHARACTERS.md)。

### 多学科探索任务

- 新增一套正式“多学科探索任务舱”，统一提供 5/10 个发现、观察舞台、选择/排序、温和提示、知识解释、本局星图、按钮与键盘全流程。
- 11 个入口共包含 110 个结构化任务，每题都有唯一答案、具体观察提示、知识结论、儿童可理解的解释和语音候选别名。
- 原有占位已经全部替换为可进入玩法：实验大师、物质虚拟世界、单词轨道、单位魔法、太阳系航线和数字战争；拼音星桥已进一步升级为独立专项页面。
- 新增规律侦探、力的实验舱、光影追踪、人体探索站和细胞小宇宙，并在首页加入正式“生命”学科行。
- 所有任务支持“开始 / 下一题 / 再听一遍 / 检查顺序 / 结束 / 继续识别”和按序号或候选项说答案；ASR 每段继续强制最多 2 分钟。
- 朗读复用通用 Web Speech 服务，严格执行先停 ASR、完成朗读、再开新 ASR 的半双工流程。语音不可用时全部核心操作仍可由大按钮完成。
- 首次未发现不会自动切题或写“答错”，而是给一个具体观察方向；结算只区分“一次发现 / 观察后发现”。
- 开放式短任务当前不写入儿童个人数据，中途结束只总结本次页面内已经完成的发现。

历史玩法原则、十一个短任务玩法定位、内容安全和后续扩展办法见 [`LEARNING_GAME_PLAYBOOK.md`](./LEARNING_GAME_PLAYBOOK.md)。
