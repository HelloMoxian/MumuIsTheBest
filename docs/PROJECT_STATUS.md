# 木木学习岛：项目状态总览

状态：**初始化、首页、ASR、三个数学玩法与三个化学模块已完成**
更新时间：2026-07-29

本文是当前已确定规则、已实现能力和后续边界的总览入口。详细的技术、安全和视觉规则以链接的专项文档为准。

## 产品方向

- 面向约 5 岁儿童的技术启蒙与算术学习网站。
- 核心价值是“木木最努力”：鼓励好奇、尝试、坚持和一点点进步，而非强调天生聪明或排名竞争。
- 体验定位是学习与娱乐结合的星际学习乐园；题目、反馈和下一步操作必须始终比装饰更醒目。

## 已确定的工程规则

| 领域 | 当前规则 |
|---|---|
| 技术栈 | Node.js 24+、TypeScript strict、pnpm workspace、React + Vite 前端、Fastify 后端。|
| 数据 | 不使用数据库；默认题库等可版本控制内容与孩子的运行时数据严格分离。|

## ASR 安全与使用规则

- 实时识别使用阿里云百炼 Fun-ASR；浏览器仅连接同源 Fastify WebSocket，后端在上游握手时添加鉴权头。
- API Key 永不写入 Git、代码、日志、截图、测试或浏览器存储。
- 语音测试页是本机配置入口。Key 仅保存于 Git 忽略的 `var/config/asr-settings.json`（文件权限仅当前用户可读写）；页面只显示已配置状态，绝不回显明文。
- 单次实时 ASR 会话从上游 `task-started` 起**强制最多 2 分钟**。服务端负责到时发送 `finish-task`，前端倒计时仅作辅助。未来任何算术、游戏或知识模块接入 ASR 时默认继承此规则。
- 不保存孩子的音频或识别文本；所有错误提示不得泄露 Key、请求头或上游原始鉴权异常。

协议、安全架构和手动测试方式见 [`ASR_REALTIME.md`](./ASR_REALTIME.md)。

## 已实现能力

### 主页与设计系统

- 正式品牌为“木木学习岛”，首页主题为“木木最努力”。
- 内置 40 条努力学习鼓励语，每次进入页面随机展示一条。
- 首页包含“学科探索地图”：数学、化学、语文、英语、物理、宇宙、游戏七个学科行。
- 每行左侧为学科舱和 CSS 学科插画（函数曲线、分子节点、文字、摆锤、行星环等），右侧玩法区在桌面端固定每行 3 个等宽卡片。
- 已放置第一批玩法占位：

  - 数学：加减练习、算数大战、乘法小能手、神秘函数。
  - 化学：元素周期表、反应熔炉、实验大师、物质虚拟世界、物质守恒。
  - 语文：拼音、常用 500/1000/1500/2500 字。
  - 物理：单位魔法。
  - 游戏：数字战争。
  - 英语、宇宙以及部分物理玩法使用清晰的“正在准备”占位，不伪造可用入口。

### 实时语音识别测试

- 顶部“功能测试”菜单提供“语音识别测试”入口；菜单层级已独立处理，不会被首页面板遮挡。
- 页面可保存本机 ASR 配置、显示配置状态、接收麦克风 PCM 音频并在右侧展示中间/最终识别结果。
- 识别测试包含可理解的网络、Key、端点、麦克风权限和超时错误提示。

### 数学：加减练习

- 首页“数学 → 加减练习”已成为正式可用入口，页面支持 5/10/20 题、加/减/混合和不朗读/中文/英文配置。
- 题目严格限制为操作数和结果均在 0—20；加减混合局同时包含两种运算，同一局不重复算式。
- 每题使用独立 ASR 会话，只判定“等于 / =”后的阿拉伯或中文数字；支持 `十二`、`一十二`、`零十二` 等识别差异。
- 错误答案会显示“再想一想”并持续监听；本题一旦说错，最终答对后仍只按一次“非首次正确”统计。
- 全部完成后显示逐题结果并写入 Git 忽略的本机历史文件；中途关闭不保存。历史面板按题数和运算类型聚合耗时、年龄与正确率。
- 页面使用专属原创星际数学实验室插画、本地程序化成功音和完整的移动端/减弱动效样式。

完整规则和数据语义见 [`ADD_SUBTRACT_PRACTICE.md`](./ADD_SUBTRACT_PRACTICE.md)。

### 数学：算数大战

- 首页“数学 → 算数大战”已成为正式可用入口，支持同时出现 1—5 题和简单/中等/超难三个档位。
- 同一局算式和答案均保持唯一，孩子说出一个“等于 + 答案”时最多点亮一题，并可自由决定解题顺序。
- 简单题聚焦带进退位的两位数加减；中等题混合乘法与整除除法；超难题使用 2—4 个数和 300 以内的综合运算，并避免低复杂度随机题。
- 正确结果每 200ms 检查并立即点亮；未命中任何题目的识别结果等待 2 秒确认后显示温和提示，识别过程不中断。
- 每段 ASR 仍由服务端限制为 2 分钟，本玩法最多顺序续接 5 段；第 5 段结束仍未完成则不生成成绩。
- 逐题耗时按相邻正确答案的识别间隔计算。只有全部完成才以 100 分、100% 正确率结算，并写入独立的 Git 忽略历史文件。
- 历史面板按题目数量和难度聚合平均总耗时、单题耗时、计算时间、年龄与正确率。

完整规则和数据语义见 [`ARITHMETIC_BATTLE.md`](./ARITHMETIC_BATTLE.md)。

### 数学：乘法小能手

- 首页“数学 → 乘法小能手”已成为正式可用入口，复用纵向 1—5 题并行语音挑战、分段 ASR、间隔计时和完整结算模式。
- “0—10 乘法”覆盖两个乘数 0—10，并允许 `7 × 8`、`8 × 7` 等先后顺序变化。
- “逆向除法”由 0—10 乘法事实反向生成，被除数不超过 100、除数为 1—10，保证整除且绝不除以 0。
- “进阶乘除”混合 20 以内乘法与 100 以内整除，乘法结果不超过 400；同一局题目答案始终互不相同。
- 只有全部题目解出才以 100 分结算，完整成绩写入独立的 Git 忽略历史文件；历史面板按题目数和难度聚合。

完整规则和数据语义见 [`MULTIPLICATION_PRACTICE.md`](./MULTIPLICATION_PRACTICE.md)。

### 化学：元素周期表

- 首页“化学 → 元素周期表”已成为正式可用入口，按标准 18 族、7 周期布局展示原子序数 1—118，并在底部独立展示完整镧系和锕系。
- 每个元素格包含原子序数、元素符号、中文名、带声调拼音和相对原子质量；10 类元素同时用颜色、图例文字和选中描边区分。
- 默认选中氢，支持鼠标/触控、方向键和语音“上 / 下 / 左 / 右”空间导航；连续方向词逐个消费，到达边缘不循环。
- 语音“详细信息 / 返回”打开或关闭元素档案；ASR 中间与最终结果按句子增量消费，避免全量结果让光标重复移动。每段识别继续继承服务端 2 分钟上限。
- 118 个元素都有用途概述。详情弹窗展示物理和原子资料、化学性质、真实电子层、发现年代、常见氧化态、在人类世界中的用途及相关化合物。
- 动态原子模型按每个元素的真实电子层和电子数渲染；原子核稳定在中央、内层电子灰蓝、最外层电子高亮并沿独立椭圆轨迹缓慢运动。桌面端左栏在详情滚动时保持可见。
- 基础数值来自 PubChem，中文名称参照中国化学会发布的 IUPAC 中文元素周期表；未知和预测性质保持明确标记。

完整数据来源、交互和详情语义见 [`PERIODIC_TABLE.md`](./PERIODIC_TABLE.md)。

### 化学：反应熔炉

- 首页“化学 → 反应熔炉”已成为正式可用入口；每次从 308 种可解析物质中无重复随机选择 20 种目标。
- 资料库包含常见单质、无机物、有机物、生命分子、矿物、材料、配合物和水合物，并区分分子、配方单元、单质结构和材料结构。
- 右侧原子仓严格按本批 20 种物质的总需求生成。少量原子逐个投放，大量同类原子按最多 10 个一组投放，支持 C₆₀ 等大结构。
- 炉体使用实时 Canvas 绘制能量云、星尘、投放波纹、原子布朗运动和边界碰撞；配方齐全后依次播放靠近、震动、键位发光、局部闪光和稳定漂移。
- 解析器支持上下标、括号、方括号配合物、结晶水与前置系数，并过滤变量聚合物、未知元素符号和异常大配方。
- 页面明确标注“虚拟组成演示，不是实验步骤”，不提供危险物质的可操作制备条件；减弱动效模式会关闭持续运动并缩短聚合动画。

完整资料库、组成语义和实时渲染规则见 [`REACTION_FURNACE.md`](./REACTION_FURNACE.md)。

### 化学：物质守恒

- 首页“化学 → 物质守恒”已成为正式可用入口，支持每局 5/10/20 道以及启航、探索、挑战三个难度。
- 内置 165 条不重复常见反应，覆盖化合、分解、置换、沉淀、放气、中和、燃烧、工业氧化还原、生命和环境过程；每条都有现实情景、条件、现象和反应类别。
- 资料加载时自动解析每个化学式，验证箭头左右所有元素守恒、系数为正整数且已经约为最简比；Mn、Sn 等带小写 `n` 的合法元素符号也已修正解析。
- 系数槽只能改变化学式前的数字，固定数字、当前选择、提示填入和完成状态都有独立视觉与文字。数字控制台可点击 `1—15`，并支持键盘 `1—9` 快捷输入。
- 元素天平实时列出每种元素的 `左 n / 右 n`，未配平时只提示优先观察一个元素；成比例但未约分时会引导继续化简。
- 单步提示每次只补一个系数。配平成功后播放反应物汇聚、中央重排、局部闪光、生成物展开和守恒锁定的实时 Canvas 动画。
- 结果页区分独立完成和提示后完成并展示用时，不显示失败或扣分；当前模块不写入个人数据。

完整资料来源、随机策略、配平语义和动画规则见 [`CONSERVATION_GAME.md`](./CONSERVATION_GAME.md)。
