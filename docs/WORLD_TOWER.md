# 物质塔

状态：十六层精选图谱正式实现

## 1. 内容边界

物质塔是一张从基本粒子通向宇宙的儿童知识关系图。它不追求节点数量，而只保留孩子熟悉、生活中重要或所在时代具有代表性的内容。

- 十六层结构固定，不得增删、合并或交换层级。
- 节点表示重要事物、生命、材料、发明、天体或知识对象。
- 每个非起点节点只有一条精简关系，包含 1—3 个前置节点、关系类型和一个儿童可理解的知识主题。
- 有明确组成或制造关系时使用真实关系；没有直接组成关系时，使用望远镜、显微镜、计算机等发现前置，或用能够承载该知识的代表节点建立归纳关系。
- 前置节点只表示知识路线，不被消耗。不再使用动作、条件、环境、粒子包或知识背包。

## 2. 唯一合成规则源

[合成规则源](../content/world-tower/composition-rules.v2.json) 是人工维护的唯一规则源，记录十五个精选内容层的节点以及元素、基本粒子的生成规则。用户明确给出的节点全部保留，组写法已经展开；其中包含射电望远镜、空间望远镜、显微镜、火箭等必要发现前置。

运行时文件由 node scripts/generate-world-graph.mjs 生成：

| 文件 | 职责 |
|---|---|
| composition-rules.v2.json | 十六层、精选节点、关系类型、1—3 个前置、知识主题和层级价格 |
| world-graph.v1.json | 503 个运行时节点、493 条配方、索引和十六层计数 |
| unlock-catalog.v1.json | 503 个节点价格与共享知识币定义 |
| icon-manifest.v1.json | 503 个节点的完整语义图片、外框、背景与紧急占位路径 |
| generated-art-plan.v1.json | 本轮 296 个补图节点的固定图集、格位、行列、节点 ID 与切图策略 |
| chemistry-art-plan.v1.json | 24 个生活化化学节点的两张 3×4 图集、固定格位和透明切图协议 |

运行时图谱仍使用 schemaVersion 1 的既有服务契约，内容身份为 mumu-material-tower-graph-v2。规则发生变化时，依次运行：

    pnpm content:world-tower:generate
    pnpm content:world-tower:validate

## 4. 界面与加载

- GET /api/world-tower/map 一次返回全部 503 个节点和 1244 条输入边，不再返回 100—160 个抽样骨架。
- 503 个节点都绑定语义一致的图片；未点亮节点的名称和内容图统一显示为问号，点亮后才揭示真实名称、图片和知识主题，星尘图只作为文件异常时的紧急降级。
- 首次打开页面时，中央图谱直接定位到最底部的基本粒子层，并优先聚焦电子节点；后续点亮或刷新数据保持孩子当前的阅读位置。
- 十六层在同一张连续长图中紧凑排布；画布按可用宽度在每行 6—11 个节点之间动态调整，118 种元素自动换行。
- 左侧导航是与中央滚动图完全独立的固定栏。中央图滚动时，导航自动加亮当前阅读层；点击导航直接定位到该层。
- 常态不绘制全部边。选择节点后只显示直接前置与直接去向，并在右侧展示关系类别、知识主题、点亮价格和缺失前置。
- 页面顶部直接显示知识币、已点亮数、总节点数和十六层信息。

保留的兼容接口 GET /api/world-tower/level-map 与 GET /api/world-tower/nodes 供诊断使用，新版主界面不依赖层级展开或分页。

## 5. 生成图片与固定切图协议

原有资源中有 183 个节点已经具备合适图片；其余 296 个节点使用 15 张新源图集补齐。生成与切分必须遵循同一份固定协议，禁止按批次临时更改行列数：

- 每张源图固定 5 列 × 4 行，共 20 格；按从左到右、从上到下的行优先顺序编号。
- 前 14 张图集各含 20 个真实节点；第 15 张含 16 个真实节点和末尾 4 个纯色空白保留格。不得把最后一张缩成 4×4 或其他尺寸。
- 每个格位只放一个居中主体，主体约占格位的 58%，不得越过分隔线；图中不得包含文字、编号、水印或装饰边框。
- 自然、农业、远古与物质类使用洋红键色，其他批次使用绿色键色；键色不得用于主体。
- 源图完整保存在 `apps/web/public/images/world-tower/source-atlases/material-tower-v1/`，不得覆盖或删除。
- 切图固定使用等宽等高 5×4 网格、24px 安全内缩、透明背景、透明边裁切和 8px 留白；输出为每节点一张独立 PNG。
- 每个批次的 `manifest.json` 记录源图尺寸、格位、节点稳定 ID、裁切框、透明覆盖率和警告；`generated-art-plan.v1.json` 记录节点到批次、行列和文件的完整映射。
- `node scripts/validate-world-icon-atlases.mjs` 必须确认 15 张源图、300 个格位、296 张非空节点图、4 个空白保留格、24px 统一内缩和透明边均符合协议。

第三、第四层的 24 个生活化化学节点使用独立扩展协议，不改变上述旧图集：

- 两张源图均为固定 3 列 × 4 行、每张 12 个真实节点，按行优先排列且没有保留格；
- 第一张覆盖氧气、甲烷、过氧化氢、苏打、小苏打、石灰和常见有机物，第二张覆盖冰、水蒸气、糖、醋、乳制品、骨骼、木材和铁锈；
- 源图保存在 `apps/web/public/images/world-tower/source-atlases/material-tower-chemistry-v1/`，透明切图保存在对应的 `nodes/generated/material-tower-chemistry-v1/`；
- 两张图集统一使用 24px 安全内缩、透明边裁切、8px 留白和稳定节点 ID；校验必须保证 24 张切图零警告、透明四角且与节点名称和层级一一对应。

## 6. 进度、安全与迁移

个人进度与知识币默认存放在 `../data/learning/world-tower/progress.json`，也可以由 `APP_DATA_DIR` 指向其他仓库外绝对目录。服务端使用单写入队列、临时文件、原子替换以及 0700 目录 / 0600 文件权限。

从旧图谱切换到物质塔时：

- 保留知识币余额、奖励场次、奖励幂等标记和交易历史；
- 清空旧图谱节点、永久资源和背包库存，因为旧 ID 与新规则不再等价；
- 下一次发生写操作时按新 graphId 保存；
- “点亮全部”点亮 503 个节点，“清空进度”清空全部节点，两者都不改变知识币余额。

知识币奖励、十分钟随机三倍玩法、进入时倍率锁定、家长密码清零或设定余额等规则继续与数学玩法共用，奖励细则保持现有实现不变。

## 7. 验证要求

校验脚本必须确认：

1. 十六层顺序和价格与规则源一致；
2. 节点 ID 与名称唯一；
3. 十个基本粒子直接点亮，其余节点恰有一条 1—3 前置配方；
4. 所有前置存在、不被消耗，资源条件全部为空；
5. 图无环，全部 503 个节点能从基本粒子到达；
6. 节点价格完整，503 个节点的美术引用真实存在；
7. 15 张旧生成图集保持固定 5×4，2 张化学扩展图集保持固定 3×4；全部使用 24px 内缩，320 个节点格零切图警告，旧图集 4 个保留格保持为空；
8. 服务端测试、前端逻辑测试、类型检查与生产构建通过。
