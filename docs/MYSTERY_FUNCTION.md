# 神秘函数玩法规范

状态：**已实现**

入口：`/math/mystery-function`

## 1. 学习目标

“神秘函数”不是计分题库，而是让孩子通过直接拨动参数，建立三个直观联系：

1. 公式是一台把 `x` 变成 `y` 的小机器；
2. 公式中的参数变化，图像会同步改变位置、方向、宽窄和弯曲；
3. 多条曲线可以共享同一个坐标系，并在同一个 `x` 位置得到不同的 `y`。

页面不使用倒计时、正确率或失败反馈，当前版本不写入个人学习数据。

## 2. 函数模板

公式库固定提供九类常见函数：

| 模板 | 标准形式 | 核心观察 |
|---|---|---|
| 一次函数 | `y = ax + b` | 斜率和上下平移 |
| 二次函数 | `y = ax² + bx + c` | 开口方向、宽窄和顶点变化 |
| 三次函数 | `y = ax³ + bx² + cx + d` | 远端方向和多次弯曲 |
| 正弦函数 | `y = A·sin(Bx + C) + D` | 振幅、频率、相位和平移 |
| 余弦函数 | `y = A·cos(Bx + C) + D` | 与正弦相似但起始位置不同 |
| 绝对值函数 | `y = A|x − H| + K` | V 形方向和尖角位置 |
| 平方根函数 | `y = A√(x − H) + K` | 定义域起点和延伸方向 |
| 反比例函数 | `y = A/(x − H) + K` | 两支曲线与渐近线 |
| 指数函数 | `y = A·Bˣ + K` | 快速增长、衰减和平移 |

每个参数都有独立的最小值、最大值和步进。默认值应立即产生清晰可见的典型图像，不得出现除零、`NaN`、无限值铺满画布或浏览器异常。

## 3. 完整流程

1. 进入介绍页，阅读“参数会让曲线变身”的任务说明；
2. 点击“开始探索”，默认点亮一次函数；
3. 从右侧公式库添加函数，同一坐标系最多保留四条；
4. 选择任意曲线，通过滑杆或加减按钮调整参数；
5. 可隐藏、重新显示或收起某条曲线，也可把坐标范围切换为 `±6 / ±10 / ±20`；
6. 在坐标图按住拖动，放下同一个 `x` 探针并比较各曲线的 `y`；
7. 点击“完成探索”查看本次点亮的函数家族、参数调整次数和最终公式；
8. 结果页支持继续调整、再开一次或返回学习大厅。

添加第五条曲线时不得覆盖已有曲线，只显示温和提示，要求先收起一条。

## 4. 绘图与动画

- 坐标图由 Canvas 按设备像素比实时绘制，包含网格、数字刻度、x/y 轴和原点。
- 曲线按定义域采样；平方根在定义域外不绘制，反比例函数在渐近线两侧分段，不能跨越不连续点连接。
- 新增曲线或参数变化后，当前曲线在约 820ms 内从左至右逐段出现，少量光粒子沿曲线前端汇聚，完成后稳定发光。
- 当前曲线使用更粗线宽、更高亮度和“正在调整”文字；其他曲线降低亮度但保持可见。
- 曲线使用固定的青、粉、黄、绿四色，并始终配套编号、名称和实时公式，不只依赖颜色辨认。
- `prefers-reduced-motion` 下直接绘制完整曲线，关闭粒子、扫描和持续浮动。

## 5. 坐标探针

- 鼠标、触控笔和手指使用同一套 Pointer Events。
- 按下或拖动时将屏幕坐标换算为一位小数的 `x`。
- 页面在 Canvas 外以文字列出每条可见曲线对应的 `y`；不在定义域内时明确显示“没有图像”。
- 双击图像或点击“清除探针”可以移除探针。

## 6. 验收边界

- 九类函数的默认计算结果必须有单元测试。
- 参数必须按模板范围夹紧并按步进对齐。
- 平方根和反比例函数必须安全处理定义域与除零。
- 反比例函数的采样结果必须分成至少两段，不能连过渐近线。
- 第五条曲线不能加入。
- 页面必须通过 TypeScript strict 检查、全量单元测试和生产构建。
