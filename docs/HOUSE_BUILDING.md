# 盖房子：二十档材料、可调形状与梁弯曲（v3）

入口为首页一级「物理」→「盖房子」，路径 `/physics/house-building`。二维侧视；搭建时冻结，运行时模拟；回到搭建恢复原始布局。孩子的设计与通关记录保存在仓库外。

## 引擎选型与真实性边界

首轮调研采用 [Planck.js](https://piqnt.com/planck.js/docs/) 1.5.0（MIT），Box2D 的 JS/TS 实现，支持接触、摩擦、铰链、固定连接与关节反力。其接口适合本玩法读取载荷并实现简化破坏。

| 候选                                                                  | 官方能力与集成判断                                                                                                                                         |
| --------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Box2D 3](https://box2d.org/documentation/)                           | 成熟二维刚体、连续碰撞与子步；浏览器需额外 WASM 绑定。Planck 不是 Box2D 3 官方绑定。                                                                       |
| [Rapier](https://rapier.rs/docs/user_guides/javascript/joints/)       | 官方 JS/WASM，二维、三维与关节；未来三维版值得重新评估。                                                                                                   |
| [Matter.js](https://brm.io/matter-js/docs/classes/Constraint.html)    | 适合常规二维互动；本次关节反力、力矩和独立连接语义优先选择 Planck。                                                                                        |
| [Project Chrono](https://api.projectchrono.org/9.0.0/manual_fea.html) | 有有限元柔性体；[WASM 构建](https://api.chrono.projectchrono.org/tutorial_install_chrono_emscripten.html)需要组织 C++ 工具链和模型，完整结构分析成本更高。 |

本产品不是工程安全分析工具。没有任何引擎能仅根据“木材”“钢材”名称自动准确模拟真实房屋。木纹、缺陷、钢材塑性、裂缝、屈曲、局部压痕、连接工艺与三维绕流均未完整建模。

[Planck 限制](https://piqnt.com/planck.js/docs/limitations.html)包括质量比、碰撞容差及迭代解算误差。固定步长 1/240s；有完整梁连接时使用 48 次速度迭代、24 次位置迭代，其余 24/12；连续碰撞。相同环境和输入可重复，不承诺跨平台逐位一致。后台或超过 0.5s 的长帧暂停；其他落后帧减慢模拟，不放大物理步长。

此前已移除木板的教学缩弱参数。v3 进一步修正高刚度梁完全刚性化的问题：`BeamJoint` 对 60Hz 以下的段使用原有转角弹簧；高频段通过实际弯矩 M 与截面转角刚度 kθ，令连接目标转角以 40ms 松弛时间向 −M/kθ 收敛，用耦合刚性约束保持段端点接合。强制使用完整的位置迭代预算，避免引擎默认角度容差吞掉微小挠度。适配器使用 Planck 1.5.0 的内部参考角字段，升级依赖必须重新验证。

这是高频段的准静态弯曲近似，过滤了无法稳定解析的高频内部振动；不宣称完整有限元、塑性或屈曲模拟。低频结构运动、碰撞、风震仍逐步求解。方块、三角块、圆块为刚体加简化破碎，只有板条和长方形沿长轴分段模拟弯曲。绘制时按仍连接的分段拼接连续外轮廓，隐藏内部边框并统一渐变与选中描边；轮廓随实际弯曲变化，内部连接真正断开后才分成不同轮廓，避免开始运行就像碎裂。

验算使用无自重、固定首段、自由端 100N 载荷，木头三档，截面出屏 0.2m、高 0.1m：2/4/6m 梁模拟挠度分别约 0.955/9.545/34.944mm，对照有效悬臂跨度的理论值 0.974/9.588/34.565mm。自动回归要求这三例误差小于 10%；这是特定小挠度算例的边界，不是所有复杂建筑的精度承诺。厚度翻倍后挠度约为 1/8；同尺寸木头一档换五档、弹性模量翻倍，挠度约减半；300N 端载下 2m 薄板保持完整、6m 薄板折断。

理论对照 [Purdue 梁挠度公式](https://engineering.purdue.edu/~ce474/Docs/DA6-BeamFormulas.pdf)：悬臂端载 δ=PL³/(3EI)、矩形截面 I=bh³/12。只有材料、截面、支撑、载荷一致时才能直接比较长短；实际倾倒还受重心、底座和连接影响，不能承诺短构件在任何摆法下都更稳定。

## 物理规则

- 米、秒、千克、牛顿、牛顿米；重力 9.81m/s²；构件出屏厚度统一 0.2m。普通质量 = 面积 × 厚度 × 密度；圆形用圆面积；三角形面积为底边 × 高度 / 2，碰撞与绘图使用以重心为原点的真实三角轮廓。配重直接指定 10—1500kg，作为不破碎的实验载荷。
- 正方形、长方形、三角形、木板/板条、圆块和配重六种，均可直接点击选择。正方形、圆块等比调整；长方形和三角形可分别调整底边与高度。板条长度至少为厚度两倍，最长 10m、最薄 0.05m。板条与长方形沿长轴分成 3—12 段，通常约每 0.5m 一段，尺寸改变同时影响质量、造价、截面刚度和破坏弯矩。
- 接触堆叠使用摩擦。固定连接约束相对角度，铰链可旋转；锚点必须距离两端表面不超过 0.13m，不隔空吸合。连接的局部刚体互相关闭碰撞，近似错层铰接。
- 梁的截面惯性矩 I = 出屏厚度 × 高度³ / 12，转角刚度 kθ = EI / 段长。内部连接按截面与材料强度计算力和弯矩门槛，持续超限 0.08s 才断裂。外部连接有独立承载上限，不等于材料本体强度。
- 块体局部四方向接触法向冲量/步长及连接反力估算名义压力，持续超限 0.12s 生成四块碎片，保留质量与原速度场；圆块用近似扇形。不是按堆叠层数扣除生命值。
- 风用 [NASA 阻力公式](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/drag-equation/) F = 0.5ρCdAv|v|，ρ=1.225、Cd=1.2。0.1m 射线条带只给首个迎风表面加载，受力点产生力矩，使用相对风速；不包含绕流、尾流和三维升力。
- 风速 0—60m/s，左右方向、阵风可选。地震实际移动地基；目标加速度 0—10m/s²、频率 0.5—4Hz，振幅 = 加速度 / (2π频率)²。启动平滑，报告同时保留设定加速度与模拟峰值；不写成真实地震震级。
- 地基总反力上限默认 1000kN，可调 0.1—100000kN；新连接默认 100kN，可调 0.1—10000kN。地基连续超载 0.3s 后下沉，速度 0.16m/s、最多 0.8m。这是整个平台的简化承载模型。
- 高度指与地基经接触或未断连接相连的结构最高点，相对运动地基测量；抛飞的块不贡献验收高度。

## 搭建交互

- 世界范围 x=-40…40m、y=0…40m，最多 160 个原始构件、400 个用户连接；支持缩放按钮、空白拖动平移、看全建筑、全屏与收起工具。
- 直接点构件编辑形状、材质、尺寸、角度；不再使用“选择积木”下拉框。新积木材质和选中积木材质分开显示。家长可做 0.1—10 倍强度/刚度对照实验，明确不是额外真实材料等级。
- 0.1m 网格与接触吸附；聚焦画布后方向键微调、R 旋转、Delete/Backspace 删除。复制、固定到地基、解除连接、清空均可撤销；保存最近 30 次编辑的会话撤销。
- 改变几何会解除该块原连接，修改材质不解除。重叠或越界拒绝并说明。限定地基时允许逐块修正旧方案，不因其他尚未移走的非法地脚阻断编辑。
- 重量、重心分别勾选。完整构件的重量写在构件中心，长条分段不重复写多份总重量；破坏后各刚体碎段显示自身实际质量。无自动音效。
- 自由实验开始有 1.5s 重力预备阶段，随后加载已选风震；可在运行中调整风震。任务实验立即开始加载；目标几何锁定至返回搭建，风震在运行侧栏可调，每次调整清空保持时间及峰值并按新参数重新验收。暂停、慢动作和后台都按有效模拟时间处理。

- 点击添加时优先以当前选中构件为基准，没有选中则使用现存列表中最后创建的构件；新块水平居中，在正上方贴合实际表面，并自动选中新块以连续堆叠。复制同样放在原块正上方。圆形与倾斜构件按实际几何求接触，不用外包矩形制造悬空缝隙；上方被占用或越界时提示腾出空间，不悄悄改放旁边。空台第一块仍放在当前视角附近（限定地基时优先地基上方）。

## 三个独立随机任务

全部关闭时自由实验，不产生通关记录。任意组合均可开启，未编辑任务由 uint32 种子确定并持久化，读取时重新计算校验；手调任务采用 layoutVersion 2 保存具体布局，不能换面板就悄悄改目标：

1. 高度：随机 4—12m，以目标线显示。
2. 坐标：x=-6…6m、y=2…6m（且低于该次目标高度），实际构件覆盖目标点；圆形、旋转长条、碎块使用实际几何，不能凭外包矩形刷过关。
3. 地基：随机一或两段亮色区。贴地构件的水平投影必须完整落入某一地基区；其他位置实际没有地面碰撞体。上方允许跨空搭桥，但坠入禁区会使条件失败。两段地基共享总承载上限。

必须所有开启条件**连续保持 10 秒模拟时间**。失去任一条件立即重置保持时间；暂停不计时，慢动作相应延长现实等待时间。显示大号剩余秒数、进度及未满足原因；成功自动暂停并弹出祝贺报告，减弱动效模式取消入场缩放。首版无金币奖励。

报告包含：持续达标时间、最高/最终高度、建筑总质量、每类形状与材质的数量/重量、风速/风向/阵风、峰值总风力、地震设定/频率与实测峰值加速度。峰值按本次从启动至成功累计；最高高度按受支持构件测量。条件每四个物理步检测一次，峰值力/加速度每个物理步采样。

## 紧凑工作台交互

材料五档显示「很弱、弱、中、强、超强」，ID 与参数不变；数字等级仍兼容旧记录。侧栏未选中时仅展开添加用材质与形状，添加后保持添加状态；点中积木后切换更换材质、带独立外框的更换形状、尺寸、旋转、属性与连接操作。「添加积木」返回添加状态并沿用刚才所选构件作为叠放基准。任务与承载默认折叠。运行/暂停时右侧显示风力、风向和震动紧凑控制，搭建时隐藏，范围仍为风速 0—60m/s、震动加速度 0—10m/s²，保留独立启停；频率 0.5—4Hz 与阵风放入运行调节区设置。自由实验可运行时调整；挑战中每次调整会清空验收进度与峰值，按新参数重新连续保持 10 秒，并更新报告所用参数，成功后禁止再改本次报告。

点击画布空白取消显式选择并回到添加面板；内部保留最近点中的积木 ID 作为叠放热点。添加后不选中，新积木成为下一次叠放热点；热点被删除或撤销时回退到最后一块有效积木，空场景采用原落点规则。此临时交互热点无需新增存档格式。

## 可编辑任务布局（layoutVersion 2）

顶部「配置任务」打开独立右侧面板，随机按钮生成高度/目标/地基并随机风速 10—35m/s、震动 1—5m/s²，随后可手调。三项条件仍独立开关，风与震动作为场景环境参数保存在 design.settings 与 view；关闭所有几何条件时仍是自由实验。任务面板可选择 1/2 段地基；滑条与画布手柄同步，方向键按 0.1m 微调。高度 .5—40m，目标 x=-40—40m/y=.1—40m，地基不得越界、重叠或互换顺序。现有积木不会被任务配置移动，贴地构件不符合地基时需先移入才能开始。

## 添加和复制的空位搜索

热点上方被占用时，新增构件保持同一 x，依次越过重叠的构件，直到找到可完整放入的上方位置；超过 40m 上边界才提示换起点。复制入口位于选中面板顶部，保留形状、材质、尺寸、旋转、强度/刚度倍率和配重属性，分配新 ID，不复制原物件与其他构件的外部连接。先搜索上方，再右侧，再全搭建台的边界/构件边缘空位候选，所有候选须满足碰撞、边界和任务地基规则。副本成为显式选择和下次叠放热点；超出当前视野时平移视角，最多 160 块限制与撤销保持有效。


## 自定义区域与关卡库（2026-10）

任务布局新增 layoutVersion=3，保留旧 seed 布局及 v2 自定义布局的解析。新增 zones（最多 24 个，稳定 ID、required/forbidden、enabled 与矩形四边界）；必经区域至少与一块获支撑的实体相交，禁入区域不能与任何实体相交，按真实圆形/凸多边形检测，破碎凸多边形用矩形裁剪，不能拿空的包围盒角当实体。所有目标跟随地基坐标系。各区域独立启停、画框添加、拖动中心、数值调整边界、删除；底部地基最多 12 段，不能重叠，随实际运动地基一起震动。关闭地基限制时恢复整片地面。删除最后一段时关闭限制。

**保留原有完整贴地规则**：接近地面的积木横向范围必须完整落在单段地基内，超宽仍禁止搭建；运行时也保留同一限制。提示改为“贴地积木超出地基范围，请加宽地基或缩短积木”，不暗示构件必然散架。上层积木不套用完整脚宽限制。首个积木按真实轮廓底部贴地，拖动预览与放下使用同一吸附规则。

关卡稳定 ID 为 physics-house-levels，文件 learning/physics/house-levels.json；通用外壳 v1，payload schemaVersion=1、levels（最多 500 条），每条包含 id、name（1—60 字符）、revision（从 1 起）、createdAt、updatedAt、workspace。服务端串行合并新 ID，默认名冲突顺延；重复请求幂等，重命名要求前一 revision+1，同名重试不重复生成，旧页面冲突拒绝覆盖。损坏、未来版本及非法输入拒绝覆盖，保存错误可按原请求重试。旧缓存、旧历史不迁入关卡库，也不被覆盖。

## 接触与互斥修正（2026-10）
新搭建、复制、吸附、保存与启动采用严格实体重叠检查，取消旧版 0.012m 穿入许可，仅保留 1e-9m 的浮点比较误差。吸附先枚举邻近接触位置，完整验证后选择，优先贴合承托面，不能按积木列表顺序反复挤入邻居。旧缓存/关卡/历史中原先合法的微小重叠可以读取供调整，运行与新写入必须通过严格校验，原存档不静默改动。

Planck 多边形自带 polygonRadius 接触皮肤；矩形、地基和凸多边形的碰撞核心向内收，使外部接触边界与显示轮廓对应。质量、质心和惯量仍从原实体轮廓计算，避免碰撞核心缩小改变材料重量和梁理论。极小破碎多边形限制内缩幅度以保留有效凸核心。物理求解仍存在数值接触容差，不能声称数学上绝对零穿透；编辑阶段拒绝实质重叠，紧密错缝砖墙须通过启动速度和位置漂移回归。

运行环境可视化：模拟快照提供实际环境风速与有符号累计风程，风线覆盖整个搭建视窗，密度 24—240 条随实际风速增大，方向/速度跟随风场与阵风；启动预热期间不提前显示风，暂停不累计风程，关闭风隐藏。地基斜条纹和轮廓共同绑定真实 ground 位移，背景网格固定参照，不放大震动或改动物理参数。系统减弱动效使用静态风线。


## 振幅控制、多选与组合预制件（2026-10）
地震面板现在常驻振幅（cm）和频率（0.5—4Hz）。新设置以 quakeAmplitude（米，可选 0—2）显式保存位移振幅；旧方案未带此字段时继续使用旧加速度/频率公式解读，第一次调整频率会把原位移振幅固化，不把旧强度数字直接当米。普通编辑振幅上限 50cm，已载入更大旧振幅保持可见可调。振幅及频率仍通过 0.8s 渐变接入，防止瞬间跳变；正弦运动中 a_peak = A(2πf)^2，同振幅 0.5Hz→2Hz 的实测加速度比约 16。真实建筑响应还取决于支撑、刚度和共振，不能保证频率越高必然越容易倒塌。地基摩擦参数由 0.7 调整为 1.4，材料间摩擦不变；保留摩擦极限和滑动，不增加粘接。相关背景见 https://www.usgs.gov/programs/earthquake-hazards/what-are-effects-earthquakes 。

搭建时「多选」模式可在空白处拖框，也可逐块点选增减，普通模式支持 Shift 点选。框选按积木外包范围与选框相交处理。选中多个后「复制整组」和 Ctrl+V 保留相对位置，重新分配所有 ID，保留组内已有连接与平移后的锚点，移除对外/地基连接，不新增连接。整体查找合法空间，逐块检查碰撞、地基与数量上限；失败不留下部分副本。单击某一块恢复单块编辑，下方属性明确仅修改最后点选块。

组合预制件折叠面板支持小房子、大高楼、三角阵列、锥形系统组合和「选中积木存为预制件」。预制件不是新的物理刚体，插入后仍是独立积木，逐块移动保持原编辑语义。自建库 physics-house-prefabs 存在仓库外 learning/physics/house-prefabs.json，通用外壳 v1，payload schemaVersion=1，最多 100 条，含 id/name/createdAt/updatedAt/design。名称最长 60 字符；服务端严格校验几何，按 ID 幂等追加，冲突拒绝覆盖；空库、损坏/未来版本保护和写失败重试均覆盖。旧缓存/关卡保留，新关卡可携带 quakeAmplitude，不重算旧报告。
