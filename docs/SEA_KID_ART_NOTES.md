# 跳海小孩：美术预览待处理事项

最初用于造型与地形讨论；正式版本已接入，规格见 `SEA_KID.md`。本文件保留当时发现的问题和处理结果。

## 投掷物必须独立于角色

用户指出第一版概念图中主角的飞出锤子、风火轮，以及青蛙水弹、章鱼水弹/墨汁、BOSS 火焰等与人物画在同一个格位中。部分喷射物直接连接嘴部，不能将整个格位直接当作正式角色动画帧。

- 正式制作时分别提供无飞出物的角色攻击姿态、独立投掷物和可选独立发射特效。
- 程序在手部/嘴部挂点生成投掷物，单独驱动位置、旋转、生命周期和碰撞。
- 不连体的投掷物可评估独立裁取；连体、遮挡轮廓或影响对齐的素材不强行抠取，重新生成干净角色帧和独立特效。
- 所有角色帧保留统一画布、身体中心、脚底基线和挂点；走路双帧需真正交换前后腿，当前概念图的两帧过于相似，不能直接视为完成的动画。
- 主角只保留两级药水强化，泳圈与滑板车独立；不生成小翅膀或独立加速道具。

## 静态路线预览

正式制作已重新生成干净角色与独立投掷物，使用整格画布和锚点绘制；源图保留，独立残片通过可复现的透明通道清理步骤去除。

预览文件为 `temp/sea-kid-routes.html`，只有预先绘制的 HTML/SVG，不含脚本、操作按钮、试玩或缓存逻辑，也不是正式产品运行时依赖。

- 展示第 1、4、8、16 大关各三个场景，另附第 8 大关大海的两条替代路线，用于比较同难度变化。
- 方块为可行走地面，三角为敌人位置示意；不代表已经实现敌人行为或碰撞。
- 前三个大关丛林、洞穴无坑，大海平台相接或近乎重叠；第八大关起洞穴 BOSS 区可有坑。
- 各路线同长度。方块数量与跳距只是评审比例，不是最终速度、物理参数或可通关验证结果；正式开发必须使用基础角色物理能力复核，包括起跳、落点、加速度与安全余量。
- 页面沿用设计系统深空/玻璃/青紫色 token；仅有静态内容与浏览器滚动，无按钮状态、加载状态或游戏结算状态。
