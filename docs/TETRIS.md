# 俄罗斯方块 · 水晶探索舱

## 入口与边界

- 主页面：`/games/tetris`，首页“游戏”区域下的“俄罗斯方块”。
- 本页无数字作答接收者，复用其他沉浸游戏的规则隐藏全局数字键盘入口；不会变更共享数字提交协议。
- 独立开发预览：Vite 启动后访问 `/tetris-preview.html`，不依赖其他玩法入口的合并进度。
- 代码独立位于 `apps/web/src/features/tetris/`；无新增依赖。人数、键盘/手柄模式、设备选择和手柄键位通过通用控制模块保存在本机，重新打开恢复。分数、棋盘、速度与游戏声音开关仍属于本次页面；全站音乐遵从全局已保存设置。
- 视觉沿用 `DESIGN_SYSTEM.md` 的“水晶方块双人棋盘”。资产由 `CrystalPiece` 与 `tetris.css` 按七种形状、设计 token、透明切面、亮边和内阴影实时绘制；无需生成或下载位图。预览方块与实际棋盘共用水晶材质。

## 棋盘、出块与下落

- 标准 10 列 × 20 行；I、O、T、S、Z、J、L 七种四格方块。每七块洗牌一次；双人各持有同一种子、独立状态的随机生成器，因此整个方块序列一致，操作与消行互不影响。
- 显示三个后续方块和虚线落点。左右移动、顺/逆时针旋转、单步下移与直落可用；墙边和底部旋转允许有限偏移，不能穿过已有方块。不声称实现竞赛 SRS 或 T-spin 规则。
- 初始速度及每级增速均接受 0—100 的整数，默认均为 0；非法、空值、小数或超范围输入禁止开始。开始后本局设置锁定，重新设置先暂停再确认。
- 等级 `1 + floor(消行总数 / 20)`；速度 `min(100, 初始速度 + floor(消行总数 / 20) × 每级增速)`，不存在强制最低速度。
- 速度大于 0 时每格间隔 `5000 / 速度` 毫秒，速度 100 为 50ms/格，从顶部到底部约 0.9—1 秒；速度 0 时不自动移动也不自动固定。两项均设为 0 为持续手动模式；初始 0、增速非 0 会在首次升级后开始自动下落。
- 自动下落遇阻则固定。手动下移遇阻也固定；直落一次移动到落点并立即固定。固定后逻辑一次结算满行并准备下一块；界面保留固定后快照，在约 1040ms 内依次从左到右出现裂纹（每列间隔 55ms）、整行下坠淡出（600—800ms）、上方积木下移归位（800—1040ms），随后显示下一块。动画期间该棋盘不接收操作、不推进重力，另一名玩家可继续；暂停冻结动画，减弱动效直接显示结果。新方块区域受阻则该玩家结束，另一名玩家可以继续。
- 帧间隔最多累计 250ms，避免卡顿后突然追赶；隐藏页面或窗口失焦自动暂停，返回后需主动继续。暂停清除按住状态，不累计下落时间。

## 键盘与触控

| 动作 | 玩家 1 | 玩家 2 |
| --- | --- | --- |
| 左移 / 右移 | A / D | ← / → |
| 下移 | S | ↓ |
| 变形（顺时针） | J | N |
| 逆时针旋转（左旋） | K | M |
| 立即直落 | W | Enter |
| 全局暂停 / 继续 | P 或 Escape | P 或 Escape |

- 赛前展开“键盘设置 · 自由换键”，进行中打开“键盘 / 手柄设置”会先暂停。每个动作均可换成字母、数字、方向键、空格等单键；P、Escape、Tab 和修饰键保留。双人共用一套物理键盘命名，重复键位给出冲突说明，可明确点击“互换这两个键位”，无需先切换双人模式；支持取消和恢复默认。屏幕按钮同步显示实际键位。
- 键位单独写入浏览器 localStorage 的 `mumu.tetris.keyboard.v1`，包含 schemaVersion 1、stableId、createdAt、updatedAt 和完整双人绑定。首次使用默认值；损坏或未知版本只降级到默认并提示，不自动覆盖原记录；用户主动改键/恢复默认/再次保存后写入。读取和写入异常不影响本页操作，保存失败提供重试；不包含学习记录，不迁移原服务端手柄设置。清理浏览器缓存后回到默认键位。
- 使用物理 `KeyboardEvent.code`；左右、下移独立计时连发，不依赖操作系统重复最后一个键。旋转和直落每次按下执行一次。键盘、屏幕按钮和手柄下移都绑定按下时的积木身份，固定后长按不再推动下一块，必须松开重按；消行动画中按住下移也不转移到下一块。横移仍可连发。暂停、失焦与重开清理长按。
- 文本、数字输入、按钮、链接及编辑区域不被游戏快捷键接管；开始、继续和触控操作后焦点回游戏区。Tab 仍可正常操作控件。
- 两人各有六个 48px 以上的触控按钮。宽屏并排，窄屏纵向排列；两个棋盘不叠放。

## 手柄控制

复用 `shared/controllers/`，动作注册位于 `controls.ts`。详细研究、接入合同、默认配置与本机保存格式见 [GAME_CONTROLLERS.md](GAME_CONTROLLERS.md)。默认操作：

| 动作 | 标准手柄 |
| --- | --- |
| 左 / 右 / 下移 | 十字键或左摇杆对应方向 |
| 右旋 | 下方键 A / × |
| 左旋 | 左侧键 X / □ |
| 直落 | 上方键 Y / △ |
| 暂停 / 继续 | 菜单 / Start |

右侧键 B / ○、方向向上、肩键等默认不绑定，可自行换键。每次按旋转/直落只执行一次；横移按住 170ms 后每 75ms 一次，下移每 50ms 一次。双人同时按菜单只切换一次暂停，暂停同一帧不执行移动。手柄和对应键盘始终可并用。

赛前清楚选择人数与每位玩家的输入方式，支持双键盘、双手柄或键盘加手柄。进行中“手柄设置”先暂停；人数在本局锁定，调整输入设备和键位不会清空棋盘。完成设置后主动继续，断开也暂停；每次恢复先松开按键再继续操作。开始游戏仍点击页面按钮，使音频有明确用户激活入口。

## 分数

一次消除 1 / 2 / 3 / 4 行，分别获得 `100 / 300 / 500 / 800 × 清除前等级` 分。手动成功下移每格 1 分，直落实际移动每格 2 分，自动下落不加分。只消行才升级；没有攻击行、惩罚扣分、知识币或能力排名。两位玩家结束后分别展示消行数和得分。

## 中英表扬

- `praise.ts` 维护 60 对简短自然的中英表扬。洗牌轮转，60 对全部使用后重新洗牌，轮次交界也避免连续同一句。偏重尝试、思考、耐心和进步。
- 每清除一行生成一个表扬事件；同时清除四行生成四个，不合并为一次。双方共用轮转选择器和顺序播放调度，避免说话重叠。静音时仍显示双语文字。
- 页面载入不发声；顶部“表扬声音”默认关闭，明确开启并开始游戏后按“中文 → 英文”播放。调用统一 `speakLearningMoment(praise, "bilingual")`，不自行创建语音实例或请求其他 TTS 服务。
- `PraisePlayback` 仅管理待播放的消行事件；语种选择、语音队列、发声、超时和降级均由共享 speech/experience 服务负责。暂停保留未完成事件，继续时重播完整的这一组；静音、重新设置、重开与离页取消待播。音频不可用时保留文字和玩法，显示温和提示与“再试朗读”入口。
- 快速连续消行会积累待播事件，页面显示剩余组数；不打断当前英文，也不同时播放多句。这里不接入 ASR，不申请麦克风。

## 验证

`logic.test.ts` 覆盖非法配置、空棋盘、零速触底、等级边界、100 速度、1—4 行计分、清行位移、落点、旋转碰撞、七袋公平、双人隔离、堆满终局与 100 个种子模拟。

`praise.test.ts` 覆盖 60 对完整性、不重复轮转、双方共五行顺序朗读、静音、暂停重播、关闭清队列以及声音错误/取消时不无限重试。

`keyboard.test.ts` 覆盖默认、换键恢复、非法或未知版本、重复动作、元数据和浏览器读写失败。

`input.test.ts` 覆盖积木切换后长按隔离、松开重按、触控和消行期间按下保护，以及双方同时按住独立连发、松开一人不影响另一人、下移/横移分别计时、旋转与直落不连发以及暂停清除按住状态。

控制偏好的非法输入、空记录、增量迁移、读写失败与恢复通过共享模块及服务器临时目录测试覆盖。实机验收还需检查所用浏览器的中英声音、两个实体键盘/手柄同时按键及不同屏幕尺寸下的实际观感。

## 音乐与操作音效

- 顶栏提供独立“音乐”和“音效”开关；音乐默认关闭，按本次需求操作音效默认开启，但仅主动开始后发声。赛前打开后，主动开始游戏才发声；进行中可以直接开关。循环音乐、移动、旋转、落地、消行、升级都有独立素材。只有成功移动/旋转产生反馈，自动下落没有逐格提示声。
- 音效与游戏逻辑事件一致；每次固定都有落地声，消行另播放破损声，升级另加庆祝声；变形仅在实际成功旋转时播放。每类最多三个并行音效，移动限流 65ms，其他限流 45ms，避免双人长按造成爆音。
- 中英表扬待播时，音乐从 0.24 降到 0.06，操作音效降到原音量的 40%；待播结束后恢复。暂停、窗口失焦、结算和离页停止游戏音频；继续时音乐从暂停位置恢复，重开从开头播放。
- 播放失败只显示温和说明，不影响操作、计分和表扬文字。播放 Promise 的迟到回调不能在静音或离页后重新发声。
- 当前发行文件为六份许可明确的 CC0 音频：wipics 的 City Loop 循环音乐、Kenney Digital Audio 的移动/旋转/消行/升级音，以及 qubodup 的温和落地声。音效裁短并淡入淡出，音乐保持原件。
- 素材复用仓库现有、已校验 SHA-256 的 CC0 原件，并在网上重新核对许可页。`scripts/prepare-tetris-audio.mjs` 可使用本机 ffmpeg 离线重建派生文件；完整来源和摘要见 `apps/web/public/audio/tetris/SOURCES.md` 与 `manifest.json`。
- `audio.test.ts` 验证主动开始门槛、开关、并行播放限制、表扬时降音量、暂停/离页、异步失败与迟到回调，以及六个音频文件的格式、摘要和有效音量。

## 全屏沉浸模式

- 开始后点击顶栏“全屏游戏”，复用 `useGameFullscreen`；只将当前俄罗斯方块容器放入原生全屏，拒绝或不支持时保持等价的满窗口布局。退出按钮和 Escape 均可返回，P 继续用于暂停；切换不重置棋盘、分数、随机序列或键位。
- 全屏主区固定为当前窗口高度：轻量工具栏、剩余空间中的完整棋盘、三块预览、得分/等级/速度/消行/升级进度、双语表扬和六个大号操作按钮。棋盘按容器剩余宽高等比缩放；宽屏双人并排，600px 以下双人上下分配空间。矮屏信息改为紧凑排列，保留实际速度数值，省略重复的“/100”和手动模式说明。不渲染站点入口、长篇规则及外围全站浮钮。
- “游戏设置”先暂停，使用原生模态提供音乐、音效、表扬、键盘和手柄设置，完成后主动继续；长设置仅在模态内滚动，游戏区不滚动。设置内 Escape 关闭模态（改键时先取消捕获），不会同时切换暂停。重新设置需确认并退出全屏后回赛前页；结算保留再玩一次和退出。
- 全屏入口与退出在切换期间禁用，返回恢复原页滚动能力，焦点不落到隐藏控件。继续游戏后键盘焦点回棋盘；页面隐藏或失焦仍沿用自动暂停。全屏不新增声音、不改动保存格式，减弱动效沿用原规则。
- 浏览器验收覆盖桌面、390×844 竖屏、844×390 横屏及 320×568 小窗口的双人布局，检查棋盘和信息栏不重叠、底部按钮完整、容器无滚动溢出，及 Escape/退出、设置暂停与返回后的棋盘保持。
