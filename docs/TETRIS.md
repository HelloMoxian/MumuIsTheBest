# 俄罗斯方块 · 水晶探索舱

## 入口与边界

- 主页面：`/games/tetris`，首页“游戏”区域下的“俄罗斯方块”。
- 本页无数字作答接收者，复用其他沉浸游戏的规则隐藏全局数字键盘入口；不会变更共享数字提交协议。
- 独立开发预览：Vite 启动后访问 `/tetris-preview.html`，不依赖其他玩法入口的合并进度。
- 代码独立位于 `apps/web/src/features/tetris/`；无新增依赖。人数、键盘/手柄模式、设备选择和手柄键位通过通用控制模块保存在本机；本局棋盘、当前/后续积木、随机袋、分数、行数、速度配置与阶段通过浏览器缓存恢复。全站音乐遵从全局已保存设置。
- 视觉沿用 `DESIGN_SYSTEM.md` 的“水晶方块双人棋盘”。顶部“方块外观”下拉菜单提供默认配色、经典 FC 配色、晶莹剔透、随机水晶、随机宝石、小笑脸、立体方块、扁球体和纯色九种方案；预览、棋盘、统计图标与赛前造型同步切换。默认方案保留原有设计 token、透明切面、亮边和内阴影；经典 FC 使用 I 青、O 黄、T 紫、S 绿、Z 红、J 蓝、L 橙的高饱和色；纯色方案由 CSS 绘制。
- 六种材质方案复用 ImageGen 生成的一张 7 列 × 6 行精灵图集，运行时逐格裁掉透明空边、归一化为对称轮廓，并缩小为 672 × 576 WebP（每格 96 × 96，约 49KB），只发起一次图片请求；生成提示词与处理说明见 [`assets/game/tetris/ART.md`](../assets/game/tetris/ART.md)。图片材质在棋盘、后续预览和统计图标中保留 1px 细缝，放大的“下一个”预览保留 2px 细缝；所有方案仍只替换单个基础小格子的颜色或表面材质，每格独立渲染，本版不实现落地后按连通块拆分、连接纹理或自动拼接边缘。

## 棋盘、出块与下落

- 标准 10 列 × 20 行；I、O、T、S、Z、J、L 七种四格方块。每七块洗牌一次；双人各持有同一种子、独立状态的随机生成器，因此整个方块序列一致，操作与消行互不影响。
- 显示三个后续方块和虚线落点。单人宽屏的普通模式和全屏模式都把最近的下一块单独放在棋盘右侧，水晶小格与棋盘小格接近同尺寸，后两块仍并排放在预览区底部。预览只在上、中、下三个固定区域间切换：已落定积木的最高占用行为 0—6 时在上区、7—13 时在中区、14—19 或空棋盘时在下区；不逐行跟随，避免视线跳动。等级、速度、消行和升级进度面板避让预览：上区时排在其下，中区时固定到底部，下区时排在其上。左右移动、顺/逆时针旋转、单步下移与直落可用；墙边和底部旋转允许有限偏移，不能穿过已有方块。不声称实现竞赛 SRS 或 T-spin 规则。
- 初始速度及每级增速均接受 0—100 的整数，默认均为 0；非法、空值、小数或超范围输入禁止开始。开始后本局设置锁定，重新设置先暂停再确认。
- 等级 `1 + floor(消行总数 / 20)`；速度 `min(100, 初始速度 + floor(消行总数 / 20) × 每级增速)`，不存在强制最低速度。
- 速度大于 0 时每格间隔 `5000 / 速度` 毫秒，速度 100 为 50ms/格，从顶部到底部约 0.9—1 秒；速度 0 时不自动移动也不自动固定。两项均设为 0 为持续手动模式；初始 0、增速非 0 会在首次升级后开始自动下落。
- 自动下落遇阻则固定。手动下移遇阻也固定；直落一次移动到落点并立即固定。固定后逻辑一次结算满行并准备下一块；界面保留固定后快照，在约 420ms 内让每格以 22ms 间隔从左向右碎裂、扫光和淡出，上方积木从 150ms 起同步下移归位，整体时间不因逐格效果延长。碎裂与下移动画交给 CSS 合成层执行，React 只渲染动画开始和结束，不按屏幕帧率重复计算整块棋盘或写存档。动画期间该棋盘不接收操作、不推进重力，另一名玩家可继续；暂停冻结动画，减弱动效直接显示结果。新方块区域受阻则该玩家结束，另一名玩家可以继续。
- 帧间隔最多累计 250ms，避免卡顿后突然追赶；隐藏页面或窗口失焦自动暂停，返回后需主动继续。暂停清除按住状态，不累计下落时间。

## 键盘与触控

| 动作 | 玩家 1 | 玩家 2 |
| --- | --- | --- |
| 左移 / 右移 | A / D | ← / → |
| 下移 | S | ↓ |
| 变形（顺时针） | J | N |
| 逆时针旋转（左旋） | K | M |
| 立即直落 | W | Enter |
| 全局暂停 / 继续 | P 或 Escape | P 或 Escape |

- 赛前展开“键盘设置 · 自由换键”，进行中打开“键盘 / 手柄设置”会先暂停。每个动作均可换成字母、数字、方向键、空格等单键；P、Escape、Tab 和修饰键保留。双人共用一套物理键盘命名，重复键位给出冲突说明，可明确点击“互换这两个键位”，无需先切换双人模式；支持取消和恢复默认。屏幕按钮同步显示实际键位。
- 键位单独写入浏览器 localStorage 的 `mumu.tetris.keyboard.v1`，包含 schemaVersion 1、stableId、createdAt、updatedAt 和完整双人绑定。首次使用默认值；损坏或未知版本只降级到默认并提示，不自动覆盖原记录；用户主动改键/恢复默认/再次保存后写入。读取和写入异常不影响本页操作，保存失败提供重试；不包含学习记录，不迁移原服务端手柄设置。清理浏览器缓存后回到默认键位。
- 使用物理 `KeyboardEvent.code`；左右、下移独立计时连发，不依赖操作系统重复最后一个键。下移首次轻按只走 1 格；持续按住后的每次连发依次走 2、3、4、5 格并封顶 5 格，键盘、触控和手柄节奏一致。旋转和直落每次按下执行一次。所有下移输入绑定按下时的积木身份，固定后长按不再推动下一块，必须松开重按；消行动画中按住下移也不转移到下一块。横移仍可连发。暂停、失焦与重开清理长按。
- 文本、数字输入、按钮、链接及编辑区域不被游戏快捷键接管；开始、继续和触控操作后焦点回游戏区。Tab 仍可正常操作控件。
- 两人各有六个 48px 以上的触控按钮。宽屏并排，窄屏纵向排列；两个棋盘不叠放。
- 鼠标横向跟随始终可用，但只响应真实的鼠标移动事件：鼠标静止时，键盘或手柄移动、出下一块和界面刷新都不会把积木拉回鼠标所在列。棋盘所在列从左侧留白到右侧留白均为感应和点击热区；移到棋盘左/右之外分别锁定最左/最右边缘，点击任一热区都会在当前指向位置直落。双人时只影响指针所在玩家的棋盘。
- 原“鼠标模式”改名为可选的“最佳匹配”。未勾选时，鼠标只改变当前形状的横向位置，不旋转、不结合堆叠微调；勾选后沿用原鼠标模式规则：在覆盖指针相邻两列的合法旋转与横向位置中，先选新增纵向空腔最少、再选落得更深的方案。移动只预摆当前积木，点击才固定，不会自动连续落块。

## 手柄控制

复用 `shared/controllers/`，动作注册位于 `controls.ts`。详细研究、接入合同、默认配置与本机保存格式见 [GAME_CONTROLLERS.md](GAME_CONTROLLERS.md)。默认操作：

| 动作 | 标准手柄 |
| --- | --- |
| 左 / 右 / 下移 | 十字键或左摇杆对应方向 |
| 右旋 | 下方键 A / × |
| 左旋 | 左侧键 X / □ |
| 直落 | 上方键 Y / △ |
| 暂停 / 继续 | 菜单 / Start |

右侧键 B / ○、方向向上、肩键等默认不绑定，可自行换键。每次按旋转/直落只执行一次；横移按住 170ms 后每 75ms 一次，下移每 50ms 一次。双人同时按菜单只切换一次暂停，暂停同一帧不执行移动。手柄和对应键盘始终可并用。

赛前清楚选择人数与每位玩家的输入方式，支持双键盘、双手柄或键盘加手柄。进行中“手柄设置”先暂停；人数在本局锁定，调整输入设备和键位不会清空棋盘。完成设置后主动继续，断开也暂停；每次恢复先松开按键再继续操作。开始游戏仍点击页面按钮，使音频有明确用户激活入口。

## 本局缓存与继续

- 浏览器键 `mumu.tetris.session.v1` 保存 schemaVersion、stableId、savedAt、阶段和一至两个完整玩家状态。玩家状态包含 10×20 棋盘、当前积木类型/旋转矩阵/坐标、后三块、七袋余量与随机种子、分数、行数、速度配置、下落计时、积木序号、终局状态及尚未结束的消行动画快照。
- 本轮统计随同棋局保存；累计与当天统计独立保存在 `mumu.tetris.statistics.v1`，最佳匹配与方块外观保存在 `mumu.tetris.preferences.v1`。偏好内容升级为 schemaVersion 2；旧版 `mouseMode` 原值迁移为 `bestMatch`，旧偏好没有外观字段时迁移到默认配色，未知外观值按损坏偏好处理。统计写入使用本轮快照增量，恢复棋局不会重复累计；自然日按本机日期切换，只清空“今日”，不影响累计和恢复中的本轮。
- 开始、移动、旋转、下落、自动下落、消行、暂停、结束和页面离开都会更新缓存；连续帧写入最多约每 90ms 一次，页面离开强制保存。再次打开时，进行中的对局统一以暂停状态恢复，由玩家主动继续；完成局恢复结算分数与棋盘。
- 读取时严格校验棋盘尺寸、格子种类、四格矩阵、数值范围、随机袋、速度和动画数据。损坏或未知记录只显示提示，不覆盖原缓存；新开一局后重新写入。确认“重新设置”清除旧进度，键位和通用手柄偏好仍独立保留。

## 分数

一次消除 1 / 2 / 3 / 4 行，分别获得 `100 / 300 / 500 / 800 × 清除前等级` 分。手动成功下移每格 1 分，直落实际移动每格 2 分，自动下落不加分。只消行才升级；没有攻击行、惩罚扣分、知识币或能力排名。两位玩家结束后分别展示消行数和得分。

## 落块统计与完美率

- 七种积木分别统计累计出现次数及其占全部积木的比例；同时展示累计、今日、本轮三个范围的整体完美率和单种积木完美率。顶部整体完美率固定显示两位小数，单种积木面板内的出现占比及三个完美率全部四舍五入为整数。积木图标按统一基础小格尺寸绘制，I 形的 4×4、常规形状的 3×3 和 O 形的 2×2 外框宽度随网格数变化，不通过压缩小格塞入等宽容器。出现次数在积木正式进入棋盘成为当前块时增加，预览队列不计数；完美率分母只包含已经固定的积木，尚未落下的当前块不进入分母。
- 每次落子触发的实际消行数归属于该次落子的积木种类，例如 T 形一次消除 3 行就为 T 形增加 3 行。单块列表把累计出现次数和累计归属消行数画成两条共用同一最大值、单位长度一致的进度条，因此条长可以直接比较；旧版统计没有该字段时安全迁移为零，后续按累计、今日和本轮增量持续落盘。
- 另按一次固定同时消除 1、2、3、4 行分别累计事件次数；界面以四张紧凑卡片展示累计、今日和本轮，不把“消除四行一次”误记成四次单行。
- 空腔只按纵向单列判断，不计算左右连通性：从每列最上方第一个已有方块开始，其下每个空格都算一个空腔。完美落块表示本次结算后没有比落子前新增空腔。
- 完美判定先放置积木，再完成由这次落子触发的消行和整体下落，最后与落子前比较空腔数。因此临时形成的空腔若随本次消行消失，仍记为完美；填掉旧空腔或保持空腔数不变也记为完美。整体完美率显示到小数点后两位，单种积木完美率取整；无已固定积木时显示破折号。
- 统计面板提供“清空统计”，二次确认后同时清空累计、今日和当前一至两位玩家的本轮统计，但保留棋盘、分数和操作设置；清空结果立即覆盖写入浏览器持久存储与本局存档。正常落块、消行、暂停和离页也持续落盘，刷新或重新打开不会丢失已提交统计。

## 中英表扬

- `praise.ts` 维护 60 对简短自然的中英表扬。洗牌轮转，60 对全部使用后重新洗牌，轮次交界也避免连续同一句。偏重尝试、思考、耐心和进步。
- 每清除一行生成一个表扬事件；同时清除四行生成四个，不合并为一次。双方共用轮转选择器和顺序播放调度，避免说话重叠。静音时仍显示双语文字。
- 页面载入不发声；顶部“表扬声音”默认关闭，明确开启并开始游戏后按“中文 → 英文”播放。调用统一 `speakLearningMoment(praise, "bilingual")`，不自行创建语音实例或请求其他 TTS 服务。
- `PraisePlayback` 仅管理待播放的消行事件；语种选择、语音队列、发声、超时和降级均由共享 speech/experience 服务负责。暂停保留未完成事件，继续时重播完整的这一组；静音、重新设置、重开与离页取消待播。音频不可用时保留文字和玩法，显示温和提示与“再试朗读”入口。
- 快速连续消行会积累待播事件，页面显示剩余组数；不打断当前英文，也不同时播放多句。这里不接入 ASR，不申请麦克风。

## 验证

`logic.test.ts` 覆盖非法配置、空棋盘、零速触底、等级边界、100 速度、1—4 行计分、清行位移、落点、旋转碰撞、七袋公平、双人隔离、堆满终局与 100 个种子模拟。

`praise.test.ts` 覆盖 60 对完整性、不重复轮转、双方共五行顺序朗读、静音、暂停重播、关闭清队列以及声音错误/取消时不无限重试。

`keyboard.test.ts` 覆盖默认、换键恢复、非法或未知版本、重复动作、元数据和浏览器读写失败。

`input.test.ts` 覆盖积木切换后长按隔离、松开重按、触控和消行期间按下保护，以及双方同时按住独立连发、松开一人不影响另一人、下移/横移分别计时、旋转与直落不连发以及暂停清除按住状态。

控制偏好的非法输入、空记录、增量迁移、方块外观旧记录迁移与未知方案拒绝、读写失败与恢复通过共享模块及服务器临时目录测试覆盖。实机验收还需检查所用浏览器的中英声音、两个实体键盘/手柄同时按键及不同屏幕尺寸下的实际观感。

## 音乐与操作音效

- 顶栏提供独立“音乐”和“音效”开关；音乐默认关闭，按本次需求操作音效默认开启，但仅主动开始后发声。赛前打开后，主动开始游戏才发声；进行中可以直接开关。循环音乐、移动、旋转、落地、消行、升级都有独立素材。只有成功移动/旋转产生反馈，自动下落没有逐格提示声。
- 音效与游戏逻辑事件一致；每次固定都有落地声，消行另播放破损声，升级另加庆祝声；变形仅在实际成功旋转时播放。每类最多三个并行音效，移动限流 65ms，其他限流 45ms，避免双人长按造成爆音。
- 中英表扬待播时，音乐从 0.24 降到 0.06，操作音效降到原音量的 40%；待播结束后恢复。暂停、窗口失焦、结算和离页停止游戏音频；继续时音乐从暂停位置恢复，重开从开头播放。
- 播放失败只显示温和说明，不影响操作、计分和表扬文字。播放 Promise 的迟到回调不能在静音或离页后重新发声。
- 当前发行文件为六份许可明确的 CC0 音频：wipics 的 City Loop 循环音乐、Kenney Digital Audio 的移动/旋转/消行/升级音，以及 qubodup 的温和落地声。音效裁短并淡入淡出，音乐保持原件。
- 素材复用仓库现有、已校验 SHA-256 的 CC0 原件，并在网上重新核对许可页。`scripts/prepare-tetris-audio.mjs` 可使用本机 ffmpeg 离线重建派生文件；完整来源和摘要见 `apps/web/public/audio/tetris/SOURCES.md` 与 `manifest.json`。
- `audio.test.ts` 验证主动开始门槛、开关、并行播放限制、表扬时降音量、暂停/离页、异步失败与迟到回调，以及六个音频文件的格式、摘要和有效音量。

## 全屏沉浸模式

- 普通模式在 1440px 及以上宽屏使用与全屏近似的棋盘、预览、统计三栏：页面最多利用 1800px 宽度，棋盘随视口放大至约 520px 宽，统计栏扩展至约 590px；侧栏状态始终限制在三栏区域内。中等宽度继续使用紧凑三栏，窄屏再把统计移动到下一行，不允许等级/速度面板溢出到提示和操作按钮区域。

- 开始后点击顶栏“全屏游戏”，复用 `useGameFullscreen`；只将当前俄罗斯方块容器放入原生全屏，拒绝或不支持时保持等价的满窗口布局。退出按钮和 Escape 均可返回，P 继续用于暂停；切换不重置棋盘、分数、随机序列或键位。
- 全屏主区固定为当前窗口高度：轻量工具栏、剩余空间中的完整棋盘、大号下一块与底部两块预览、得分/等级/速度/消行/升级进度、落块统计、双语表扬和六个大号操作按钮。单人宽屏使用棋盘、预览、统计三栏并利用两侧空间；双人或窄屏优先保证棋盘和控制完整，详细统计仍可在普通页面查看。棋盘按容器剩余宽高等比缩放；600px 以下双人上下分配空间。矮屏信息改为紧凑排列，保留实际速度数值。不渲染站点入口、长篇规则及外围全站浮钮。
- 当前实际速度为 0 时不显示顶栏暂停按钮；页面隐藏、窗口失焦、设置弹窗及恢复存档仍可进入暂停状态，并通过棋盘中央的“继续游戏”恢复。速度因升级从 0 变为正数后，暂停按钮随当前状态出现。
- “游戏设置”先暂停，使用原生模态提供音乐、音效、表扬、键盘和手柄设置，完成后主动继续；长设置仅在模态内滚动，游戏区不滚动。设置内 Escape 关闭模态（改键时先取消捕获），不会同时切换暂停。重新设置需确认并退出全屏后回赛前页；结算保留再玩一次和退出。
- 全屏入口与退出在切换期间禁用，返回恢复原页滚动能力，焦点不落到隐藏控件。继续游戏后键盘焦点回棋盘；页面隐藏或失焦仍沿用自动暂停。全屏不新增声音、不改动保存格式，减弱动效沿用原规则。
- 浏览器验收覆盖桌面、390×844 竖屏、844×390 横屏及 320×568 小窗口的双人布局，检查棋盘和信息栏不重叠、底部按钮完整、容器无滚动溢出，及 Escape/退出、设置暂停与返回后的棋盘保持。
