# 实验大师玩法规范

状态：**正式生效**

## 1. 功能定位

“实验大师”是安全的虚拟科学观察玩法。孩子不接触真实化学材料，通过“先预测、再观察、最后解释”理解基础物质现象。

- 内容覆盖溶解、过滤、蒸发、密度分层、凝结、酸碱指示、气体占据空间、结晶、磁性分离和净水流程。
- 页面展示的是教学观察示意，不是现实实验步骤。
- 不提供危险材料的用量、温度、压力、混合顺序或家庭操作方法。

## 2. 一局流程

1. 孩子选择 5 题或 10 题。
2. 页面一次只展示一个观察任务和三个大号候选项。
3. 孩子先作预测；第一次未选中时显示温和提示，并允许继续观察。
4. 找到答案后展示准确结论和儿童可理解的原因，不自动跳题。
5. 孩子主动进入下一题；中途结束只总结已经完成的发现。

结算区分“第一次发现”和“观察后发现”，不使用生命值、连败、倒计时或羞辱性措辞。

## 3. 内容结构

课程数据位于 `apps/web/src/features/mission-lab/curricula.ts`。每个任务必须包含：

- 稳定且唯一的 ID；
- 清楚的问题、提示、结论和解释；
- 可操作候选项与唯一答案；
- 与问题一致的观察示意；
- 适合语音识别的候选项文字或别名。

课程必须至少包含 10 个互不重复任务，以支持 5 题和 10 题随机局。科学结论使用稳定的教材级事实；模型或流程有简化时必须明确说明。

## 4. 语音与朗读

- 实时语音统一复用阿里云 Fun-ASR 同源转接，每段强制最多 600 秒。
- 支持“开始、下一题、再听一遍、结束、继续识别”和候选项序号或文字。
- 文字朗读统一复用 `apps/web/src/shared/speech/`，朗读与识别保持半双工。
- 语音不可用时，大按钮和键盘仍能完成全部流程。

## 5. 数据与安全

- 默认课程属于版本化产品内容，不包含孩子个人信息。
- 当前玩法不写入学习历史；未完成的一局只存在页面内存中。
- 真实饮用水处理、化学分离和酸碱判断都比教学示意更复杂，解释不得暗示页面可以代替实验室规范或饮用水标准。

## 6. 验收要求

- 课程 ID 和答案合法且不重复；5 题、10 题抽取不重复。
- 鼠标、触控、键盘和无语音环境均可完成任务。
- 默认、悬停、按下、焦点、禁用、提示、完成和空状态遵循 `DESIGN_SYSTEM.md`。
- 移动端不出现横向溢出；减弱动效模式停止持续漂浮和扫描动画。
- 合并前通过类型检查、单元测试和生产构建。
