# 全局界面语言与学习语义朗读

状态：**全局能力已实现**

## 目标与边界

正式应用在每个页面顶部提供统一的界面语言与朗读模式，孩子切换后无需刷新即可继续当前任务。界面翻译使用随应用发布的本地静态词条，不依赖运行时网络翻译，不上传页面内容。

本能力只翻译产品 UI 与面向孩子的讲解。阿拉伯数字算式、化学式、元素符号、拼音本体和识字任务中的单个目标汉字保持原样，避免改变学科事实或答案协议。

## 界面模式

- 中：完整保留现有中文界面，也是首次打开的默认值。
- 英：显示儿童可理解的英文界面。
- 中英：先显示完整中文行或语义段，再另起一行显示英文；不能在一个标题中穿插两个语言的片段。

选择写入浏览器本地偏好，并通过共享状态与 DOM 本地化层立即应用到当前路由。动态加入的反馈、弹层和题目辅助文案同样接受本地化；纯数字题目不改写。

## 朗读模式

朗读模式固定为 无 / 中 / 英 / 中英，默认中英。中英模式必须等中文完整结束后再读英文；切换模式立即作用于下一条学习语义，选择“无”会停止当前朗读。浏览器没有对应声音时只降低声音能力，不能阻止作答或清空进度。

所有短语义统一由 apps/web/src/shared/experience/learning-speech.ts 生成，再交给 apps/web/src/shared/speech/ 的浏览器 TTS 服务。业务模块不得自行创建 SpeechSynthesisUtterance 或朗读整页 DOM。

## 开场磨耳朵

页面加载本身不播放声音。应用打开后，孩子第一次点击或键盘触发有效功能时，在该用户手势后随机播放一条短问候，例如“你好，木木 / Hello, Mumu”或“我们开始学习吧 / Let's start learning”。固定中文在前、英文在后，同一浏览器标签页只播放一次；“无”模式不播放。

若第一次操作是站内页面导航，先完成问候再进入目标页面，避免导航中断声音。离站链接和非功能区空白点击不触发问候。

## 玩法语义矩阵

| 玩法或模块 | 学习动作 | 中文与英文朗读内容 |
| --- | --- | --- |
| 加减练习、算数大战、乘法小能手 | 答案正确 | 完整算式、等号和结果，例如“四加三等于七 / four plus three equals seven” |
| 找数字 | 找到目标 | 神秘数字和本局提问次数 |
| 猫鼠游戏 | 列式正确 | 图片中的数量关系、答案、单位和完整算式 |
| 神秘函数 | 发现新曲线 | 函数名称、公式和下一步探索提示 |
| 拼音星桥 | 打开音节 | 当前拼音和关联汉字示例 |
| 常用汉字 | 揭示答案 | 汉字、拼音、含义和例句 |
| 元素周期表 | 打开元素 | 中英文名称、元素符号和原子序数 |
| 反应熔炉、分子工厂 | 成功组合 | 物质名称和化学式 |
| 实验大师 | 完成观察 | 观察结论和儿童可理解的解释 |
| 物质塔 | 解锁节点 | 节点名称、所在路径和解锁结果 |
| 国学长阅读 | 主动点读 | 继续使用页面已有的句子级长文朗读、暂停和停止能力 |

算式解析支持加、减、乘、除，数字先转换为目标语言的自然读法，运算符再转换为“加、减、乘、除以”和 plus / minus / times / divided by。可见题面始终保留阿拉伯数字。

## ASR 半双工

同时使用阿里云 ASR 的页面严格执行“停止旧 ASR → 播放学习语义 → 朗读结束 → 新建 ASR”。朗读被切题、离页或新语义取消后，旧流程不得重新打开麦克风。TTS 不可用或出错时允许直接恢复可见任务与 ASR。

## 验证要求

- 单元测试覆盖静态和动态翻译、双语换行、纯阿拉伯数字题目不改写、数字读法及完整算式语义。
- 桌面与窄屏实际浏览器检查三种界面即时切换、顶栏触控与横向滑动、英文长标题换行和页面无横向溢出。
- 人工检查首次功能操作只问候一次，无模式静音，中英朗读顺序正确，连续作答不会重叠发声。
- 每个接入 ASR 的玩法检查声音与麦克风不同时运行，离页后不残留声音或识别会话。
