# 大学 Top100

## 1. 页面与导航

- 首页一级学科舱名称：`规划`，与自然、语文、国学平级；
- 规划舱内入口名称：`大学`；
- 大学功能页名称：`Top100`；
- 正式路由：`/universities/top100`
- 兼容路由：`/university/top100`

“大学”不得出现在首页屏幕顶部的全局导航中。孩子从首页“规划”学科舱点击“大学”入口后进入 Top100 页面；页面层级说明统一写作 `规划 / 大学 / Top100`。

页面是公开资料查阅页，不记录儿童成绩、搜索词或浏览历史，也不自动播放声音。

## 2. 分类与榜单语义

2025 年榜单严格沿用软科世界一流学科排名的两层分类：

- 一级领域：理学、工学、生命科学、医学、社会科学，共 5 类；
- 二级专业：共 57 个；
- 默认打开：工学 / 人工智能，与需求中提供的原始页面一致。

每个专业保留来源页面中名次起点不超过 100 的全部记录，包括 `51-75`、`76-100` 等名次区间。绝大多数专业有 100 所大学；若来源只发布较短榜单，则按来源实际数量展示，不补齐、不重新编号、不推算缺失总分。

## 3. 数据字段与来源

运行时目录位于 `apps/web/public/data/university-rankings-2025.json`，当前 schema 为 `1`。文件包含：

- 5 个领域与 57 个专业；
- 大学代码、中文名、国家/地区、校徽链接和来源资料页链接；
- 原始名次、总分和五项指标；
- 国家/地区名称与旗帜图片链接；
- 抓取时间、原始榜单地址和来源说明。

榜单和校徽链接来自[软科 2025 世界一流学科排名](https://www.shanghairanking.cn/rankings/gras/2025/AS0229)，国家/地区旗帜链接来自 Flagcdn。校徽与旗帜是增强信息；图片不可用时必须显示文字或首字占位，不能阻止核心榜单查阅。

## 4. 刷新与校验

执行 `pnpm content:university:refresh` 会重新读取 57 个专业的公开页面并生成本地榜单 JSON。脚本必须满足：

- 只接受软科 2025 GRAS 页面和其 Nuxt 数据载荷；
- 必须得到 5 个领域、57 个专业和非空专业榜单；
- 国家/地区必须有明确的 ISO 两字母映射；遇到新地区时停止生成，不能猜测图标；
- 只在全部专业通过校验后覆盖正式数据文件。

页面读取时再次校验 schema 和必要字段。加载失败、版本不兼容、空数据、筛选无结果和远程图片失败均提供可恢复的文字状态。
