# 数学知识塔

状态：正式生效

## 1. 产品目标

数学知识塔把人教版小学一年级至初中九年级的数学学习内容整理为一张从下向上的连续成长塔。孩子从底部一年级开始，逐条查看知识点，并用四盏灯记录自己对每个知识点的掌握过程。

知识塔不是考试排名，不自动判定孩子已经掌握某项内容。灯由孩子或陪伴者主动点击，是清楚、可恢复保存的自我成长记录。

## 2. 固定内容口径

- 课程目录文件：`content/math/knowledge-tower.v1.json`。
- 目录 ID：`mumu-math-knowledge-tower-v1`。
- 年级：小学一年级至六年级、初中七年级至九年级，共 9 个年级。
- 知识点：固定 517 个，每个知识点具有稳定且不可复用的 ID。
- 熟练度：每个知识点固定 4 盏灯，共 2068 盏灯。
- 课程文件属于可版本控制产品内容，不得混入孩子姓名、点亮记录或其他运行时个人数据。

四级熟练度固定为：

1. `aware`：初步知晓——知道这个知识点在说什么；
2. `understand`：原理理解——能说清为什么这样做；
3. `calculate`：熟练计算——能比较稳定地完成相关计算或判断；
4. `master`：完全掌握——能灵活运用并解释给别人听。

四盏灯互相独立，不强制按顺序点亮；未点亮时点击点亮，已点亮时再次点击熄灭。四级灯色固定为淡绿色、正蓝色、淡紫色、亮红色，并始终配合对号和状态文字，不能只靠颜色区分。

## 3. 塔的方向与页面结构

- 视觉底部是一年级起点，顶部是九年级终点。
- 年级内部的第一个知识点位于本年级最下方，后续知识点向上累积。
- 首次进入页面直接定位到一年级底部；之后点亮灯不得抢夺或重置滚动位置。
- 页面采用“顶部常驻成长仪表 + 左侧年级导航 + 右侧连续知识塔”。
- 桌面端左侧导航独立显示九个年级；移动端改为可横向滚动的粘性年级导航。
- 全部 517 个知识点在同一页面完整呈现，不分页、不按年级折叠。

## 4. 得分、进度与年龄映射

设：

- `K = 517`，知识点总数；
- `L = K × 4 = 2068`，总灯数及满分；
- `lit`，当前已点亮灯数；
- `D = 9 × 365 = 3285`，6 周岁到 15 周岁的总映射天数。

计算规则：

- 当前得分：`score = lit`；
- 总分：`maxScore = 2068`；
- 知识进度：`progress = lit / 2068`；
- 已增长年龄天数：`progressDays = floor(progress × 3285)`；
- 显示年龄：`6 周岁 + progressDays`。

年龄文字按 365 天为一年、`365 / 12` 天为一个平均月拆分为“X 岁 X 月 X 天”。显示天数向下取整，确保 0 盏灯准确显示 `6岁0月0天`，2068 盏灯准确显示 `15岁0月0天`。年龄是趣味进度映射，不是医学、心理学或真实学力评估。

## 5. 进度文件与 API

运行时进度默认保存到：

`var/learning/math/knowledge-tower-progress.json`

使用 `APP_DATA_DIR` 时相对结构保持不变。文件必须包含：

- `schemaVersion`；
- 稳定 UUID；
- `catalogId`；
- `createdAt`、`updatedAt`；
- 唯一的 `litLightIds` 数组。

写入必须使用单写入队列、临时文件和原子替换，并限制为当前用户读写。读取时校验 schema、目录 ID、灯 ID 和重复项；旧版本迁移后必须立即按当前格式保存。

接口：

- `GET /api/math/knowledge-tower`：返回完整课程目录、四级熟练度和当前进度；
- `POST /api/math/knowledge-tower/lights`：接收 `topicId` 与 `masteryId`，把对应灯切换为相反状态，成功持久化后返回 `isLit` 与最新进度。

服务端不得信任浏览器提交的得分、总分、百分比或年龄。所有统计均由已验证的目录与已保存灯 ID 重新计算。

## 6. 交互与无障碍

- 每盏灯都是至少 48 × 48px 的原生按钮，并提供知识点、熟练度、已点亮/未点亮的完整无障碍名称。
- 点亮不能只靠颜色：必须同时出现实心灯、对号、边框和状态文字；已点亮灯的无障碍名称和可见提示都要说明可再次点击熄灭。
- 保存中锁定同一知识点的四盏灯；成功后由 `aria-live` 播报得分与年龄变化。
- 保存失败时保留原状态，显示“这盏灯暂时没有保存，请再点一次”，不使用失败、落后或扣分措辞。
- `prefers-reduced-motion` 下取消点亮弹跳、持续光晕和滚动动画，只保留静态状态变化。

## 7. 测试边界

至少覆盖：

- 空进度首次读取；
- 合法点亮与再次点击熄灭；
- 非法知识点和非法熟练度；
- 目录恰好为 517 个唯一知识点；
- 2068 盏灯与年龄边界计算；
- 损坏或未来版本进度文件；
- 旧版本进度迁移；
- 原子写入失败时不返回虚假的点亮状态。
