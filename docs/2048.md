# 无限 2048

- 移动反馈：每个原块沿真实合并路径滑动 150ms，落点汇合后数字更新并轻微回弹 140ms，新块在滑动接近结束时浮现。仅 transform/opacity 动画；规则、分数和保存立即更新，无输入锁、动画队列或逐帧 React 更新。快速连按采样上一动画的当前可见位置继续移动；重开/切尺寸清除旧动画，减少动态效果设置下直接显示最终状态。

- 数学 Tab → 2048，路径 `/math/2048`。4×4、5×5、6×6 各有独立棋盘、当前分数、最高分和生成档位；切换保留，重开仅清空当前尺寸的棋盘与当前分数。
- 方向键、WASD、单指滑动与四个方向按钮等效。一行沿移动方向压缩，相同值两两合并，每个方块每步只参与一次合并；得分为本步合成数字之和。无变化的移动不产生新块，不计分、不保存。
- 每次有效移动后在随机空位生成一个块：低档 90%，高档 10%。开局两个块。默认生成 2 / 4；用户描述中的 16392 按二倍序列的 16384 实现。棋盘最大值达到 16384 且没有 2 时改为 4 / 8；达到 32768 且没有 4 时改为 8 / 16，以此类推。仍有最低档方块时继续生成该档；档位只上升，重开归初始。
- 2048 及之后任何数值都不会触发胜利结束。只有棋盘填满且横纵都无法合并才提示新开或切换尺寸，原盘继续保存。
- 方块按二的指数存储，分数用 BigInt 运算、十进制字符串存储，避免浮点精度与科学记数法。20 档预设颜色覆盖 2—1048576，按黄→橙→红→深蓝→黑排列。以 2=#FFF0B3、16=#FFA346、128=#CD3539、1024=#74182B、32768=#11223A、1048576=#080A0E 为锚点，按指数层级对 R/G/B 逐通道分段线性插值、四舍五入，预先写入色表。1024→32768 共五次升级，每步理想增量为 R −19.8、G +2、B +3，整数取整后各步误差至多 1；经酒红和暗紫自然过渡到深蓝。32768→1048576 同样均匀过渡到黑色，之后沿用末档黑色，不使用浅蓝。数字由 SVG 单行居中，按位数缩小、完整显示，不自动换行。输入校验的资源保护范围是指数 ≤10000、分数字符串 ≤4096 位，不是 2048 通关门槛。
- 自动保存通过通用持久化队列即时提交，每次回执检查版本防止旧状态覆盖新移动。保存失败保留页面进度并可重试；未落盘时阻止误返回并触发浏览器离页保护。读取失败不创建新盘覆盖旧记录。服务端串行写入并保留更高的历史最高分；多标签棋盘采用最后写入的有效快照。
- 全屏复用原生全屏/窗口内沉浸降级，保留退出入口，Escape 退出；正常模式复用通用单行顶栏。无倒计时、无自动声音、无新增币奖励。全局数字键盘隐藏。
- 首版外壳及 payload 都为 schemaVersion 1，无旧版迁移来源；未知版本与损坏内容拒绝读写，不清空或静默重置。未来升级应先保存迁移来源。当前没有单独导入导出格式。
- 数据文件为仓库外 `learning/math/2048-state.json`；API `/api/persistent-data/math-2048`。外壳由服务端提供 UUID、创建与更新时间，文件使用既有队列、临时文件原子替换与 0600 权限；以后备份需要包含此文件。
