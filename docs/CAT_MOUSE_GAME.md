# 猫鼠游戏

## 1. 状态与入口

- 状态：已实现。
- 入口：数学栏目中的“猫鼠游戏”。
- 路径：`/math/cat-mouse-game`。
- 目标年龄：约 5 岁儿童，在成人少量引导下完成看图列式和整数计算。
- 当前版本不保存独立答题历史；只有答对后的知识币奖励会通过统一服务写入 `var/learning/world-tower/progress.json`。

进入页面后必须立即生成一道题，不设置难度选择或开始页。点击“换一道题”后重新生成题目，且新题签名不得与当前题完全相同。

## 2. 题型

题目使用 `x` 表示待求的猫、老鼠、狗、物体高度、长度或数量。当前题库包含八类模板：

| 题型 | 已知关系 | 求解方式 |
| --- | --- | --- |
| 和差高度 | `a - x = d`、`a + x = s` | `x = (s - d) ÷ 2` |
| 堆叠增加 | `b + x = t` | `x = t - b` |
| 高度差 | `x - k = d` | `x = k + d` |
| 两段长度 | `2 × x + b = t` | `x = (t - b) ÷ 2` |
| 三段长度 | `3 × x + b = t` | `x = (t - b) ÷ 3` |
| 平分为二 | `2 × x = t` | `x = t ÷ 2` |
| 平分为三 | `3 × x = t` | `x = t ÷ 3` |
| 两只猫和一只鼠 | `2 × x + x = t` | `x = t ÷ 3` |

模板中的字母只用于解释生成规则；儿童页面以画面、数值标签和自然语言呈现已知条件。

## 3. 数值约束

- 待求答案必须是 `1—200` 的正整数。
- 所有展示给儿童的已知数值必须是 `0—200` 的整数。
- 除法只允许除以 `2` 或 `3`，并且生成时先选择整数答案再反推被除数，保证整除。
- 不得出现小数、分数、负数、除数为零或超出范围的中间展示值。
- 每道题生成后都必须通过统一校验器；校验失败时重新生成，不能把无效题目展示到页面。

## 4. 动态生成

每道题至少组合以下变化维度：

- 八类公式模板；
- `0—200` 范围内的合法数值；
- 八个室内外背景；
- 四种画面布局；
- 猫、老鼠、狗的动作姿势；
- 石柱、木板、木桩、箱子、木桶、梯子、桌椅和台阶等参照物。

文字、数字、尺寸线和问号必须用 HTML/CSS 实时绘制，不能烘焙在背景图中。角色和参照物使用透明 PNG 独立图层，保证同一资产可以在不同题型、尺寸和位置中衔接复用。

## 5. 答题与反馈

1. 首屏只显示题意、图中已知数值、整数输入框和提交按钮，不提前泄露列式。
2. 输入只接受 `1—200` 的整数。
3. 答错时保留原题和输入机会，使用鼓励式提示，不倒计时、不扣分。
4. 答对后显示原始关系式、逐步计算式和带单位的最终答案。
5. 每道题最终答对时奖励 20 个知识币，并显示奖励后的总余额；主动揭示答案不奖励，同一道题不能重复奖励。
6. 点击“看看这题怎么列式”可以主动揭示解法；揭示后仍保留“换一道题”入口。
7. 结果区域使用 `aria-live` 播报状态，主要控件支持键盘操作和可见焦点。

## 6. 美术资产与绿幕处理

- 源图集：`apps/web/public/images/tom-and-jerry-library/source-atlases/`。
- 网页图集：`apps/web/public/images/tom-and-jerry-library/atlases/`。
- 已抠图单体：`apps/web/public/images/tom-and-jerry-library/sprites/`。
- 资产目录：`apps/web/public/images/tom-and-jerry-library/catalog.v1.json`。
- 生成和切分约定：`apps/web/public/images/tom-and-jerry-library/GENERATION_SPEC.md`。

角色和道具图集均按固定网格生成。绿幕切分工具会按网格独立取样背景色、生成软边透明通道、抑制绿色溢色，并输出稳定 ID 和 JSON 清单。手持道具继续遵循固定把手锚点规则；测量参照物保留完整画布边界，避免裁切后锚点漂移。

## 7. 响应式与动效

- 桌面端使用“左侧看图、右侧解题”的双栏布局。
- 窄屏改为“先看图、后解题”的单列布局，输入框和按钮触控目标不小于 `48 × 48px`。
- 动效只用于轻微入场和反馈；启用 `prefers-reduced-motion` 时必须停止非必要动画。
- 页面延续星际探索舱设计系统，猫鼠画面只作为任务内容，不建立第二套页面视觉语言。

## 8. 测试要求

- 每种题型至少批量生成数百组题目，验证答案、已知数和中间展示值边界。
- 验证所有除法精确整除，除数只能是 `2` 或 `3`。
- 验证连续生成的题目会覆盖不同题型、背景和布局。
- 合并前运行 Web 单元测试、全仓库类型检查和生产构建。
