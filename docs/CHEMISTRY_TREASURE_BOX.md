# 化学百宝箱功能规范

## 1. 功能定位

“化学百宝箱”是一个开放式原子组合玩法。孩子从前 90 号元素组成的密集元素表中自由投放原子，观察原子在反应区内做布朗运动；当游离原子的数量满足一种已收录物质的组成时，系统自动聚合该结构，并把它移出反应区、收藏到下方百宝架。

这里展示的是虚拟组成关系，不是现实化学反应模拟器：

- 不提供温度、压力、点火、比例、制备方法或实验步骤；
- 不暗示任意原子在现实环境中都能直接生成页面物质；
- 离子晶体、水合物和材料结构继续沿用反应熔炉的虚线组成示意；
- 已发现物质、游离原子清单和当前查看元素会保存在本设备的浏览器本地缓存；重新打开页面后可继续本次探索。“重新开始”会清空并覆盖这份本地探索记录。

## 2. 元素选择器

- 右侧固定呈现原子序数 1—90 的元素，包括氢至钍。
- 元素按原子序数从 1 到 90 连续排列，每行 8 个，取消标准周期表中的空位，让右侧选择器保持紧凑。
- 每个元素格同时显示原子序数、元素符号和中文名称；中文名称是主要阅读信息，字号明显大于元素符号。格子底部以弱化样式显示“物 n / 原 n”，分别表示当前已收集且含该元素的物质数，以及反应区内该元素的游离原子数；这些计数不能增加元素格高度。
- 点击、触控与键盘激活元素格时，同时选中该元素并按固定批量投放：氢和碳每次 5 个，氧每次 3 个，其他元素每次 1 个。批量规则不在元素格增加新的可见标签；元素网格下方同步列出本轮已收集且包含该元素的全部物质。
- 元素颜色与元素周期表、反应熔炉保持一致；颜色只辅助辨认，元素符号和中文名始终可见。
- 为保护儿童设备，反应区最多同时保留 240 个游离原子；到达上限时保留现有状态，并提示先等待组合或清空游离原子。

## 3. 可发现物质

候选物质复用反应熔炉的 518 种运行时资料，不复制第二套化学数据。百宝箱启动时执行以下筛选：

1. 只保留全部原子都属于前 90 号元素的记录。
2. 排除总原子数为 1 的单原子单质或结构，因此投入一个金、氦等原子不会立刻生成收藏。
3. 氧气、臭氧、氢气、氮气以及碳材料等含两个及以上原子的单质允许生成。
4. 对原子计数完全相同的同分异构体或重复资料，只保留一个代表记录；优先教材常见记录，其次优先无机物，避免同一份原子数量连续生成多个无法由组成区分的结构。

当前筛选后共有 482 种不重复组成可以发现。资料库升级时该数量允许随筛选结果变化，页面必须读取实际数量，不能硬编码。

## 4. 自动组合与唯一性

1. 每次点击按元素固定批量把原子送入反应区并开始布朗运动；整批原子必须一起投放，接近 240 个游离原子上限且剩余容量不足时拒绝本次投放，不能只投入半批。
2. 系统等待约 520 毫秒的连续投放停顿后检查配方，给孩子保留连续点击多个元素、补齐完整组合的机会。
3. 匹配时优先选择恰好用完当前全部游离原子的物质；若没有恰好匹配，再优先选择原子总数更多、元素种类更丰富、教材优先级更高的可组成物质。
4. 物质一旦开始聚合，立即从游离原子计数中扣除对应数量；组成动画完成后才进入百宝架。
5. 同一物质在当前收藏中只能存在一次。已经收藏的配方不会再次消耗原子；从元素物质清单移除后，该配方解除完成状态，可以重新生成。
6. 例如：点击氧会一次投入三个氧原子并优先匹配臭氧；臭氧完成后再次点击氧，未完成的氧气仍可消耗其中两个氧原子，剩余氧原子继续留在反应区。
7. 聚合阶段一次只处理一种物质；新投放原子仍可在反应区运动，当前结构离场后继续检查剩余原子。

## 5. 实时渲染

- 复用反应熔炉的 Canvas 原子球、元素配色、入场扩散、布朗运动、边界碰撞、聚合震动、键位发光和结构缓存。
- 百宝箱使用“离场”模式：结构稳定后向反应区底部漂移并淡出，随后在百宝架生成静态结构卡。
- 已离场结构和对应原子从 Canvas 状态中移除，避免长时间探索造成无上限渲染负担。
- prefers-reduced-motion 下原子直接静态散布，聚合与离场缩短为淡入淡出，但组成状态与收藏结果保持完整。

## 6. 页面与可访问性

- 页面沿用“星际探索舱”和“实时反应熔炉”视觉；顶部只保留返回、玩法名、游离原子数、发现数、清空与重新开始。
- 桌面端主体为左侧大反应区、右侧窄栏元素表；窄屏改为上下排列，元素表只在自身区域纵向滚动。
- 反应区高度较初版紧凑布局再缩减约 20%，让百宝架标题和最新结果尽量进入同一视口。
- 百宝架紧贴在反应区正下方，桌面端每行排列 3 张结构卡；最新生成的物质固定放在左上角第一位，原有卡片逐个向右、再向下一行后移。窄屏改为单列，每张卡显示发现序号、分子式、中文名、特性、结构类型和已收藏文字。
- 元素物质清单位于右侧元素网格下方；每条记录显示分子式、名称和带“× 移除”文字的触控按钮。移除会同时更新清单、元素格计数和百宝架，状态变化通过可见文案播报。
- 状态变化通过可见文案与 aria-live 播报，不能只依赖颜色或动画。
- “清空游离原子”不会删除百宝架；“重新开始”会清除当前全部游离原子和收藏。

## 7. 本地缓存与隐私

百宝箱只使用浏览器本地缓存，不上传探索记录，也不保存孩子姓名、账号或学习成绩。缓存记录具有 `schemaVersion`、稳定玩法 ID、创建时间和更新时间，内容仅包括：已发现物质的资料库 ID（按百宝架新旧顺序）、游离原子清单、当前查看元素和可能被页面关闭打断的聚合状态。

- 恢复前会验证资料库 ID、前 90 号元素范围、原子数量为正整数、240 个游离原子上限及去重规则；无效记录安全忽略；
- 若页面在结构聚合动画中关闭，恢复时会把这份结构的原子归还到游离清单，再按正常匹配规则继续，避免丢失原子；
- 删除百宝架物质、清空游离原子和重新开始都会立即更新本地缓存；浏览器禁止本地写入时，页面继续可用且不会显示技术错误。

## 8. 测试边界

自动化测试至少覆盖：

- 候选物质不含单原子记录，且每种原子计数组合唯一；
- 全部候选物质只使用前 90 号元素；
- 氧气与臭氧使用各自独立的完成状态，均可按实际游离原子数量正确命中；
- 完成过的物质不会再次生成；
- 已收集物质按所含元素正确建立索引，移除后可以再次命中同一配方；
- 氢和碳单次投入 5 个、氧单次投入 3 个、其他元素单次投入 1 个，且批量投放不会突破游离原子上限；
- 水的原子恰好齐全时优先生成水，而不是先消耗成氢气。
- 本地缓存覆盖有效记录恢复、损坏记录拒绝、版本零迁移与浏览器写入失败降级。
