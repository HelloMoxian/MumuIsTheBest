# 仰望星空

## 当前交付与隔离边界

自然学科的沉浸式星座观察页，已接入主站自然 Tab，正式路径为 `/nature/stargazing`。主站按需懒加载 `StargazingPage`；业务代码位于 `apps/web/src/features/stargazing/`。保留 `apps/web/stargazing/` 中的独立入口和启动配置，便于与其他正在开发的模块分开预览。静态星表只有一份，不新增服务端接口、钱包奖励或学习进度存储。

独立运行：在 `apps/web` 中执行 `pnpm exec vite --config stargazing/vite.config.ts`，打开 [5176 独立预览](http://127.0.0.1:5176/)。端口已占用会明确退出，不悄悄挤占其他开发服务。独立开发页“自然”返回现有 [主站自然区域](http://localhost:5173/#nature-title)；主站与独立生产页默认返回 `/#nature-title`。

独立构建：在 `apps/web` 中执行 `pnpm exec vite build --config stargazing/vite.config.ts`。默认输出仅为本机 `/tmp/mumu-stargazing-build`，不会覆盖主应用构建；可以显式传 `--outDir` 指定交付目录。主站接入后的生产 bundle 已通过 Vite `build({ build: { write: false } })` 内存构建验证，不落盘、不覆盖其他模块的构建产物。本功能的星表与科学内容随包提供，无外部运行时天文请求。

主站入口复用原有全局音乐播放器及偏好，但隐藏常驻音乐浮钮，改由本页“观察设置 → 背景音乐”按需打开。此路由不显示全局数字键盘。独立页没有主站音乐层，因此不另建播放器或偏好副本。

## 分组与专属观察合同

| 分类 | 分组 | 内容与初始展示 |
| --- | --- | --- |
| 精选 | 最出名的星座 | 猎户、大熊、仙后、天蝎、狮子、小熊、双子、南十字，共 8 座；编辑精选，全天展示 |
| 精选 | 十二星座 | 传统十二宫名称对应的 12 个现代星座，不含蛇夫座；全天展示 |
| 精选 | 亮星三角 | 冬季大三角与夏季大三角所在的猎户、大犬、小犬、天琴、天鹰、天鹅，共 6 座；全天展示 |
| 精选 | 黄道上的十三站 | 天文学上黄道经过的 13 个现代星座，包含蛇夫座；全天展示 |
| 四季 | 冬夜的钻石、夏夜的银河、春天的星空、秋夜的四边形 | 各 6 座，保留各组的局部天球取景 |
| 南北天空 | 寻找北极星、南方的星海 | 各 6 座，保留北天或南天的局部取景 |

`SKY_COLLECTIONS` 保留稳定组 ID、成员 IAU 缩写和初始视野，增加可选 `category: featured | seasons | hemispheres` 与 `atlas: boolean`。本轮全部 10 组已赋分类，四个精选组的 `atlas` 为 `true`。整组视图只使用该组星座的真实连线图形和去重后的轮廓星，不将其他星座留作背景。选择一座后进入专属观察，保留所属分组，能够返回整组或切换同组的上/下一座；选择“全天总览”则恢复全部 88 座。

分组副标题使用孩子容易理解的短句；“最出名”属于编辑选择、并非官方知名度调查的说明集中放在弹窗脚注和资料说明，不在每张分组卡片重复。

`constellationFigureStars` 用球面角距，将每个连线顶点匹配到 0.05° 内最近的目录恒星，按稳定 ID 去重，按视星等排序；空、非法或没有近邻的点不生成假恒星。此函数允许图案借用邻座恒星，例如飞马大四边形中的壁宿二实际属于仙女座、御夫座图案中的五车五实际属于金牛座。`constellationStars` 仍优先使用星表的正式归属，详情中的“所属恒星”不得沿用图案借星语义。

单座专属观察同时隐藏其他恒星、银河、网格和地平线干扰，只保留选中星座的图案线索；“显示连线”可独立关闭。关闭“只看这个星座”恢复全天恒星及原图层选择，不修改目录或原有归属。

恒星过渡保留进入前的探索镜头，520ms 镜头推进不会把临时中间视角写成新的探索位置；800ms 交叉放大完成后结束过渡。中途返回、换目标或离页会取消旧过渡与定时器，不能稍后被旧目标重新带入近景。`prefers-reduced-motion` 下直接进入球体，不执行推进或交叉放大。

## 科学事实、示意与产品参考

- 使用 HYG 4.1（Hipparcos / Yale / Gliese 汇编）固定快照，筛选视星等 ≤6.5，移除太阳，保留 HYG 稳定编号与可用 HIP 编号。
- 88 个星座按 IAU 现代体系；图形来自 d3-celestial，巨蛇座两个分区合并到 `Ser`。星座连线不是 IAU 官方唯一图案。目录 `zodiac` 对应天文学黄道十三座，包含蛇夫座；“十二星座”是另一个明确不含蛇夫座的传统名称分组。北斗七星、冬季及夏季大三角是星群而不是额外的正式星座。
- “知名度·入门推荐”是本站面向中文家庭的编辑顺序，明确不是官方投票、访问量或调查排名。季节分组参考北半球中纬度晚间，不承诺当下当地一定可见。
- J2000 赤道坐标、USNO 近似恒星时与几何地平方位。不含岁差、自行、折射、实时天气、地貌遮挡、日月行星轨道、卫星或望远镜控制。全天自由图不模拟白昼大气，所以白天也能浏览。
- 恒星颜色参考实测 B−V 色指数或目录近似温度；低温橙红、高温蓝白，显示增强只为辨认。色温为空但色指数有值时，仅驱动示意颜色，不补造测量温度。
- 通用半径由视觉光度与近似温度推算，未作全波段光度改正，属于教学尺寸代理。精选对象补充有出处的科普/研究模型。所有半径在 UI 中明确标估算；压缩圆点和球体不是严格同比例比较。
- `rotationKmS` 是所引研究模型的赤道速度，不是 `v sin i`、径向速度或画面自转周期。缺失参数显示“未收录”。无依据的质量、自转、距离不编造。
- 球体的表面颗粒、暗纹、光晕与转动均为程序化科学示意，不是实拍；不同恒星保留温度次序、尺寸层级和纹理差异。
- 能力组织参考 [Stellarium](https://stellarium.org/) 与 [天文通](https://twtapp.com/) 的观星主流程；本页聚焦恒星与星座，不宣称复刻整个专业平台。没有搬运其品牌、页面代码或商业美术。

本轮分组事实核查来源：

- [IAU：The Constellations](https://iauarchive.eso.org/public/themes/constellations/)：88 个现代天区、星座区域与连线图案的区别，以及星群不等于正式星座。
- [NASA：What Are Asterisms?](https://science.nasa.gov/solar-system/what-are-asterisms/)：冬季大三角由天狼星、参宿四、南河三组成；夏季大三角由织女星、牛郎星、天津四组成。分组选择的是这些恒星所属的六个现代星座。
- [Royal Observatory Greenwich：July 2026，Ophiuchus](https://www.rmg.co.uk/stories/space-astronomy/astronomy/night-sky-highlights-july-2026)：黄道实际经过蛇夫座，而传统十二宫未把它列入。这里只使用该天文事实，不把传统星座用来推断个性或命运。

来源与完整许可见业务目录 `CATALOG_SOURCES.md`，并通过 `?raw` 打包进页面“资料与操作 → 完整来源与许可”。HYG 派生数据采用 CC BY-SA 4.0；d3-celestial 保留 BSD-3-Clause 完整声明。生成器 `scripts/build-stargazing-catalog.py` 默认只校验；`--write` 使用锁定上游提交重新生成，需按仓库规则配对记录写入。

## 交互与错误边界

- 所有操作按钮至少 48px，主要操作文字至少 18px；窄屏工具栏可横向滑动，详情可以独立纵向滚动。矮横屏为独立双栏兜底，资料区不会归零。
- 天球可用方向键转向、+/−缩放、Enter 选择中心附近恒星；搜索列表和全天 SVG 星座均支持键盘。模态对话框限制焦点、Escape 关闭、归还打开者焦点，并隔离全屏 hook 的 Tab/Escape。
- 本页不调用麦克风、定位或摄像头，不新增独立音乐播放、偏好或个人进度存储。主站音乐遵守原播放器的主动播放、音量、静音和持久化偏好合同；只从“观察设置”打开原面板，不因进入星空另开一份音源。静态目录不涉及新增持久化格式迁移、奖励与写入失败。
- Canvas 不可用时保留目录；WebGL 不可用或上下文丢失时用 Canvas 静态恒星示意降级。空搜索有恢复全部入口。经纬度、非法日期、范围与夏令时不存在时刻均校验，不把不合法值归一化为看似准确的观测结果。
- 暂停、后台、离页停止恒星连续绘制；减弱动效跳过进入过渡、冻结自转并关闭巡视，允许主动拖动。图层、进入详情与返回不修改科学数据。球体画布随容器与像素比更新 drawing buffer，尺寸稳定时不反复重设，避免球体因低分辨率画布而模糊。

在 `apps/web` 运行 `pnpm exec tsx --test src/features/stargazing/*.test.ts`；另从仓库根运行 `python3 scripts/build-stargazing-catalog.py`。前端类型检查复用 `pnpm --filter @mumu/web typecheck`。独立构建使用上述 5176 配置，主站集成验收使用 `write: false` 的内存生产构建，避免覆盖并行开发中的现有产物。

本轮 **42/42 项测试全部通过**，包括 36 个星空定向测试与 6 个现有音乐回归测试；前端类型检查通过。主站生产内存构建采用默认 `publicDir` 和 `write: false`，处理 743 个模块、生成 572 个内存输出项，退出码为 0 且无警告。定向测试覆盖球面正逆投影、RA 零点/两极、星座取景、地平转换、温度颜色、88 座与星表完整性、10 组引用及分类、传统十二与天文学十三的区别、轮廓星最近匹配/去重/借星、正式归属优先、别名与编号搜索、无结果、非法经纬度/日期、缺失参数、全天边界折线、点击几何与镜头过渡。测试关注真实成员、分类和交互合同，不依赖分组副标题的具体修辞。

浏览器已验证主站自然入口；猎户座专属模式在 8,920 颗背景星与 23 颗轮廓星之间切换，关闭连线后仍保留相同星点；十二星座整组为 12 座和 147 颗去重轮廓星，组内单座、前后切换和返回整组均可用。进入恒星时能观察到进入过渡状态，800ms 内返回会取消旧过渡，稍后仍停留原星座。近景渲染缓冲为 1,344 × 928，对应 896 × 619 的布局尺寸，没有被入场缩放压成低分辨率。主站音乐面板可从观察设置打开，Escape 仅关闭音乐面板并回焦点到原按钮；页面没有常驻音乐浮钮或数字键盘。390 × 844 手机竖屏、568 × 320 横屏均无横向溢出，专属勾选区域达到 48px，横屏控件不与底栏相撞。
