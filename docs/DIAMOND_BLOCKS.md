# 钻石方块

游戏大厅入口为 `/games/diamond-blocks`。进入立即开始，已有浏览器缓存则直接恢复。核心为竖向三颗一组、左右移动与循环换序，横/竖/两条对角线连续三颗及以上消除，交叉去重；消除后逐列下坠，继续检查连锁。下一组预告、落点虚线、积分和关卡进度常驻。普通组无法放入顶部三格、或奖励方块无法放入顶部一格时结束，不扣币、不发放学习币。

## 过关奖励与落点策略

每次消除结算跨入下一关奖励一枚单格「全消方块」，一次跨多关逐关累加到 `pendingPrisms`。本轮所有连锁结束后优先出场，不占用或改写已预告的普通三连块；队列清空后继续普通预告。用统一青紫粉棱镜/白星外形表示，活动组为 `gems: [-1]`，普通棋盘与普通预告仍只接受 0—6，奖励标记绝不写进已落棋盘。

全消方块可左右移动、下移、直落，不能换序；预判其正下方将接触的元素，描边标出盘面所有同类，并显示可消除数量。落定后立即消耗自己，清除全盘该类元素（无需相连，单颗也可消除）；沿用消除动画、每颗 10 分及后续重力连锁。直接落到空列底部也会消耗，但不消除、不加分。落定仍递增 `pieces`，所以按住下移不能穿透到下一枚奖励或普通组。

奖励实际落定时 `scene` 加一，背景按紫/青/绿/粉/金五种深空色调循环，BGM 在七首本机配乐中换下一首。普通过关时只发奖励，不提前换景；落空也换景。场景编号随进度保存，刷新不会再次触发落定或重复发奖。音乐开关、音量、首次交互解锁、语音避让与全站声音焦点不变；选择的配乐作为起始曲，当前曲叠加场景偏移，电台继续自动轮播。

`rewardLevel` 记录已处理到的关卡：只在真实消除结算时发奖，调整每关数量时重设为当前关卡，不追补历史关卡、不清空已有奖励，之后正常跨关继续发放。动态停用元素保留奖励方块；若同色全消正在进行，其目标色也按随机种子替换为保留类型并重新计算尚未结算的目标，不重复记分。

## 局中设置

顶部「设置」打开原生对话框并暂停；应用后恢复原先运行状态，取消不改变配置。重开二次确认。

- 横向 6—15、纵向 10—20，默认 15×15。
- 每关消除 3—9999 颗，默认 60；当前关卡为 1 + floor(累计消除 / 每关数量)，改变数量立即重算关卡。
- 初始速度 0—10 格/秒，默认 1；每级增加 0—5 格/秒，默认 0.15；实际速度上限 20。初始速度为 0 时始终不自动下落，每级增速 0 保持初始速度。
- 7 种身份，默认启用 6 种，至少保留 2 种。停用种类后，盘面、活动组、预告中的相应元素按持久化随机种子随机替换为保留种类，然后重新检查消除；已提交积分不重复结算。
- 尺寸调整锚定左侧与底部，保留所有已有元素及分数。会裁掉元素或活动组重叠时拒绝，不暗中清空。消除动画进行时先完成连锁再改尺寸，或明确确认按新设置开局。
- 皮肤：独立生成的原子星港元素图标、宝石迷阵宝石、水晶俄罗斯方块样式、原创 SVG 像素矿块、原创 SVG 极光星珀。原子星港采用 H 红圆、He 蓝水滴、Li 绿三角、Be 黄方、B 紫菱形、C 橙六边形、N 白星；运行时位于 `public/images/diamond-blocks/elements-v1/`，原图、提示词与格位清单位于 `assets/game/diamond-blocks/elements-v1/`。只替换本玩法素材，不修改数独图片或已保存身份编号。五套共用身份，皮肤变更不改逻辑；像素纹理/几何轮廓/符号辅助颜色识别。

每轮消除每颗 10 分 × 当前连锁次数。显示累计消除、最高连锁与已落组数。不保存排行或个人身份。

消除表现为 720ms 原地提亮、翻转、菱形光框切换和收缩；随后按实际源/目标行距播放 300ms 下坠。重力计算同时提供目标盘面与移动距离，动画仅作用于行号改变的存留元素，禁止再给整盘所有图标添加统一下沉动画。刷新在 settling 阶段直接展示已保存落点，不伪造移动或重播结算。

方块最终消失、逻辑结算和自动保存发生在同一次阶段转换；同时在消除区域附近弹出「+分数」，用金白渐变粗体、深色描边和星芒做 620ms 弹跳，然后用 520ms 弧线飞到真实计分位置，再用 160ms 递增总分。相邻消除格聚合为一份数字，分散区域最多聚合为六份，每颗只贡献一次，合计严格等于本轮得分。独立飞分队列允许连锁重叠，未抵达金额暂从显示总分扣除，真实计分与保存不等动画。棋格位置归一化，动画每帧读取当前棋盘/计分位置，适配滚动、全屏与旋转。

动画暂停随页面状态同步，结束局仍可完成最后一次分数入场。飞分和下落距离仅为内存展示状态；减弱动效直接显示最新总分。重新读取/重开时清除旧展示状态，刷新不重播已结算的飞分。

## 控制与页面

按住 ↓ / S 或手柄下移只连续下落按下时的当前组；以已落组数绑定每次按住，当前组落定后必须松开再按才能下移下一组。消除/归位期间按住不预先控制下一组。暂停、设置、失焦和重开清除按住状态，键盘残留重复事件不能恢复下移；直落和换序维持单次触发，屏幕按钮不响应 Enter/空格的按住重复点击。正常自动下落速度不受此约束影响，不修改存档结构。

方向左右移动，↑ / W / X 正向换序，Z 反向换序，↓ / S 手动下移，空格直落，P 暂停，Escape 暂停。A/D 同左右键。屏幕有至少 48px 的独立动作按钮，棋盘是展示区。手柄复用共享输入：方向移动，A 换序，X 反向换序，Y 直落，B/菜单暂停；暂停后回到全站导航，可进入设置或返回大厅。失焦、后台、断开手柄时暂停，不补算后台时间。

棋盘按可用区域等比缩放，窄屏将预告与分数放在棋盘上方。全屏复用共享全屏组件，保留设置/返回/暂停等必要入口。减弱动效下禁用呼吸、消除星芒和位移，保留真实文字及描边。图片故障以独特符号降级。

全屏将原页头、预告宣传、皮肤图例和次要统计收起。横屏棋盘独占可用高度，右侧窄栏集中设置、暂停、重开、退出、下一组、得分与关卡和动作按钮；返回大厅先退出全屏。竖屏工具与预告置顶、动作条置底，棋盘占据剩余区域。棋盘以容器实际宽高与行列比例取最大内接尺寸，去掉固定减高与最小宽度限制；低高度横屏压缩统计和操作排列，保持按钮至少 48px。安全区适配刘海和底部手势区，异常提示单独占行可滚动；同一个棋盘 DOM 保留局面，不因旋转或全屏切换重新开始。

## 自动保存与保护

仅使用浏览器 localStorage，沿用历史键 `mumu.diamond-blocks.v1`，当前快照为 `schemaVersion: 2`；不涉及服务端或仓库内运行时数据。单一原子 JSON 快照含稳定 UUID、创建/更新时间、revision、配置、整盘棋格、活动组、普通下一组、随机种子、阶段/阶段计时、消除集合、分数和累计计数，以及 `rewardLevel`、`pendingPrisms`、`scene` 和 `clearColor`。`clearColor: null` 为普通匹配，非空时为同色全消目标；后者允许不足三颗，并校验消除集合恰好包含全盘同类。

操作/阶段转换后及前台每秒保存，暂停、失焦、离页再保存。刷新从保存阶段继续，正在消除的匹配只结算一次；待发奖励、正在下落的奖励、全消阶段与场景都能续玩。缺失缓存直接使用默认配置。

v1 先按旧规则完整校验，再在内存中补 `rewardLevel = 当前关卡`、`pendingPrisms = 0`、`scene = 0`、`clearColor = null`，保留 ID、原进度、随机种子与消除计时，不追补升级前奖励。首次成功写入 v2 前把合法旧原文留在 `mumu.diamond-blocks.before-v2`（已有备份不覆盖），备份失败则不替换旧进度。回滚时可在旧版应用中将该原文恢复至历史键；这是迁移时快照，不包含之后的新进度。损坏/未知版本不迁移，旧应用无法理解 v2 时也不会覆盖新档。

完整校验尺寸、身份范围、活动组碰撞、匹配集合、数值范围及阶段一致性。损坏/未知版本原值不自动覆盖。写入配额或权限异常保持内存盘面，显示重试；跨标签通过 storage 事件及写入前原值比对暂停保存，提供重新读取或二次确认替换。清理浏览器数据会删除本玩法进度。

## 音乐

四首原创、运行时本地合成的分层芯片曲（棱镜舞步、环星旅行、星光花园、月海潮汐），旋律/低音/和弦/节拍随乐句变化；另复用已有三首本机配乐。电台可自动轮播七首，也可选择起始曲并在当前场景内循环；全消方块落定时均切换下一首。操作音效包含移动、换序、直落、落地、消除、逐级升调连锁、升级、换景、结束、继续等事件；音乐/音效独立开关和音量。

进入即开局但音频需首次真实交互解锁。持有共享 audioFocus 创作引用，避免全站配乐叠播；麦克风期间停止，TTS/学习语音降低音量。暂停/后台/离页停止声音并清理音源，资源或设备异常只影响声音。本页隐藏全局音乐和数字键盘浮钮。既有音频来源沿用 `assets/audio/global/` 和 `public/audio/tetris/SOURCES.md`，新增旋律、音效和 SVG 图案均在代码中原创生成。
