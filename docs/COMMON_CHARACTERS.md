# 常用汉字玩法规范

## 1. 共用玩法与字池

- 路由分别为 `/chinese/common-characters/500`、`/1000`、`/1500`、`/2000`
  和 `/2500`。
- 五个入口共用同一套组件、语音协议、学习策略和进度文件。
- 字池是 `content/chinese/common-characters.v1.json` 频率序列的连续前缀；
  不允许分别维护五份会相互漂移的题库。
- 单局可选择 5 个或 10 个互不重复的字。

## 2. 单屏学习流程

1. 目标汉字立即以大字号居中出现。
2. 约 1.7 秒后出现拼音。
3. 约 3.9 秒后出现释义、组词、例句和成语。
4. “看拼音和词语”或语音“详细信息 / 看看拼音 / 提示”可立即揭示全部内容。
5. 学习画面必须限制在一个桌面视口内，不得要求儿童滚动才能看完当前字。
6. “我会了”只点亮当前字，不自动跳走，给孩子保留查看完整信息的时间。
7. “下一个”会记录当前字并切换；未说“我会了”的字记为“继续复习”，不得使用
   “答错”“失败”等高压措辞。

## 3. 自适应选择

- 优先队列：`notKnownCount >= knownCount` 的字，约占一局的一半；
- 新字队列：从未出现的字，约占一局的三成；
- 复习队列：已掌握的字，优先选择较久没有复习、掌握比例较低的字；
- 当某个队列不足时，从其他队列补足；
- 同一局不得重复出现同一个字。

这套规则确保不会只出新字，也不会因为说过一次“我会了”就永远不再复习。

## 4. 语音控制

识字页复用 `docs/ASR_REALTIME.md` 的阿里云实时 ASR 安全转接。每段识别强制最多
120 秒；到时停止后由页面明确显示状态，点击语音状态按钮可开启下一段。

支持的自然语音命令：

- 开始：`开始`、`开始练习`、`开始一局`
- 掌握：`我会了`、`这个会了`
- 前进：`下一个`、`下个字`
- 揭示：`详细信息`、`看看拼音`、`提示`
- 结束：`结束`、`结束练习`、`结束一局`
- 再来：`再来一局`、`下一局`、`重新开始`
- 清单：`文字清单`、`汉字清单`、`查看清单`
- 返回：`返回`、`返回设置`

ASR 可能重复发送增量和整句文本，前端按 `sentenceId + 语义命令` 去重，避免一个
“下一个”跳过多个字。

## 5. 进度数据

学习进度只写入：

`var/learning/chinese/common-characters-progress.json`

或 `APP_DATA_DIR/learning/chinese/common-characters-progress.json`。

文件包含 `schemaVersion`、稳定文件 ID、创建/更新时间及每字稳定记录 ID。每字记录：

- `studiedCount`：完成查看并切换/结束的次数；
- `knownCount`：其中明确说或点击“我会了”的次数；
- `notKnownCount`：考过但没有标记“我会了”的次数；
- `lastStudiedAt`、`lastKnownAt`：自适应复习所需时间。

服务端使用 schema 校验、临时文件 + 原子替换、`0600` 权限和单写入队列。运行时
进度不得进入 `content/`、前端代码、浏览器存储或 Git。

## 6. 文字清单

- 保持字频顺序；
- 展示汉字、拼音、代表组词、学过次数、我会了次数、继续复习次数和综合状态；
- 支持按汉字、拼音、组词搜索；
- 支持“没见过 / 继续复习 / 已经会了”筛选；
- 每页 40 字，避免一次渲染 2500 行。
