# 星页数独 · 独立可运行原型

一个给孩子玩的过程化图案数独：排除候选、保留问号、主动确定，一行一行把动态故事拼回来。

## 试玩与运行

本次运行地址：http://127.0.0.1:4317

需要 Node.js 24 或更新版本，无需安装依赖。进入本目录后：

```sh
node server.mjs
```

打开上面的地址即可。首次打开自动创建入门水晶关；“新的故事”可选择六档难度和五个世界。服务只监听本机。重启后恢复上次棋盘、候选排除与奖励。

默认进度在 `/private/tmp/mumu-sudoku-story-data/progress.v1.json`，不与正式应用数据或币余额交互。临时目录可能被系统清理；如需长期保存，使用仓库外的绝对路径启动：

```sh
SUDOKU_DATA_DIR=/absolute/path/outside-repository/sudoku-data node server.mjs
```

同一数据目录只运行一个服务进程。不要把进度文件复制进源码目录。默认服务端口为 4317，可用 PORT 配置。

## 过程化交互

- 题目固定格：金色高亮内框和小圆点，选中或出现重复提醒时仍保留；自己填写的格子使用普通边框，棋盘下方有图例。
- 点开空格：展示全部候选，记录“正在考虑”。
- 排除候选：点图案标叉，再点恢复。格子里保留问号和剩余候选的小图片；4×4/6×6 最多显示四张，9×9 最多三张，更多时显示省略号。打开工作台可看全。
- 只剩一个候选：自动确定。仍允许重新考虑、恢复候选、清空和撤销。
- 全部候选被排除：不填入非法值，显示恢复提示。
- 直接填写：可以覆盖先前排除，允许先做假设，不提前按隐藏答案阻挡操作。
- 同行、列、宫重复：用叹号、边框、无障碍文字提醒，不扣分。
- 提示：只按目前同行、列、宫推导允许值，在工作台显示可考虑的图案，不直接揭晓答案，也不改写笔记或存档修订号。
- “重新考虑”保留叉号历史，“清空这格”同时清除排除记录。撤销最多 200 步。
- 方向键移动，数字 1—9 / A—I 操作；Escape 收起，Backspace/Delete 清空。
- 全盘正确后锁定结算，防止撤销和重填刷同一局奖励；可以任意开始下一局。

## 随机题目与故事

题目生成池包含随机回溯终盘、合法结构置换终盘；挖空混用随机格次序与中心对应次序。每删除一个给定值都会求解并统计到两个解，只有唯一解时才接受。最多 40 次整盘尝试，达不到档位精确给定数则报告生成失败，不伪造难度。

故事使用共享上下文：主角、出发时间、交通工具、主题目的地、任务物品、配套的障碍/应对/结果、答谢礼物。原型有 5 个主题、8 个主角、4 个时间、4 种交通、4 个因果事件组、4 种礼物，理论上有 10,240 个主题故事组合。4/6/9 行分别组织为短、中、长故事。

每行句子均切成与该行格子数相等的碎片，按终盘符号建立该行映射。填写一个符号就把对应碎片放到这一格；排列不对时故事也接不顺；整行与唯一终盘一致时标记为已拼好。由此故事是真实拼接玩法，而不是与棋盘无关的随机通关文案。碎片可能成为语义提示，这是儿童探索模式的设计选择。

## 五套生成模型美术（V2）

- 水晶花园：9 种不同轮廓的立体宝石，细致切面与折射，配水晶花园星空。
- 原子星港：H—F 前九号元素的珐琅徽章与中文名称，配星港建筑；只是身份图标，不把背景装饰当作科学原子模型。
- 数字航海：1—9 立体琉璃数字，配星海与灯塔。
- 字母邮局：A—I 珐琅字母，配云中邮局与漂浮信封。
- 伙伴营地：9 位不同发型、服饰和配件的小宇航员头像，配帐篷、山峦与星河。

本轮使用内置 `image_gen.imagegen` 生成 5 张透明图标图集与 1 张场景图集，接入 45 张图标及 5 张背景；场景图集中另有 1 张备用探索舱背景。原始图集与完整提示词保存在 `assets/source-v2/`，运行时 PNG 在 `assets/v2/`。使用工程的图集切分工具并保留原始透明通道。图标以形状、配件和名称辅助辨认，棋盘及候选不再叠加辅助编号，数字主题本身仍然显示数字图像。

模型图集的行间距有偏差；`assets/source-v2/extract_assets.py` 先识别九个主要透明轮廓，按阅读顺序保留原像素并居中排到等大画布，再调用工程切分工具，避免切掉尖角或发饰。原图不覆盖，边界记录在各主题的 `*-alignment.json` 中。中间对齐图集可由脚本重建，不纳入版本控制；最终图标和原始生成图集保留。素材清单使用相对路径，提示词中的源图路径相对于 `prompts.json`。

所有主题均沿用星际探索舱色彩和界面。图片随原型本地提供，运行时无需访问图像服务；背景是本轮生成的固定场景，种子只微调展示位置，题目与故事仍逐局随机。图像加载失败时退化为图案名称，保留操作能力。没有自动声音或外部字体依赖。

## 文件与接口

- `engine.mjs`：纯算法、候选状态转换、规则校验、故事拼接。
- `art.mjs`：主题图片映射、图案名称与候选缩略图。
- `assets/v2/`：实际使用的图标、场景与切分清单。
- `assets/source-v2/prompts.json`：生成工具、完整提示词与源图路径。
- `app.mjs` / `index.html` / `style.css`：独立浏览器界面。
- `store.mjs`：版本化状态校验、单写入队列、临时文件原子替换、幂等奖励。
- `server.mjs`：本机静态页面与 GET `/api/state`、POST `/api/action`。
- `engine.test.mjs` / `http.test.mjs`：算法、存储与服务集成测试。
- `DESIGN_NOTES.md`：独立界面状态约定。

操作请求包含 operationId、revision、gameId；服务端拥有题目、终盘和奖励，浏览器只提交操作。重试使用同一 operationId；修订号防止不同页面覆盖进度。题目、候选、奖励、历史写入同一原子事务；写入失败不先改变内存、不先发币。

数据格式从 schemaVersion 1 开始；目前没有历史版本需要迁移。未知版本或损坏文件拒绝加载并保留原文件，不自动重置。

## 后续合并边界

这是无需依赖的 JavaScript 原型，尚未迁入正式 React + TypeScript + Fastify 架构。后续合并应：

1. 将纯算法与契约移入正式 TS 模块，按本项目 schema 工具校验；页面改为 React 组件。
2. 为正式钱包增加数独场次与幂等结算协议，接入知识币与能量币；进入场次时由服务端锁定奖励倍率。
3. 接入正式学习数据目录、迁移策略和奖励动效。不要直接导入本原型的试玩余额。
4. 若启用朗读，复用 `apps/web/src/shared/speech/`，不另建 TTS 或 ASR。
5. 在确认后补充正式设计规范、导航入口和业务文档；完成浏览器、触控与真实设备验收。

数独内容仅位于本原型目录；正式 apps、content、docs 和其他正在进行的工作不属于本原型提交范围。将原型纳入 main 不会自动增加正式应用入口或接入全局钱包。
