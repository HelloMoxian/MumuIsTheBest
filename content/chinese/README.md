# 常用汉字内容资产

`common-characters.v1.json` 是“常用 500 / 1000 / 1500 / 2000 / 2500 字”
共用的版本化内容资产。五个字池不是五份重复数据，而是同一个频率序列的前缀。

## 数据范围

- 2500 个互不重复的通用规范汉字表一级字；
- 每字包含频率序号、拼音、部首、笔画、通用规范汉字编号、简明释义；
- 每字包含 1—4 个组词、一条儿童可安全朗读的例句；
- 有合适成语时，附带最多 2 条成语、拼音与释义；
- 资产中不包含木木的个人信息、学习记录或运行时数据。

## 来源与处理

1. [hanziDB.csv](https://github.com/ruddfawcett/hanziDB.csv)（MIT）提供基于
   Jun Da 现代汉字语料的简体字频率顺序，并用于交叉检查拼音、部首、笔画与规范字编号。
2. [HSK 3.0 vocabulary](https://github.com/ivankra/hsk30)（MIT）用于优先选择
   分级学习词，避免只按影视语料得到不适合儿童的组词。
3. [SUBTLEX-CH](https://doi.org/10.1371/journal.pone.0010729.s002) 是基于电影与
   电视字幕的词频数据，用于对剩余词语和成语候选做常用度排序。
4. [chinese-xinhua](https://github.com/pwxcoo/chinese-xinhua)（MIT）提供中文释义、
   词语与成语候选。该仓库说明数据来自网络收集，因此这里只把它作为候选来源，不把单一
   条目视为绝对权威。
5. 自动流程会移除损坏文本、数字声调编码、不规范字、成人化表达和不含目标字的词语；
   自动抽取不稳定的常用字另有儿童友好的人工补充释义。
6. 例句采用保守的朗读句式，确保一定包含目标字和首个组词，不冒充原始词典例句。

## 分批与校验

生成时以 500 字为一个检查批次；正式提交前运行：

```bash
pnpm content:validate
```

校验覆盖 2500 项数量与去重、五档前缀池、一级规范字编号、拼音、释义乱码、组词、
例句和成语结构。当前资产包含 9978 个组词和 4592 条成语记录。

生成器位于 `scripts/generate-common-characters.mjs`。它需要本地提供上述四份上游
数据文件，生成结果使用固定时间戳，确保同一输入可以得到稳定、可审查的 Git 差异。
