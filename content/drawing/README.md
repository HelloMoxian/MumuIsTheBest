# 画图玩法内容资产

本目录保存开发者有意维护的默认贴纸源稿，不保存孩子的作品、作者姓名、历史记录或任何运行时数据。

## source-atlases

- `leaf-variety-atlas.v1.png`：树叶 3 × 3 黑白样张，已确认允许单片叶、复叶和多种轮廓。
- `butterfly-geometric-atlas.v1.png`：蝴蝶 3 × 3 黑白样张，统一为几何分区、无表情版本。
- `botanical-variety-atlas.v1.png`：花朵、蘑菇、果实、枝叶与仙人掌 3 × 3 黑白源稿。
- `sky-weather-atlas.v1.png`：太阳、月亮、星星、彩虹、闪电、雪花、雨滴、风与彗星 3 × 3 黑白源稿。
- `garden-creatures-atlas.v1.png`：瓢虫、蜻蜓、甲虫等庭院小虫 3 × 3 黑白源稿；正式运行时只采用无表情、无拟人五官的格位或重绘结果。
- `outdoor-objects-atlas.v1.png`：贝壳、海星、珊瑚、果实、树木、帆船与风筝 3 × 3 黑白源稿。

当前运行时目录提供 15 个二级主题、45 个独立矢量贴纸。源图只用于轮廓、分区和复杂度参考；运行时实现已经重绘为带稳定 `regionId` 的封闭矢量区域。

这些 PNG 只作为美术源稿和风格依据，不得直接作为无限白板运行时贴纸。正式贴纸入库前必须完成：

1. 按固定 3 × 3 格位切分且不覆盖源图；
2. 清理孤立噪点和透明边缘；
3. 修补关键轮廓的微小断点；
4. 转换为平滑矢量路径；
5. 为每个可涂色封闭区域生成稳定 `regionId`；
6. 校验外轮廓、自交、碎片数量和区域面积；
7. 分离轮廓层、填色层和点击命中层。

含眼睛、嘴巴、腮红、眉毛或其他拟人表情的贴纸不得进入正式目录。无法通过闭合校验的图集格位必须重新生成或人工修整，不能依赖运行时油漆桶修补。
